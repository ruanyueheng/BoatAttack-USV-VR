# 第20版岛屿美术

目标：保持现有四岛自由探索与秘境玩法，把圆盘海岸、积木岩石、柱状塔楼、团块树冠和玩具沉船换成具有连续曲面和结构细节的场景。

本版使用 `create-3d-model` 的生产流程、建模、材质、相机、灯光、渲染和导出模块。建模通过已连接的 Blender 5.2 MCP 分成 terrain、wind、forest、wreck、star、export 六阶段完成；最终石台通路修正和重导出在独立Blender后台进程中执行。未改动用户其他 Blender 场景、设置和插件；所有新增数据归属 V020 场景和带有 COL-V020 前缀的集合。

14个原创FBX：四个海岸地形，以及海蚀拱、层理岩峰、风铃瞭望平台、潮林老树、迎风松、蕨类、沉船、观星台、潮纹石门和木板栈桥。沿岸岩群复用原BoatAttack带纹理岩石，与背景海湾材质衔接。海岸有湿沙、干沙、草地的连续顶点色过渡和通向交互点的沙径；沉船有曲面肋骨、错缝破损船板、部分甲板、桅索和残帆；树木有弯曲分枝、根系及双面叶片；石门与观星台使用单独切分的拱石、径向台阶、柱槽和星环。

坐标：Unity米制，X东西、Y向上、Z南北。Blender使用(X,-Z,Y)，FBX导出在副本上镜像X并修正面绕序，Unity烘焙地形碰撞时保留导入根旋转。南部两岛从旧地形遮挡区移至开阔海面：沉船沙洲(-350,-340)，星望岛(350,-340)，防止视角进入旧山体。其余岛屿位置、栈桥、来信、宝箱、信标、居民和秘境路径沿用当前场景；所有互动目标根据新地面重新落地。攀登的平台碰撞保留，外观替换为木板、绳栏和屋顶结构。

运行 `Tools/Art/build_v020_islands.py` 可在新的 Blender 后台会话重建；代码不会清空已有场景。每个资产合并为单个共享顶点色材质网格；导出前检查有限坐标、非退化三角形、颜色通道及单资产24,000三角形上限。Unity安装入口：`Tools/Run-UnityValidation.ps1 -Suite FishingV020Install`。导入及最终玩法验收的结果见 `Docs/VALIDATION_V020.md`，源渲染与实际游戏截图分别保留。

`CoastalIslands-v020.blend`为可编辑源工程，FBX为Unity使用的交付格式。`asset-manifest.json`记录三角形数、Blender XYZ尺寸和最终文件SHA-256；其中Blender Z对应Unity高度。
