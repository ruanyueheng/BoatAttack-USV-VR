# 玩家反馈整改：第40版

目标为休闲经营与可选探险。故事为返村接任村长、发现旧海图、探索风林潮星四境、拼合宝藏航路，最后找到宝藏并取得“海贼王”称号。

## 实现范围

1. 渲染与显示：扩大海水岸深覆盖，修正首次采样时序与CPU波浪生命周期；AK降至12000三角面；树干下粗上细；替换三阶段萝卜并去掉菜园石圈；保留真实握点与实体碰撞。
2. 新玩法：四境独有遗物与蓝图、宝藏终章、材料与配方调整；鱼缸展示喂养成长；五类动物住所、捕捉网、诱捕笼与异性繁殖；斧、铲、耙及锯木、锻打；萤火沙洲可选守卫挑战和限区夜怪。
3. 世界观：序章接任村长，书桌发现秘密海图，居民提供动机和方向，四枚遗物制作航海罗盘并寻找大宝藏。普通M海图不会直接发现剧情秘密。
4. 交互：M掏出、展开和收起纸图；钓竿与水壶握姿、桌旁拿壶；环境线索与主动分级求助；双轮踏板、双阶段光路与桥梁开合；箱盖铰链；同源骨架互动动作；真人摇树短声与冷却；AK瞄准、连射和散布恢复。

## 试玩入口

- 海图：M打开，滚轮缩放、拖动地图并选航点，M或Esc收起。书桌保留原有海图入口。
- 主线：完成或跳过序章均记录接任；回家查看书桌，完成四境后到终端领取遗物与永久蓝图，工作台制作航海罗盘。
- 家园：商店“家园生态”购置套件、网和鱼食，或按配方制作。背包与XR手册均有生态页。家中管理展示鱼、喂食和住所；带网近距离瞄准真实动物捕捉，笼需放置并上饵。
- 成长：展示鱼经历三个游戏日及三次不同日喂食；幼兽两个游戏日成年。同种异性成年动物住进对应住所后可繁殖，受食物、每天次数和容量限制。暂停和离线不推进成长。
- 枪械：桌面左键长按连射、右键按住瞄准、F单发；短点射更稳定，移动和持续射击扩大散布，停火恢复。XR以实体控制器方向瞄准，保留头显视野。
- 可选战斗：萤火沙洲告示开启礁蟹守卫试炼；红圈蓄力后冲撞，侧移躲避。告示可结束挑战，离岛也会结束；失利安全回港且保留物品和金币。夜怪只在指定外礁区域出现。
- 战利品：守卫首胜获得守卫珠、礁甲和金币，礁甲可制作诱捕笼，守卫珠可制作家园纪念像。满包奖励记录会保留，整理后在告示补领。
