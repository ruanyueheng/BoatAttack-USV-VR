验证覆盖：

- 所有鱼种、三级鱼线/卷线器、三种鱼饵、大小鱼与不同随机节奏均可用张力反馈策略钓获；传说最短20秒，二级鱼线持续硬拉仍会失败。
- 非有限时间不推进规则；抄网换手时自动泄力，真实 Update 在10秒后仍会让未入网鱼逃脱；入网后的待处理结算仍只有一次奖励。
- 图鉴普通或珍珠变体都计入调查，售鱼不清除进度，实际存档重载保留渔场/传说坐标解锁。实际 Cast 在正确条件下无需自动化强制标记即可产生传说鱼。
- 键盘 W/Ctrl 驱动真实船体：基础航行约5.62m/s、加速约8.36m/s；过热后仍按住Ctrl也回到巡航，冷却后可再次加速。刹车、倒航、菜单与暂停守卫保留。
- 三种二级专精互斥，冲突交易不扣款，其他一级、钓具和装饰仍能购买。旧版多个二级升级可正常恢复。
- 高张力抄网不会提前锁死网口；泄力后重新覆盖、提起可完成捕获，测量放生只发一次奖励。实际XR控制台显示热量、冷却阈值、抄网倒计时和仅靠图鉴获得的北岛解锁；状态文字所需210像素小于新区域234像素，按钮射线回归通过。

修正记录：旧测试要求所有小鱼完成整轮冲刺、以及用珊瑚鱼构造高张力截图；小鱼缩短后调整为新的可玩性要求，高张力夹具改用鼓鼓鱼。首轮专项验证因测试资金不足停止，补充隔离夹具中的既有岛屿奖励后重跑通过。开发检查发现调查按钮受日志暂停守卫阻止，已修复并增加真实组件断言。

接续审查修复了高张力网口提前锁定、实际XR控制台遗漏提示与文字截断。保留失败日志：`Logs/usv-validation-d6dc1fe5d88e4924aa3727d67413b03e.log`记录旧文字区域不足；`Logs/usv-validation-032ed540124c49fa80fd7fa4a2867f0f.log`记录重试夹具提升距离不足，修正模拟动作后通过。没有放宽正式网口的覆盖时间、提起高度、速度和姿态限制。
