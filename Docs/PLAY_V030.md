# 第30版 · 海风来信与腰间灯火

2026-10-16，版本0.30.0。第29版的完整改动继续保留，见[第29版说明](PLAY_V029.md)。两版一起提交PR。

试玩：[Windows完整便携包](../Builds/FishingPrototype-v0.30.0-Windows.zip) · [PICO ARM64安装包](../Builds/FishingPrototype-v0.30.0-Android/FishingPrototype.apk)。

- 钓到旧靴子、生锈罐头或沉海宝匣，同样显示醒目的钓获框、真实物品图标、音效和粒子。每种拾获都有专属幽默文字；成功放入背包后才显示，重复抄网不能重复领取。满包时继续走原有鱼获流程。
- 信封新增海岛邮票和圆形海风邮戳；信封、信纸使用有细小纤维和折痕的牛皮纸纹理。标题、正文和落款使用现有中文手写字体，深褐墨色保持清晰。
- 新版复古提灯通过腰带侧面的金属钩与短皮挂带连接，垂在髋部外侧。选择提灯后双手保持空闲，F开关琥珀色灯光；Z可以拿起检视。VR仍支持靠近腰灯握键拿起，松开后回到腰侧。
- 玩家外观替换为用户9s.zip内的人物。保留原服装、头发、眼罩与贴图，适配现有动作骨架；第一/第三人称、行走、蹲下和持物共用新人物。

原始资源与转换记录位于ArtSource/V030；未修改桌面文件，不重置正式存档。继续沿用v13存档。
