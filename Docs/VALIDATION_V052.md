# 0.52.0 VR 优化与验证记录

日期：2026-10-30。本轮保留现有工程改动与玩家存档，集中修复实际操作、回家传送、VR 提示和剧情节奏。

## 改动与操作

- **抛竿**：原代码只读 `triggerButton`，同时要求手腕达到挥动速度，静止扣扳机无法抛出。现在兼容按钮与扳机模拟量；右握把拿竿后，按住右扳机蓄力、松开抛竿，无需强制挥腕，挥腕仍可增加抛距。A 可快捷拿竿并抛出。
- **提竿与收线**：修复 A 快捷持竿后物理输入未继承持竿状态的问题。咬钩时按右扳机或 A 提竿；搏鱼时按住右扳机收线，左手转轮和右摇杆画圈继续可用。冲刺、跃水或张力过高时停止收线。
- **结束钓鱼**：船上驻钓时按下右摇杆，立即收竿并起航，同时清理鱼线、抛竿动画、持竿、抄网和收线状态。待处理鱼获须先明确存放或放生，不会自动入箱。菜单和追踪恢复后须先松开再按，防止误抛。
- **快速回家**：B 手册首页、设置、航行帮助页，以及 Windows 暂停页均有入口。传送到回潮渔屋内，船停在家中泊位；落地前检查地面支撑和站立净空。关闭手作、制作、剧情和秘境状态，同步结束战斗，保留金币、背包、鱼箱和待处理鱼。到家后仍可通过鱼获卡片或 A 处理待入箱鱼。
- **VR 文字与地点**：手柄提示复用 Windows 的纸张、金框、标题字体和颜色，修正左右摇杆按压名称。地点提示补齐渔屋、海岸和渔场等区域，使用同源标题、金线和星形装饰；暂被菜单遮挡的地点提示保留至恢复显示。检查实际生成字形的视角大小，正文至少 1°，地点标题至少 1.5°，并检查标题框高度。
- **剧情与沉船**：四个秘境的剧情由约 13 秒延长至 17 秒，保留字幕展开、转场和跳过功能。共用时间轴的序章、海图和终章同步延长并重烘配乐。沉船入口前的站立引导点后退约 0.6 米，避开吊索碰撞。
