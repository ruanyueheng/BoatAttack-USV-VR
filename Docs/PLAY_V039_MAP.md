# 0.39.1 随身全域航海图

日期：2026-10-26。追加到玩家反馈清单的2号（功能）和4号（交互），与后续旧航海图主线共用地图资料。

- 正常船上或岸上按 M，角色由腰侧取出折叠纸图，双手展开，然后进入全域航海图。
- 地图支持滚轮缩放、拖动、定位当前位置、恢复全域及点击右侧目的地标记航点。
- 再按 M、Esc 或右上角收起，先播放折叠收纳，再恢复游戏。
- 第一人称展开时短暂转入角色正前方阅读视角，收起后恢复原视线；第三人称保留原相机。
- 地图阅读及过渡暂停船只、移动、工具和游戏时间；掏图/收图采用独立计时。
- 实体纸图复用已有烘焙海图，只有4个三角面，使用原角色骨骼双手，不增加相机或碰撞。
- 携带水壶时暂时隐藏壶，保持携带状态；收起地图恢复。保留开图前提灯开关。
- 秘境内全域图将玩家标记在对应入口岛，避免把独立谜题房间的远坐标画到世界地图。
- 角落小图仍可独立展开/折叠。原书桌全图入口保留即时打开/关闭，XR沿用现有手册地图。

验证命令：

```powershell
./Tools/Run-UnityValidation.ps1 -Suite FishingPortableChart
./Tools/Run-UnityValidation.ps1 -Suite FishingV033
```

专项仅使用临时隔离存档。截图输出到 `Logs/PortableChart/`；需要复看图片，模拟InputSystem输入不等同于真人键鼠或PICO设备验收。

本补丁覆盖追加的随身地图需求。整轮反馈的性能、世界观、家园生态、谜题和战斗改进仍按项目计划分别跟踪。
