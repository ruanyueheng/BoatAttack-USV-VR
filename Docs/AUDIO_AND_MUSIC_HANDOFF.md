# 动作音效与区域配乐交接

## 本次动作音效

保留 Unity 2022.3.62f1、现有玩法及存档。本次只补动作音效，不替用户选背景音乐。

- 成功拾取石块、矿料、贝壳：短促碰撞/收纳声；木材和柔软材料使用不同声音。背包满、重复领取及取消动作不响。
- 实际采矿接触成功：独立的矿石敲击声，不把起手动画当作成功。
- 开枪：用单次枪声替代原有简短合成声；保留原射击冷却和持枪/遮挡判定，不因命中再叠一枪。
- 脚步：沙、草、木、石四类，每类四个变体；按角色真实移动距离计步，跑步/蹲行改变节奏或力度。撞墙原地、暂停、空中、游泳、攀梯与传送不发步声；覆盖 PC 和房间尺度 XR 位移。
- 鱼轮：按实际鱼线米数变化区分收线与放线；抛竿飞线也有放线声。停线即停止，不能仅因为按住左键就一直响。
- 活鱼检视：只对待处理的活鱼在左/右手中播放分散的湿尾拍声；左手跟随检视动画时钟，暂停、切换菜单、放入抄网/鱼箱后停止，不把烤鱼或普通道具检视当活鱼。

所有声音接入现有“总音量 / 音效 / 静音”设置。天气海风、船体水声等现有环境音不重复叠加。短音源约 0.6 MB，声音来源见 [CREDITS](../ArtSource/Audio/CREDITS.md)。

## 配乐建议：先准备 6 组

这是按玩法划分的配乐区域，不要求每座岛、每个 Unity 场景文件各找一首。下列是待用户提供音乐后的切换方案，**目前尚未接入区域 BGM 自动切换**。

| 编号 / 建议文件名 | 使用区域 | 音乐氛围建议 |
| --- | --- | --- |
| 01_sailing.wav | 外海开船、漂航；排除港口和固定钓位 | 舒展、轻快、有海上旅行感，避免压过引擎/提示声 |
| 02_fishing.wav | 固定钓位：等咬钩、遛鱼、收鱼 | 安静、持续感强，给鱼轮与咬钩声留空间 |
| 03_home.wav | 回潮渔屋室内、家岛、屋旁菜园与桌边手作 | 温暖、放松、有归家感 |
| 04_harbor_shop.wav | 港口、钓具商店、店员附近交易区域 | 轻松、略有生活气息，不需要每位 NPC 单独一首 |
| 05_island_exploration.wav | 岸上各岛、沙滩、科考岸、攀登探索 | 清新、有探索感；现有多个岛屿先共用 |
| 06_realms.wav | 四个潮纹秘境共用 | 神秘、克制，别遮住谜题共鸣音 |

家园用实际人物位置及屋内/菜园状态判定，商店按实际进入区域判定；不是点了导航目标就立刻切歌。对话、背包和海图一般保留当前曲，适当压低音乐；普通区域切换计划采用约 2–4 秒交叉淡化，边界停留确认后再换，避免走一步就来回切。

## 发什么格式

- **优先 WAV 原文件**：PCM 16/24 位、44.1 或 48 kHz、立体声。不是硬性限制，不用为了匹配数字再重采样。
- **OGG Vorbis 或 MP3 也可以**，直接发已有的原文件，不必把 MP3 转成 WAV（不能恢复已丢失的音质）。Unity 2022.3 官方支持 AIF、WAV、MP3、OGG：[Audio Clip 文档](https://docs.unity3d.com/2022.3/Documentation/Manual/class-AudioClip.html)。
- 每组先给一首，建议约 **2–4 分钟**，适合循环播放；无长片头、无广告、无长静音，纯音乐优先。有无缝循环版本或循环起止时间就一起给，没有也可以由我后续处理。
- 不需要先自行调低音量、反复压缩；我会统一响度、设置长曲 Streaming/Vorbis 导入及交叉淡化，避免长 WAV 一次解压占内存。
- 文件用上表编号命名最方便；也可保留歌名，另外写“这首给开船 / 这首给小屋”。请附音乐来源和使用许可，方便记录。
- 请发实际可播放文件，不要只发平台收藏页、受保护的缓存或加密音乐文件。

**最省事的首批交付：6 个音频文件 + 每首对应的区域。** 后续再补四秘境各自的版本即可。
