# 生活玩法 V044 ——相机与图鉴 · 掌心地图 · 季节与节日

> 作者：Claude（life 代理），2026-10-28。代码：`Assets/Scripts/Fishing/FishingLife.cs`（规则，不依赖场景）、`FishingLifeWorld*.cs`（表现与输入）、`FishingPrototype.Life.cs`（接线）、`FishingHUD.Album.cs`（手账相册页）。验收：`Tools/Run-UnityValidation.ps1 -Suite FishingV044Life`，截图 `Logs/V044/life/`。

## 1. 老式胶片相机
- **模型**：程序化网格（`FishingMeshBuilder`，顶点色、共用 FishingPalette 材质，约 1.1k 三角面）：黑色皮纹机身、黄铜顶盖、镜头筒、取景窗、卷片钮。不加碰撞体。
- **桌面**：`P` 进入取景模式（第一人称镜头，画面加取景框四角与对焦十字，HUD 提示），左键 / 空格 拍照，`P` / Esc / 右键 退出。取景模式占用整帧输入，不会漏到抛竿、开枪、移动。
- **VR**：无需购买或装备相机。右手举到眼前（手柄距眼 ≤ 22cm，且在视线前方）时出现取景框；扣右扳机拍照，手柄短震，放下右手自动收起。持竿、驻钓、选中猎枪或望远镜时不触发相机；先用 Y 换下这些工具再留影。相机情境提示说明快门与收起；B → 航海手札 → 相册 / 照片图鉴可查看照片和拍照方法。
- **VR 望远镜**：Y 选中望远镜，右扳机举镜 / 放下，举镜后看向 22 米内无遮挡的陆地动物，按 A 记录；B → 航海手札 → 自然观察查看记录。当前 XR 只扩展观察范围，尚未实现镜筒内的放大画面；桌面倍镜不改动头显投影。
- **拍照**：一个常驻禁用的 Camera，按当前视角渲染到 320×180 RenderTexture，读回编码 JPG（质量 80，约 12–20KB）。快门音为合成短噪声。
- **存储**：照片不进存档。路径 `<存档目录>/FishingAlbum/<runId>/p###_d<游戏日>_e<图鉴条目>.jpg`，每局最多 36 张，满了覆盖最旧的（约 0.7MB 上限）。新开一局 = 新相册目录；删除存档不影响游戏。
- **手账相册**（手账第 8 页“相册图鉴”，桌面）：左侧 3×3 照片墙（分页），右侧图鉴条目表。VR 中照片进 XR 手册（同一 API）。

## 2. 图鉴（与海上事件同一套）
条目只有一份：`FishingPhotoCodex`。“已见”直接读既有记录，“已拍”另存 1 位：

| 位 | 条目 | 已见来源 | 拍摄判定 |
|---|---|---|---|
| 0 | 湾外座头鲸 | `seaLog` 鲸已收录（sea-events） | 鲸体在画面中央 70% 内、≤ 80m |
| 1 | 湾流海豚 | `Seen(MarineKind.Dolphin)` | 任一海豚 ≤ 40m |
| 2 | 夜光海 | `seaLog` 夜光海首见 | 夜光海事件进行中，镜头俯向海面 |
| 3 | 珍珠稀有鱼 | 图鉴已有稀有个体 | 手里（待处理）是稀有鱼，≤ 3m |
| 4–9 | 六位居民 | `Lore.Met(id)` | 居民 ≤ 12m、无遮挡 |
| 10–13 | 四岛秘境入口 | 已登岛 | 秘境门 ≤ 45m |
| 14 | 回潮渔屋灯塔 | 始终 | 灯塔灯室 ≤ 120m |
| 15 | 节日灯火 | 遇到过节日 | 节日装饰中心 ≤ 25m 且当天是节日 |

- 存档字段 `LoreData.photoLog`（v20，不升版本；由 realm-redesign 加入 FishingLore）：`0 ≤ photoLog < 2^24`，`version < 20` 时必须为 0；旧档缺字段 = 0。
- 首次拍到某条目：+15 金币、桌面通知/VR 世界粒子，相片标上条目名。同一条目再拍只进相册。
- 无遮挡：从相机到目标做 Linecast（只算非触发碰撞体，止于目标前 0.6m）。

## 3. 掌心地图（仅 VR）
- **手势**：左手柄“掌心”（手柄局部 -right 轴，左手手心方向）与世界上方夹角 < 50°，并且左手在胸前（距头 25–65cm，低于眼睛）——连续 0.15s 成立才显示，不成立 0.2s 后隐藏（滞回，防抖）。淡入/淡出 0.15s，用缩放。
- **内容**：掌心上方 7cm 的 16×11cm 海图：烘焙地形图 `FishingMap`（与 M 地图/XR 手册同一张贴图）+ 1.2cm 厚木框底座；玩家位置是立起的白色小箭头（朝向=视线），下一个目标是金色立针，潮位是右侧铜色竖条（涨落潮相位）+ 文字“涨潮/落潮 · 目标名 · 距离”。
- **性能**：1 个四边形 + 1 个底座网格 + 2 个小标记 + 1 个世界 Canvas 文本；无实时光、无透明叠层（地图不透明），只在显示时更新。
- 桌面不变：M 地图照旧。

## 4. 季节与节日
- 日历：每季 28 天，春夏秋冬轮转（已有）。**节日在每季第 14 日**；夏夜光季为第 14–16 日三天：

| 季 | 节日 | 装饰（程序化，一次合批） | 居民（npc 对齐） | 集市船（sea-events 对齐） |
|---|---|---|---|---|
| 春 | 风筝节 | 彩旗串 + 三只悬挂风筝 | 广场放风筝、抬头看 | 节日限定：风筝 |
| 夏 | 夜光季 | 青蓝灯笼串，夜里发光；三晚必为夜光夜 | 傍晚在码头看海 | 节日限定：夜光浮漂 |
| 秋 | 收获祭 | 橙黄彩旗 + 稻草捆 + 南瓜篮 | 端篮子聚到广场 | 节日限定：丰收篮 |
| 冬 | 灯会 | 红纸灯笼串，夜里发光 | 广场赏灯 | 节日限定：纸灯笼 |

- API：`FishingFestival.On(day)` → -1 / 0–3；`FishingFestival.Name(i)`；`FishingFestival.NextDay(day)`；运行时广场中心 `Controller.Life.Plaza`（钓具店门前开阔地，运行时用地面射线求得）。
- 装饰：广场四周 6 根木杆（半径 7m，自带 8cm 胶囊碰撞），杆间 3.2m 高悬挂灯笼/彩旗串（无碰撞，高于头顶，不挡路）。杆位先用 `Physics.CheckCapsule` 检查，与建筑/道具重叠的点位跳过，不穿插。节日当天整天显示，非节日隐藏。
- 手账日历：节日日期格写节日名（ui-restyle 绘制，调用 `FishingFestival.On`）。当天到节日时通知一次“今天是 · 风筝节”。
- 存档：不需要新字段，完全由日期推导。

## 5. 验收（FishingV044Life）
- 节日规则：四季各一个节日、第 14 日、夏三天、跨年轮转、`NextDay` 正确。
- 存档：photoLog 置位一次、JSON 往返、越界拒绝、v19 不得携带、缺字段旧档可载入。
- 相机：桌面取景 → 拍照 → 相册文件生成（尺寸 ≤ 40KB、数量上限轮换）、拍居民/灯塔/鲸解锁对应条目、遮挡时不解锁。
- 掌心地图：模拟左手掌心朝上 → 显示，翻转/放下 → 隐藏；显示时标记位置与玩家一致。
- 节日：跳到风筝节/灯会 → 装饰出现、无穿插（CheckCapsule）、非节日隐藏。
- 截图：`life-viewfinder / life-photo / life-album / life-palmmap / life-festival-spring / summer / autumn / winter.png`，逐张检查。
- 行走：装饰杆不得让 V044-WALK 失败。
