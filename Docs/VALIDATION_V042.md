# 第42版验证与交付记录

日期：2026-10-27，Asia/Shanghai。基于已合并的 PR #53（第41版），游戏版本 `0.42.0`，存档格式19。

## 改动范围

- 修正衣袖误绑手腕/手指、过大的袖口与上臂表面；保留原人物材质、贴图、五指手套及骨架。人物没有换配色。
- 桌面第一人称采用同源双臂视图，完整身体继续投影并在第三人称显示；XR的手/下肢及身体显示策略保留。低头时自然放低携带工具，休息手按身体坐标下垂，避免移到肩后。
- 暂停/模态释放不保留惯性偏移；水壶、手作和工作触点沿其已有运动曲线跟随，避免重复平滑；相同接触几何保留指骨缓存。
- 主线目标放入右侧纸卡，移除水族箱安装点漂浮文字；鱼缸展示尺寸适配缸体、平滑转向，并增加底石。捕获记录的重量、稀有度和售价不变。
- 四座主题岛新增8处一次性岸边补给箱，稳定ID8–15；沿用原子背包领取、满包保留、真实箱盖铰链与存档回读。旧存档可以升级，新记录不能降级给旧版读取。
- 珊瑚改为水下立体分枝；柜台、家中书桌及柜门增加木板接缝和五金细节。
- 剧情配乐离线烘焙，播放不再同步合成整段PCM；视线查询使用复用缓冲，航线几何按15Hz更新并缓存不变的目标环。
- 旧海图镜头移到屋内，终章对准宝箱实际中心；过场相机临时显示完整人物，渲染结束恢复桌面/XR原显示状态。剧情截图进入对应家屋/四境/终章场景，通过正式奖励与合成规则准备终章进度。
