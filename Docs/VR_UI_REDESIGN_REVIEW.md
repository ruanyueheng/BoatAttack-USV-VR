## 当前视觉问题

1. **首页没有视觉主角。** 六行状态、说明与反馈和九个等重色块争夺注意力；标题、时间、装备与操作说明缺少层级。
2. **视觉语言不一致。** 桌面 Kit 仍是近黑蓝绿卡片，VR 手册近黑底，码头是淡白绿矩形；注释中的“暖白卡片”与实际桌面色值不一致。
3. **入口像功能清单。** “制作 / 熔炉 / 锻造”等长标签被迫换行，缺少语义图标、短标题与副说明；按钮空白很多，文字却集中在角落。
4. **正文过密。** 桌面背包物品名低至 11 逻辑像素；VR 带照片按钮的文字仅 98 像素宽、17 号字，部分六字名称很容易换行。尺寸需按世界尺度和观看距离验收。
5. **状态不完整。** 桌面有 Hover/Disabled/页签 Selected，却无独立 Pressed；VR 射线悬停直接换成浅绿色，文字仍很浅，对比下降；移开后可能等下一次 0.2 秒刷新才恢复。
6. **反馈混入说明。** VR VisibleMessage 拼进通用状态段，使首页结构随提示长度变化；菜单入口与交易确认缺少统一的视觉规则。
7. **美术资产气质混杂。** 有可复用实物缩略图，但没有同风格导航图标、纸张边框、手册插画或手写标题字体。不能用 Emoji 或默认按钮冒充完成。
8. **VR 画面未等同于真机通过。** 目前可验证实体 Canvas 和射线几何，头显字形清晰度、双眼阅读、佩戴舒适度与帧率仍需设备验收；本次 ADB 查询未发现已连接设备。

## 目标设计系统

方向：**海岛奶油手绘 · 一册可以带上船的旅行手记**。纸张是阅读承载，深海绿是文字与操作锚点，沙滩金是边框与小印章，鼠尾草绿表示可交互与选中，珊瑚橙只用于稀有奖励、提醒和少量点睛。

| 色彩 | 色值 | 职责 |
| --- | --- | --- |
| 奶油纸张 | #F4E4C3 | 主面板、信息卡片 |
| 沙滩金 | #D2A76E | 装订、边框、分隔与印章；不用于小号正文 |
| 鼠尾草绿 | #6D9F89 | 选择边框、图标底盘、反馈；不承载浅色小字 |
| 深海绿 | #314F48 | 标题、正文、主要按钮底色 |
| 珊瑚橙 | #EF916B | 奖励、重要提醒，配深海绿文字 |
| 纸张亮面 | #FFF7E6 | 普通卡片与悬停提亮 |
| 次级墨色 | #52685D | 辅助信息；仍在不透明纸底上绘制 |

字号按首页 1100×780 的设计坐标定义：手写标题 46–48；功能标题 27–30；正文/副说明 21–24；最小操作提示 20–21。正文复用 Tide Sans SC Medium；手写风标题用裁剪并重命名的霞鹜文楷，保留 OFL。数字统一等宽占位，金额、容量和装备信息位置固定。不给中文正文加合成粗体，不使用系统缺省字体兜底来通过验收。

形状：圆角纸卡、细墨线、不规则纸缘、少量装订痕迹。纸纹强度低，中心阅读区保持干净；不在每块卡片上叠加大投影。图标使用统一深海绿线稿、沙金/鼠尾草/珊瑚填色；圆角端点、统一线宽、72 设计像素底盘，无 Emoji。

| 状态 | 表现 | 输入规则 |
| --- | --- | --- |
| Normal | 亮奶油纸底、墨色字、克制的金色边线 | 仅已有动作可点击 |
| Hover | 鼠尾草描边、稍提亮、箭头加强；约 80 ms 过渡 | 射线移出立即恢复，无粘住高亮 |
| Pressed | 更深绿边线、轻微压纸反馈；约 100 ms | 保留原扳机边沿；不延迟游戏指令 |
| Selected | 深绿/鼠尾草边线与明确标记 | 用于当前页/选中项；首页可记住最近访问入口，不改存档 |
| Disabled | 降低填色饱和度、可读的辅助墨色、不可用标记 | 不执行 Action；继续拦截扳机，避免触发游戏 |

页面出现建议 100–140 ms 的局部透明度过渡；奖励用图标/金额的一次轻微弹性反馈与原有声音/触觉入口，220–320 ms，禁止无限脉动、闪烁、全屏光晕和镜头运动。样板先落实按钮反馈，页面与奖励动效随后按具体页面验证。

## 各界面布局改进

| 界面 | 方案 |
| --- | --- |
| **手册首页样板** | 横向纸册；左侧海岛明信片与简短出发文案，右侧 2×3 常用入口；底部三个低频/返回入口；顶部日期天气，左下金币与容量，底部一行射线提示。九条 Action 全部保留 |
| 背包 | 减少每屏小格数量；把物品照片、名称、数量与“装备至快捷位”分开；选中详情和明确的移动目标；快捷栏作为固定底部工具带 |
| 工坊/熔炉/锻造 | 左侧配方，右侧产物与所需材料，底部一个主按钮；缺料写明差额；进度与领取状态独立显示，避免挤在配方标题里 |
| 航海图 | 大地图居中；位置、目标和距离只在侧栏；目的地大按钮分页；当前位置与目标使用轮廓、色彩和文字三重区分 |
| 图鉴/观察/日历 | 图鉴卡突出完整生物图片与发现状态；详情只呈现栖息条件和纪录；日历突出今日天气/潮汐，推进时间操作独立并解释成本 |
| 码头委托/售鱼 | 委托需求、可售鱼货与升级分区；一个上下文主操作；原二次确认显示独立报价卡，保留委托鱼保护与价格变化校验 |
| 商店升级 | 卡片排列与物品图统一；左侧分类，右侧升级前后差异；购买固定在同一位置；不能购买时给出金币不足/互斥/满级的明确原因 |
| 群岛航记/来信/对话 | 纸笺和航海印章；一屏一段，三个短选项；长篇故事分段，不占满常驻 HUD |
| 设置/教学 | 每屏少量设置；舒适度、校准、输入教学分组；大按键图标配简短说明与练习反馈 |
| 钓鱼 HUD/鱼获奖励 | 张力与应对优先，常驻信息减少；鱼获卡突出图片、名称、重量与新纪录；收纳/放生与交易规则继续使用原有事务 |
| 暂停/提示/序章 | 统一纸张与墨色；暂停只列继续/设置/返回等主要入口；临时反馈避免遮挡眼前目标；影院屏保持已有固定世界朝向 |

## VR 几何与性能预算

首页目标尺寸 1100×780，世界缩放 0.00105，对应约 **1.155×0.819 m**。沿用前方 **1.3 m**、眼下 0.12 m 的打开位置，打开后固定世界朝向，不随头部逐帧追逐。水平约 48°、垂直约 35°是几何估算，不是头显实测。正文 22 号约 23 mm 高，需在 1.1/1.3/1.6 m、正视和侧视中检查。

卡片与物理命中区域同步；常用卡片约 0.31×0.14 m，底部按钮高约 0.067 m。视觉压下只作用于装饰，不移动碰撞范围。保留右手射线 + 扳机、B 关闭、失焦关闭、双手追踪门禁、关闭后摇杆回中、菜单暂停漂移、已有遮挡判断。此次没有必要增加触碰输入或替换 XR SDK。

单张插画、少量切片纸张与图标，使用默认 UGUI Shader；首页的单个材质副本在水面导航航线之后绘制，保留世界空间深度测试。不新增模糊、后处理或实时光照。字体纹理密度适当提高以改善中国字边缘。仅在数据刷新/状态变化时更新文本；不每帧加载资源、生成图像或重建层级。实际批次数与 CPU/GPU 帧时以 Unity 采样与 PICO 真机为准，不预先宣称优化完成。

## 资源缺口与解决方法

- 缺少用户提供的参考截图：已查官方游戏页面，作为视觉规律参考；已有游戏截图只做对照，不直接放入游戏界面。
- 缺少手册专用插画：使用 ImageGen 生成一张原创海湾明信片，落到项目资源目录；无烘焙文字，标题用 Unity 真正的中文文本。
- 缺少统一导航图标与纸张资源：制作六个功能图标、海岛/设置/返回图标及可切片纸张边框；保持透明背景与统一线宽。
- 缺少手写标题字：引入霞鹜文楷裁剪字集，重命名派生字体并附 OFL；正文继续用现有字库，对新增中文执行缺字检查。
- 缺少 PICO 当前验证条件：当前未连接头显；先完成实际 Unity Canvas 渲染、状态和射线命中验证，再把真机检查列为明确待验收项。

## 实施顺序与边界

1. 审查结论、设计规范和布局方案先交付，期间不修改游戏逻辑。
2. 只实施手册首页：新增美术资源与一个局部呈现文件；仅改动 notebook 构建/首页呈现/首页按钮反馈接点，保留九条 Action。
3. 用实际 Unity 渲染首页、五种状态和海湾内摆放图；检查中文、文本溢出、目标尺寸、射线遮挡和原页面往返；保留前后证据。
4. **用户确认样板后**，再提取可复用组件/样式资源，依次推广至背包、图鉴、码头、商店等页面；此阶段尚未授权自动开始。
5. 全部推广后，在 PICO 4 Ultra 验收双眼阅读、真实手柄、长时间舒适度、反复开关与帧时。编译通过只能算基础门槛。

当前工作区已有大量未提交的游戏与美术修改。本任务只定向改 UI 样板文件，不回滚、提交或覆盖这些既有修改，不生成新的游戏版本号或替换现有发布包。
