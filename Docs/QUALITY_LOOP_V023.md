# 第23版画面与交互修复记录

按单人本地桌面/未来PICO设备、20种固定物种、25类背包物品和一栋住宅评估。失败证据保存在本地Logs，不把失败画面作为完成预览。

1. 四条原鱼：检查原始侧视图后修正鼓鼓鱼头向，扩大旗鱼照片的纵向留白；原件保留，运行网格降为3500面。
2. 新FBX：仅设置Unity轴转换仍留下物体旋转，取sharedMesh后握点错位。静态导出改为烘焙坐标，明确+Y、+Z矛尖和-Z门廊；检查导出后的实际网格。
3. 住宅选址：高处树冠被取为地基，树枝穿入室内。移至固定临水平台，补齐坡屋顶端墙。场景照片同时检查床、门廊、厨房和书房。
4. 家具组合：在冻结父网格前先保存所有子部件世界变换，保留源配色并保证只有一个活动颜色层；修正毯子、枕头和部件偏移。
5. 资源入口：同名FBX与prefab会让Resources载入未配置材质的模型。住宅明确读取View预制体，并逐件断言使用海湾顶点配色材质。
6. 可达性：瞬移到门口不证明可步行。实际角色从泊位下船，检查浮码头→木栈道→门廊的完整移动；登岸继续经过地面、净空、支撑面及转移视线检查。
7. 手部：掌心可达不等于腕关节可达。共享修正依据真实腕部目标摆放物体，更新钓竿、鱼获、场景工具和验证夹具的所有调用；镐恢复足够的掌面间距。
8. 深度穿模：烘焙真实角色网格，计算进入柄/镜筒8毫米以上的手部顶点，检查五指接触、包握和前镜片遮挡。已通过的第一人称专项不等同于实体头显校准。
9. 序章：相机画面之外单独渲染实际字幕屏幕，检查六镜头、跳过提示和长字幕。独立电影相机禁止控制双眼，剧情输入守卫覆盖走路、房间步进、菜单、物品与日历。

没有修改或发布公共技能；使用现有3D质量修复流程修正本项目。
