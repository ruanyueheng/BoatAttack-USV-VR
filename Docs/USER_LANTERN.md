# V028 用户提灯与腰间挂灯

从 PR #38 逐项接入用户提供的 `lantern.blend`、模型、PBR 贴图、物品缩略图和校准握持。源文件保存在 `ArtSource/UserLantern`，运行资源在 `Assets/Resources/FishingUserTools`。保留 V027 房屋与界面，提灯物品编号和存档格式不变。

电脑端选中提灯后按 F 切换灯罩发光和真实暖色点光源。切换到其他工具后，提灯挂在腰间并保持已点亮的状态；打开背包、进入对话等模态行为仍收起和关闭工具。腰挂偏移按原角色裤腰实测半宽、提灯完整网格边界及 5 厘米间隙计算，蹲下时跟随实际髋部。

PICO 未拿起的提灯挂在腰间；右手靠近提灯 22 厘米内，按住右握把拿起，松开握把归回腰间。Y 仍可选装备，选中提灯时右扳机可开关灯。丢失追踪或进入模态界面后会放回，恢复后必须松开再按握把。

横柄使用源模型真实握点，前臂分担旋转。灯罩独立子网格用材质属性块控制发光；暖光强度 1.35、范围 8 米，不新增实时阴影；手持和腰挂共用一个点光源。

验证入口：`FishingLanternValidation` 检查源材质、握点、腕肘、近裁剪与实际照明；`FishingV028ToolsSleepValidation` 检查腰挂边界、换工具保留灯光和单一可见灯具。运行证据由 V028 验收日志记录。PICO 实际握持距离及舒适度仍需头显检查。
