# v0.22 PR审查

What this change does: 为选定航点提供可避岸的水面路线，为来信、维修记录与故事页加入实体拆封阅读，升级五名居民外观，并将前四鱼种的简笔图改成真实网格照片。原图鉴ID、金币与存档版本保留，未生成的混元模型通过短提示词交接。

按单人本地游戏、14个固定目的地、12鱼种和六居民评估。本报告是开发者自审；PR另外提交审查，不把自审写成独立维护者审批。

## 审查中已修复

1. **水面线无法带玩家到远岛**：原捕鱼场景复制了 `Logic/LevelBounds` 三面竞速围墙。关闭只作用于当前捕鱼场景，保留岸和建筑；14航点及四条跨岛路线的真实碰撞检查通过。共享竞速预制体没有修改。
2. **读信遮挡与旧输入穿透**：收起现场告示牌、手持图鉴和桌面近眼身体，关闭后恢复原告示牌状态；故事守卫覆盖移动、房间步进、重复E和新交互。相机画面与实际组件断言支持结论。
3. **XR关闭后持续按B又打开手册**：来信关闭前XR手册的旧按键边沿仍可能处于就绪态。统一在故事模态切换时复位其全部边沿；实际手册字段通过先松开、关信、仍按B的回归确认不会触发。
4. **图鉴照片虽然存在却是空白或裁切**：文件存在断言不足以验收美术。改用真实网格在Blender渲染，核对像素及完整轮廓留白；程序简笔画路径删除，全部鱼种读取同名照片。
5. **角色头部改善但衣服仍像方块**：采用授权成品服装，保留真实衣料、鞋与皮带几何、颜色/法线和源UV。头部保持原拓扑，服装与远LOD控制面数，Unity预制体保留贴图引用。

## PR #32自动审查反馈

首轮审查提出两条P2：维修记录没有重读入口，待处理鱼获时阅读会先退出日志却不显示信件。已在海岸调查页增加幂等重读入口，并共享阅读可用条件和明确的结算提示；拒绝时保留日志及鱼获。新增实际组件回归验证重读、任务/金币不变、未结算鱼获守卫和结算后恢复。修复后199项专项、重新构建及打包验收通过。

## 核对结果

- 水路先直达、再搜索，邻边与简化边都做船体余量检测；泊位终点可在8米范围内选择可达水面。失败不给出穿岸假路线，地图说明提示返回开阔水面。
- 路线每帧使用已有对象与列表，12箭头池固定；路径搜索在换目标或偏离时触发，没有增加导航线程或外部依赖。
- 阅读为临时展示状态，继续由既有交易写入探索事实。重复读信、跳过和关闭没有第二条奖励路径；救援与切换验收夹具关闭展示。
- 图鉴与捕鱼、鱼箱和展示统一接受前四种同名模型；暂缺最终模型时保留既有程序网格，提示词没有冒充成已完成资产。
