# 第25版 Windows / PICO 试玩说明

版本：0.25.0。Windows 和 PICO 使用相同的玩法、中文名称、物品图片、制作配方与 v12 存档格式；进度分别保存在电脑和头显上。本版不清空已有进度。

## 本版变化

- 完整整合 PR #34 的猎枪、物种掉落、锻造台、山脚煤矿、毛皮灯笼、猎物刷新与店员资源。
- 船上舒适视角只把船体上下运动的 8% 引入视点，并限制在水线上下 3 厘米；真实头部追踪保留，首次进入自动校准眼高。上船、救援不会把出生点的临时高度当成水线。
- 两端共享中文内容和图标。PICO 用空间手册呈现背包、制作、地图、日历、图鉴、委托、商店、居民对话、剧情和设置；B 随时开关。船边原英文灰色控制台改成中文、默认收起，可在港口事务页打开。
- 普通操作结果使用短暂中文提示。打开手册和序章时停止船的水平漂移；退出后先松开双摇杆与加速按压，避免练习输入直接变成移动。
- 修正掌心方向与坐姿握竿位置；猎枪沿真实右手枪口瞄准，靠近并握住前握把时左手参与支撑。
- PICO 首次进入本版时，在头部追踪和眼高校准完成后播放六镜头序章，再提供三页手柄教学；前两页有实际按键练习。旧存档的序章标记不会跳过本次教学。设置页可随时重看。
- 失焦、挂起、正常退出会保存最近进度；商店、手册、剧情与跟踪失效期间不推进猎物活动刷新计时。

## 手柄操作

| 输入 | 船上 | 岸上 / 界面 |
|---|---|---|
| 左摇杆 | 前进 / 倒车 | 各方向移动 |
| 右摇杆 | 船舶转向 | 30° 分段转身；机关中旋转转盘 |
| 按下左摇杆 | 前推时加速，过热后冷却 | 教学有安全练习 |
| 左扳机 | 刹车 | 无额外岸上动作 |
| 右扳机 | 持竿时抛竿 / 提竿 | 射线点击、使用工具、猎枪单发、放置设施 |
| 右握把 | 靠近鱼竿握住，松开放下；靠近鱼获抓取 | 中指按侧面握把 |
| 左握把 | 靠近轮柄并转动收线；抓网或鱼获 | 靠近猎枪前握点时支撑 |
| 左 X | 低速靠岸下船 | 回到泊船处上船 |
| 左 Y | 切换快捷栏 | 切换快捷栏装备 |
| 右 A | 附近互动；持竿时快捷抛竿 / 提竿 | 居民、机关、设施、近手收取猎物 |
| 右 B | 打开 / 关闭中文手册，或收起事务面板 | 相同 |
| 按下右摇杆 | 当前无游戏绑定 | 当前无游戏绑定 |
| 系统 / 菜单键 | PICO 系统管理 | PICO 系统管理 |

教学会说明扳机在食指处、握把在手柄侧面。练习期间不会推进玩家移动或开枪，完成后松开摇杆和加速键再继续。

## 狩猎、采集与制作

在钓具店与店员交谈，查看商品购买猎枪（90 金币）。B 打开背包，将物品换入快捷位，再用 Y 切换。右扳机单发，射程 45 米、间隔 0.65 秒，沿真实枪口瞄准；墙体、菜单、剧情和丢失跟踪均阻止开火。命中后靠近遗体，把右手伸到猎物旁按 A 收取，满包保留遗体。

采矿需要石镐或铁镐。把镐尖贴近资源后按 A / 右扳机，或挥动采集；没有实际接触不会消耗矿点或发放材料。靠近工作台 / 熔炉 / 锻造台按 A 打开制作页，按正确站点配方制作。煤 ×2 和兔毛 / 狐皮 / 旧毛皮 ×1 可制作提灯；原有灯笼配方保留。

鱼获仍需明确选择存放或放生。可以物理放入鱼箱，也可以在 B → 港口事务打开中文鱼获面板处理。救援返回港口保留金币、背包和鱼箱。

## 构建与验收

源码使用 Unity 2022.3.62f1，PICO OpenXR SDK 为项目已固定版本；未升级引擎或添加运行依赖。Windows 试玩入口为 `Builds/FishingPrototype-v0.25.0/FishingPrototype.exe`；PICO APK 为 `Builds/FishingPrototype-v0.25.0-Android/FishingPrototype.apk`，包名仍为 `com.ruanyueheng.tidefin.vr`，版本号 25。

完整图形回归入口：`Tools/Run-V025Validation.ps1`。它分别启动隔离存档运行新 XR、狩猎、锻造、第一人称和 v0.24 玩法回归，避免不同测试的场景状态互相污染。

构建成功、截图与自动断言分别记录；它们不能代替真人佩戴后对双眼画面、手柄倾角、持续帧率和眩晕改善的确认。保留单发无限弹药和即时锻造配方的既有范围。

本轮五项 Unity 专项通过，纯规则 3593 项、输入 70 项通过。实际 Windows 包通过 48 个状态场景和 48 张完整 HUD 截图检查。Windows 便携 ZIP 位于 `Builds/FishingPrototype-v0.25.0-Windows.zip`，解压后保持 exe、Data 和 MonoBleedingEdge 文件夹在一起。

APK 大小 248,902,105 字节，ARM64 库、848 个归档条目读取及 v2 签名检查通过。SHA-256：`97aaa9c26573a6515815facbcddb98ebefff11eb518fbb860fc61502fa227525`。
