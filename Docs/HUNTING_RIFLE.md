# 商店猎枪与岸上狩猎

## 使用

- 潮汐钓具店柜台打开“狩猎装备”页后，点击猎枪或按 `1` 购买。售价为基础钓竿升级价格的三倍，目前 `30 × 3 = 90` 金币。
- 原游戏没有单独出售鱼竿，玩家已配备鱼竿；因此以基础鱼线/钓竿升级作为固定价格基准，不随玩家升级等级变化。
- 购买后自动放入快捷栏并选中；`1–9` 或滚轮换装，`I` 查看背包。
- 也可制作获得：熔炉将矿石炼成铁锭，锻造台用铁锭 ×6 塑形为枪械铁件 ×1，再在工作台用枪械铁件 ×1、木板 ×2、绳索 ×1 组装猎枪。制作后在背包中装备，不更改商店售价。
- 岸上左键或 `F` 单发，间隔 0.65 秒，最大射程 45 米。本阶段不消耗弹药，也无需装填。
- 命中兔子、狐狸、陆龟、海龟或海鸥即击倒。靠近并看向遗体，按 `E` 收取材料。海面/空中的目标会在附近可达岸边留下遗体。
- 兔子：兔肉 ×1、兔毛 ×1；狐狸：狐狸肉 ×2、狐皮 ×1；龟类：海龟肉 ×2、龟壳 ×1；海鸥：海鸥肉 ×1、海鸥羽毛 ×1。
- 猎矛也发放对应物种材料，保留主线兔肉 ×2、狐狸肉 ×3 的产量。分类肉类可在熔炉烤制，图标统一为无字简图，名称文字仍保留。

## 行为与保存

枪采用用户提供的 AK 外观。左右手由原角色骨架握住独立握点，枪位稳定在胸前，方向随视线改变。近处障碍会触发收枪/隐藏并禁止射击。准星判定目标，再从实际枪口检测弹道；墙体不能穿透，店员不是伤害目标。

商店、背包、暂停、交互动作、船上及 XR 模式不会开枪。射击为桌面第一/第三人称功能，未实现 PICO 控制器开火。

每只动物有稳定 ID。击杀、倒地位置与领取状态随存档保存，重复命中和重读存档不会重复发放材料。满背包时整份掉落原样保留。拾取完成立即移除尸体显示与命中碰撞，复用固定数量的模型；从拾取时开始计满 300 秒有效游玩时间才恢复新活体。暂停、失去焦点、对话与离线不计时，睡觉和切换昼夜不能跳过等待。未领取遗体不会被刷新吞掉；旧版已保存的日历计时记录仍兼容。海鸥死后停止飞行及着色器拍翼，重生恢复拍翼。

整合主线 v0.23（b726e38）的 v12 存档，保留日历、猎矛、船舶升级、岛屿、海洋图鉴及开场剧情进度。主线物品编号 0–25 保持不变；本地 v8 的 23/24/25 自动迁移为猎枪/旧兽肉/旧毛皮，避免与猎矛/生兽肉/炭烤兽肉混淆。旧通用材料不猜测来源，原样保留并可继续使用；新掉落全部按物种区分。保留 v0.23 的实物缩略图；新增狩猎与锻造物品使用无字简图补全，不退回汉字图标。
