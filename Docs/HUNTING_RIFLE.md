# 商店猎枪与岸上狩猎

## 使用

- 潮汐钓具店柜台打开商店后，点击猎枪或按 `4` 购买。售价为基础钓竿升级价格的三倍，目前 `30 × 3 = 90` 金币。
- 原游戏没有单独出售鱼竿，玩家已配备鱼竿；因此以基础鱼线/钓竿升级作为固定价格基准，不随玩家升级等级变化。
- 购买后自动放入快捷栏并选中；`1–9` 或滚轮换装，`I` 查看背包。
- 岸上左键或 `F` 单发，间隔 0.65 秒，最大射程 45 米。本阶段不消耗弹药，也无需装填。
- 命中兔子、狐狸或陆龟即击倒。靠近并看向倒地动物，按 `E`，沿用现有接触拾取动作收取材料。
- 兔子：兽肉 ×1、毛皮 ×1；狐狸：兽肉 ×2、毛皮 ×1；陆龟：兽肉 ×2。
- 肉和毛皮是背包材料，可堆叠至 64。此次没有增加烹饪、制作或出售配方。

## 行为与保存

枪采用用户提供的 AK 外观。左右手由原角色骨架握住独立握点，枪位稳定在胸前，方向随视线改变。近处障碍会触发收枪/隐藏并禁止射击。准星判定目标，再从实际枪口检测弹道；墙体不能穿透，店员不是伤害目标。

商店、背包、暂停、交互动作、船上及 XR 模式不会开枪。射击为桌面第一/第三人称功能，未实现 PICO 控制器开火。

每只动物有稳定 ID。击杀、倒地位置与领取状态随存档保存，重复命中和重读存档不会重复发放材料。满背包时整份掉落原样保留，不会只给肉而吞掉毛皮。已猎取动物不会因重开场景复活；本阶段没有另加刷新周期。

存档沿用 v8，新增可选 `huntedAnimals` 字段，旧存档缺少此字段按没有击杀记录处理。背包枚举仅在末尾追加猎枪、兽肉、毛皮，已有物品编号不变。

## 验证入口

```powershell
dotnet run --project Tools/FishingTests/FishingTests.csproj --configuration Release
./Tools/Run-UnityValidation.ps1 -Suite FishingHunting
```

本机曾出现 Burst JIT 原生 DLL 加载失败（4551）。验证脚本支持临时 `-DisableBurst` 参数，不改项目或全局设置。Unity 狩猎专项使用隔离存档，检查柜台交易、双手握点、画幅/俯仰、墙体/枪口阻挡、真实动物一击击倒、接触拾取及磁盘保存。画面证据位于忽略目录 `Logs/Hunting/`。不等同于实体鼠标手感或 PICO 实机验收。

本轮结果：1466 项规则断言、62 项输入/渲染策略断言通过。Unity `FishingHunting`、`FishingShop`、`FishingField`、`FishingInteraction`、`FishingFirstPerson` 均通过；Unity 专项使用上述临时非 Burst 模式。狩猎专项还覆盖站立/蹲姿、第一/第三人称共用模型、16:9/5:4/21:9 画幅和上下 30 度瞄准时的双手可达性。
