# 第42版：海边补给与回潮航程

本版沿用返村接任村长、寻找祖父旧海图、探索四境并找到宝藏的主线。完整玩法入口仍见 [第40版玩法说明](PLAY_V040.md)，第41版加入的“潮汐回响”过场继续保留。

## 这次的变化

- 四座主题岛各增加两处岸边补给箱。靠近并看向箱子，按 **E** 打开，可获得制作、喂养、种植材料或待开启的宝匣。每个箱子在当前存档中只领取一次；背包满时可以整理后再试。
- 航海目标移到右侧纸卡。家园附近尚未安装水族箱时，纸卡会提示从 **I → 家园生态** 进入建设页面。
- 修正第一人称袖口尖块、低头时的近眼上臂遮挡和镜筒内穿指；水壶及手作动作保留自身的过渡，手和工具更紧密地跟随。
- 浅湾珊瑚改为水下立体分枝，柜台、家中书桌和柜门增加木板接缝与细节。人物保持原配色。桌面第一人称采用双臂视图，第三人称与 XR 保留身体显示。

## 过场与地图

**E / 空格** 先补全当前字幕，再次按下进入下一镜；**Esc** 跳过整段。XR 右手 **A** 跳过。

**M** 掏出并展开全域海图，可缩放、拖动和选择航点；再次按 M 或 Esc 收起。家中书桌上的剧情旧海图仍需实际查看。

## 存档

旧档兼容更正：后续使用实际存档发现，本版新增宝箱时连带改变了动物冷却数组的长度校验，会把第40–41版正常旧档误判为损坏。文件没有被删除。请使用 [第43版](PLAY_V043.md) 读取旧档；该回归已修复，不应通过新建覆盖来处理。

本版使用第19版存档格式，新补给箱领取记录会持久保存。旧可执行程序不保证能读取更新后的完整存档，降级前应保留旧档备份。

安装包、实际验证结果和设备测试边界见 [第42版验证记录](VALIDATION_V042.md)。
