# 剧情 V044 ——《潮汐之约》

> 作者：Claude（story 代理），2026-10-27。实现：`Assets/Scripts/Fishing/FishingPrologue.cs`（台词与镜头表就在 `Films` 里），验收：`Tools/Run-UnityValidation.ps1 -Suite FishingV044Story`。
> 风格：海岸渔村 + 航海手账绘本；不使用小王子的角色、玫瑰、星球、狐狸等元素。

## 1. 世界观
- **回潮海**：一片有四座秘境岛的内海。村里的老话说：海每涨一次潮，都会轻声问一句——**“今晚，有人在等你回家吗？”**
- **潮汐之约**：四座灯塔（风、林、潮、星）是村子对这句话的回答。灯亮着 = 有人在等。渔船循光回港，鱼群也跟着潮回来。约定的代价是：灯必须有人守。
- **大寂潮**：村里人陆续去了城里，没人再守灯，灯一盏盏变暗。三十年前的一夜，海问了三遍没人回答，无声的大潮漫过群岛，四盏灯同时熄灭，鱼群散去。
- **回响**：每座灯塔熄灭时，把一位旧守灯人做过的“选择”封进了秘境。重走一遍这个选择，灯就会“想起来”。

## 2. 主题
**“等待，是一种需要被回答的约定。”** 远航与回家不是对立的：敢走远的人，也要记得回来；留下来的人，要让对方看得见、听得见。
游戏里的钓鱼、种菜、修屋 = “把日子过起来”，本身就是对海的回答；秘境 = 理解前人怎么回答；终章 = 玩家亲自接过答案。

## 3. 角色
| 角色 | 动机 | 成长 / 揭示 |
|---|---|---|
| **你（新村长）** | 收到一封无邮票、盖着潮水印子的信，回到祖父的渔屋 | 从“来看看”到“留下来”；终章接过灯芯，成为下一位守灯人 |
| **祖父 沈望潮** | 最后一位守灯人。大寂潮后说“我去把灯问回来”出海未归 | 星之回响揭示：他点亮星望塔后发现灯要有人守，**自愿留在塔上**，把罗盘和日志留给后人。不是失踪，是一个选择 |
| **阿铃**（风之守灯人，回响中出现） | 暴风夜船听不见港 | 摇了一整夜的铃：等待要让对方**听得见** |
| **阿根**（林守，回响中出现） | 潮水吃掉海岸 | 种下看不到长成的红树：有些路要**很多年后**才有人走 |
| **老船长**（潮之回响） | 风暴里船要沉 | 把货推进海里、空出舱位给孩子：**放下**才能让人回家 |
| 村民 | 各自留在村里的理由 | 对白随章节变化，见 `Assets/Resources/FishingV044/Voice/lines.txt`（npc 代理）。关系：铃音＝阿铃的孙女；青禾跟“根爷爷”阿根学种红树；阿砾的父亲是归潮号那夜被老船长救下的孩子；望星曾是沈望潮的记录员；林舟在码头送他出海，三十年每晚留一盏灯 |

## 4. 主线因果（与秘境玩法的衔接）
1. 序章 → 接任村长（`Career.FinishPrologue/AcceptMayorship`）。
2. 渔屋书桌发现旧海图（`DiscoverChart`）→ **第一章**：祖父把答案拆成四段回响。
3. 四座秘境（玩法见 `Docs/REALMS_V044.md`，由 realm-redesign 负责）。每岛首次收录回响后排队播放对应章节（`FishingRealmWorld` → `Prologue.Queue(Relic(island))`）：
   - 风 · 月牙风铃岛：按旋律敲铃、蹲伏顶风过桥 —— 对应阿铃“让人听见”。
   - 林 · 翡翠潮林岛：引光唤醒活根成桥 —— 对应阿根“慢慢长出来的路”。
   - 潮 · 沉船沙洲：排干船舱、趁排水泵撑住（涨潮 40 秒/落潮 70 秒）把货箱推上承重铜台，再注水升起浮桥 —— 对应老船长“放下”。
   - 星 · 星望遗迹岛：用望远镜依次找到海鸥、船锚、归航星（夜里对焦更快），三幅星图完成后出现回响 —— 揭示祖父的选择。
4. 四件遗物在工作台组装远航罗盘 → 白帆拱湾宝箱 → **终章**：罗盘指向回潮村；祖父日志“换你来答”；五座灯塔（四岛+渔屋灯塔）同时亮起。

情感节拍：好奇（信）→ 失落（灯灭、祖父未归）→ 三次理解（听见、等待、放下）→ 反转（祖父是自愿留下）→ 接过（换你来答）→ 日常继续（“日子还长着呢”）。
关键选择：本版不加分支（避免改动存档结构）；“选择”落在玩法里——玩家在每个秘境亲手重演前人的选择。

## 5. 演出规范
- **全部游戏内实时渲染**，删除了旧版混用的 AI 插画静帧（`FishingV031/Chapters` 图集不再被过场使用）。
- 每镜 6.5s；镜头数与已烘焙配乐 `Resources/FishingV042/Story/*.wav` 对齐（6/3/2/2/2/2/4 镜）。
- 光照“情绪”（Mood）：只在胶片相机渲染期间临时压低、暖化主光与雾色，渲染后立即还原；**不加后处理、不改游戏时间**。1 = 黄昏金光，2 = 清晨冷金。
- 字幕绘本风：细海军蓝遮幅（46px），底部 `TitleGlow` 暗晕托字，标题思源宋体 + `GiltRule` 金线，左上 `Star` 四芒星 + 章节名；正文 TideSansSC 21px，奶油白 + 投影。全部取自 `FishingUITheme`。
- **桌面**：镜头缓慢推拉/横移（SmoothStep），镜间 0.7s 渐黑。E/空格 先补全字幕再下一镜，Esc 跳过整段。
- **VR**：玩家视角从不被移动。过场显示在世界中固定的“舞台屏”（玩家前方 2.1m，开场时定一次位，之后不随头动），屏内镜头**静止**（不运镜），切镜只用渐黑；玩家可自由转头。右手 A 跳过。
- **重看**：XR 手册“重看剧情 · <最新解锁章节>”；桌面日历页按钮已请 ui-restyle 改为同一 API（`Prologue.Unlocked/Latest/Begin(s)`）。
- **存档**：不新增字段。解锁由旧档已有的 `PrologueSeen / chartFound / shrines / grandTreasureFound` 推导，v0.43 及更早存档直接可用。
- 性能：沿用单个 896×504（Android）胶片 RT + 1 个相机，无新增粒子/材质。
