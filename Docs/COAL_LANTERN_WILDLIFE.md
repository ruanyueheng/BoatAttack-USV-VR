# 山脚挖煤、手提灯笼与猎物刷新

操作流程：捡石料、漂流木和纤维 → 工作台组装石镐 → 山脚持镐 E 挖煤 → 猎取兔子/狐狸并 E 拾取毛皮 → 回工作台用煤 ×2 + 兔毛/狐皮 ×1 制灯笼 → 快捷栏装备，F 开关照明。

铁矿石在熔炉配合燃料炼成铁锭；铁锭在锻造台打成铁镐头，最后在工作台与木棍、绳索组装铁镐。铁镐单次挖煤 ×4，石镐 ×3。煤点保留原有 90 秒冷却和存档 ID，布置在可达山脚岩壁旁，不在房屋墙边或山体内部生成。灯笼配方不要求先获得玻璃，原主线灯笼配方继续兼容。

拾取猎物所有掉落物后，当场隐藏尸体并关闭命中碰撞。固定人口模型复用，不累计尸体；计满 300 秒有效游玩时间后恢复活体。计时随存档保存，暂停、对话、失焦、离线不计时；睡觉/改昼夜不能直接刷新。背包满时保留尸体和完整材料，不开始重生计时。

- Hunting 专项通过：真实海鸥命中、领取后清理、完整等待后重生和拍翼恢复。
