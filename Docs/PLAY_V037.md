# 第37版：星海纸页、古门与雷雨

在本地第36版家岛生活基础上继续改进；本 PR 同时纳入尚未进入主线的第36版运行内容。沿用 v15 存档格式及旧档迁移，物品编号不变。

## 按用途设计纸面与标题

主菜单保留实时3D港湾，标题和选项落在柔和暖光中。连续羽化的阅读薄幕逐渐融入海景，移除独立信纸面板和拼接角饰，让整幅画面连贯。

设置页改用内置 imagegen 新生成的暖色绘本背景：杏色象牙纸上，细金藤蔓、星月、环形行星和玫瑰沿边缘展开，中央为控件留白。整幅水彩画铺满屏幕，色调随昼夜变化。原图1672×941，运行导入上限1024；[素材及完整提示词](../ArtSource/V037/README.md)保留在项目中。

航图与航行手册继续使用星海航图纸，自然图鉴与观察页面使用植物标本纸，工坊、背包和家园储物采用灰蓝工坊记录纸；私人信件保留自己的信纸与封蜡。纸面角饰保留比例，正文区域保持留白。

开场主标题保留细金描边，手册使用墨色书写标题，设置与储物使用清晰的正文标题。小字不再统一套用金色艺术字。图案与文字一起随昼夜主题变化。

## 雕刻归航门与流动薄雾

门体改为有厚度的石拱、古铜枝叶嵌线和星月冠饰，四境使用不同点缀色。光幕使用缓慢流动的薄雾，取消原有大竖纹；细小星尘沿轮廓漂浮。每座门仍由三个合并表面绘制，没有阻挡通行的门体碰撞。

操作保持电脑 E、PICO 右 A。秘境的归航门仍位于路线终点。“减少特效”会停止薄雾与星尘运动并取消互动闪光。

## 抓握与水壶净空

源角色每只手保留19个蒙皮关节；本次修正持物指姿叠加行走动画、掌面朝向与握点位于柄中心的问题。水壶提手抬高，为手套留出净空；水壶、井绳、锄头、钓竿与线轮、镐和矛、摇筛与曲柄根据柄面限制各指闭合。枪械、双筒镜、书页、灯笼、鱼获支撑、抄网和拾物保留各自专用姿态。

不把“审阅了全部动作”写成“所有动作已在真机无穿模”。水壶的严格蒙皮接触检查、其他工具回归及画面复看范围列在[验证记录](VALIDATION_V037.md)。

## 暗沉雷雨

雨天的天空真正接收雨量与云量，层叠雨云遮住蓝天、太阳和夜间星月；日光、环境光、雾和海面反射一起变暗。远方闪电以稀疏的单次柔和闪光出现，随后播放延迟雷声。

暂停、失焦、进入秘境、切回晴天或启用“减少特效”时，闪电与待播放雷声会停止。雷声音量遵循音效设置。

实际验证、截图、构建状态及实体 PICO 验收边界见[验证记录](VALIDATION_V037.md)。
