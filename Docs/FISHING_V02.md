# 怪鱼航线 v0.2 — 模型细化与第一人称试验

更新：2026-09-27。本轮基于已合并的 v0.1；仍是 Windows 桌面原型，不是原生 VR APK。没有读取、导出或使用商业游戏 How to Fish 的素材。

## 这一版改变了什么

### 原创模型

- 珊瑚鱼：宽身、浅色环纹、鱼鳍、鳃、嘴和眼睛高光。
- 飞梭鱼：细长流线型、分叉尾、银色侧线。
- 鼓鼓鱼：球形体、斑点和短棘。
- 三种体型各自缓存一份网格；鱼箱与市场展示重复使用，而不是每次入箱新增网格。
- 鱼竿分段收尖，增加握把、导线环、卷线器及转动摇柄。
- 抄网改为有深度的编织网篮；鱼箱改为木板、角带、顶部框和把手。
- 渔港增加浮筒、木板甲板、系泊柱、条纹篷布、柜台与展示箱。

### 画面与信息

- 捕鱼相机单独使用 ACES 色调映射与轻量色彩调整；不修改原竞速的全局 Volume。
- 不加入运动模糊、景深或色差，优先保留操作清晰度。
- 缩小顶栏和底部操作区；捕鱼时收起小地图、空鱼箱面板和场景标签，降低遮挡。
- H 切换辅助信息；关键捕捞提示保留。

### 第一人称桌面预览

- 默认第一人称；C 切换第三人称。
- 按住鼠标右键环顾，V 视线回正。松开右键保留观察角度。
- 驾驶与捕鱼有不同的固定观察方向；不能在船上自由行走。
- 不把船体俯仰/横滚直接传给视角，不添加人为头部摇晃或速度 FOV。垂直漂浮做轻度平滑。
- 第三人称对目标位置和平滑后的位置都做碰撞探测，遇到遮挡立即收近，避免平滑过程仍停留在墙后；不宣称所有航道的相机碰撞已人工验收。
- 暂停时相机停止更新；恢复/重新获得焦点时，工具鼠标键必须先松开，避免误收线或抛竿。

## 为什么建议第一人称 + 可切换第三人称

第一人称能让玩家以船上人的位置观察鱼竿、浮标和船边的鱼，更接近未来 VR 的空间交互。第三人称仍方便看航线、船体和鱼箱，因此桌面保留切换而不强迫只用一种视角。

**第一人称不是 VR 完成。** 当前桌面相机使用鼠标和屏幕投影；真正 VR 还要独立完成：

1. PICO loader / XR Origin、真实六自由度头部跟踪及手柄交互。
2. 以稳定座舱/工作站为参照，只处理船体基座运动，不覆盖头显真实姿态。
3. 船上位移、加速度、座舱抖动与 UI 距离的舒适性选项。
4. 把桌面屏幕 HUD 替换成合适的世界空间仪表/提示。
5. 双眼水面、透明鱼线、帧时、温度与长时间舒适性的设备验收。

FishingViewRig 检测到活动 XR 设备时不会继续写相机姿态/FOV。这是边界保护，不是 XR 适配或设备兼容性证明。

## 修正的问题

- 之前对非 Landing 阶段再次执行 Scoop 会显示“抄网落空”，可能覆盖已经捕获成功的提示；现在无效阶段静默拒绝。
- 当焦点/暂停恢复时鼠标仍按住，旧版可能直接继续工具操作；现在要求先释放后重新按下。
- 生成的装饰基本体先立即禁用 Collider，再延迟销毁，避免创建当帧短暂碰撞推动船体。
- 暂停恢复现在还原原时间倍率而不是硬编码为 1。
- 当前渔区在交互时即时更新，避免依赖上一帧的位置结果。
- 修复鱼鳍双面三角共用顶点导致法线相消，细鱼线启用光照法线。
- 抄网平时收在船侧，只在抄鱼阶段展开，避免持续遮挡鱼体。
- 顶部提示和航速增加深色底板；HUD 同时按宽高缩放，兼容 16:9、超宽屏和 5:4 安全区域。
- 渔港招牌改为正向文字，避免从靠港方向看到镜像。
- 回归测试复现并修复第三人称遇障碍时的平滑穿墙；人工航道测试仍需继续。
- 实际首帧驾驶截图发现船没有留在配置的港口出生点：浮力初始化临时移动物体后，刚体和显示位置未同步。捕鱼初始化现在显式还原两者；自动测试会在传送到渔区前检查出生点偏移、港口交互距离及前方 12m 视线净空，避免再次漏测开局。
