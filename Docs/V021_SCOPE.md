# v0.21 开发范围

基线：`bc8d0d8b`，分支 `feature/v021-fishing-tension`。

保留工作开始时已有的美术资产、导入配置、渲染和XR设置修改。本版沿用现有 CatchSession、Species、图鉴发现位、天气日历、交易与待处理鱼结算，不增加依赖或新存档格式。

改动必须覆盖：

- CatchSession及桌面/XR驱动、抄网、震动、水花、失败提示和捕获记录卡。
- 图鉴调查规则、渔场准入、图鉴/传说页、地图/航点、XR手册、天气与潮汐选鱼。
- 加速实际推力、热量仪表、模态和暂停守卫。
- 二级升级规则、港口/实体商店/XR购买入口和旧档兼容。
- 无硬件回归、依赖旧捕鱼时长的验收夹具、实际Unity输入与结算验证、版本号、Windows包和使用说明。

兼容性约束：不重置金币/装备；不撤销旧二级升级；不丢弃待处理鱼；任何失败不得生成渔获或重复扣款。新升级的专精限制只阻止未来冲突的二级购买。

本版没有加入撞船损伤、燃油、专精重选、新鱼种或秘境内容，也没有新增连续捕获存档字段。首次发现和最大鱼纪录复用现有记录系统。
