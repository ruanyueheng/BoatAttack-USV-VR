# PICO 实体望远镜与握镐

Unity 2022.3.62f1。

- 望远镜选中后用双手握把握住，举至双眼前，从实体后目镜看远景。松手、移开或未对准眼睛时不显示放大视图。右摇杆上下变焦，A 记录动物。
- 望远镜依据双手位置确定镜身姿态，手部仍跟随真实手柄，不将左手强行吸附到固定握点。镜筒在头显中的间距约 66 mm，桌面模型比例不变。
- 石镐和铁镐沿手柄握持方向装配，镐柄横跨拳心，不再沿着手指方向悬在小拇指旁。掌内偏移以最终跟踪姿态重算，沿用原模型、材质、缩放以及左右侧倾校准。
- 验证必须包括真实可见手指蒙皮到镐柄距离、握柄穿模、多种手腕/校准角度，以及双手举镜门槛和移开退出。模拟姿态与截图不代替真实头显的佩戴确认。
