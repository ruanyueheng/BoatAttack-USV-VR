# 设施分工改版验收

工作台只组装装备/设施，熔炉只做带燃料的冶炼/烧制，锻造台只做金属塑形。“随身加工”与设施配方分成页签，桌面和 XR 共用同一分类函数。熔炉菜单优先显示铁矿冶炼。

新增物品 ID：38 铁镐头、39 枪械铁件；现有 ID 保持不变。既有炉内 iron、charcoal、glass、brick 和烤肉任务的配方 ID、秒数、预留材料/燃料不变；旧成品不会重新收取费用或转换成零件。

验证：3630 项纯规则断言通过，包含三个设施的无交叉产物、错误设施拒绝且不扣材料、熔炉计时、完整金属部件装配链、满包回滚和旧存档恢复。Unity Forge 专项通过真实场景的采石、工作台石镐、熔炉实际 Update 完成一批冶炼、锻造部件、工作台铁镐/猎枪、煤矿、工作台灯笼及磁盘存档；Hunting 与 V023 回归通过。
