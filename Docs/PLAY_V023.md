# 第23版试玩

本版包含20种可捕获海湾生物、回潮渔屋与睡眠、36秒序章、精细工坊物品及实物背包照片。

- 首次进入本版自动播放序章；E/空格/Esc跳过。J→日历页可重看，头显用固定影院屏幕和右手A跳过。
- J→日历→“导航回潮渔屋”，或N循环到该航点。驶向专用泊位，低速按G登上浮码头，沿有扶手的木栈道进屋。靠近床按E休息至清晨；未结算鱼获必须先处理。
- J→图鉴查看全部20种生物与栖息条件。龟在白昼浅湾、章鱼在夜间/雾中的礁区，蟹跟随落潮，其他物种各有季节、潮汐和昼夜条件。沿用原鱼饵、收线、抄网、测量、保留与放生。
- 快捷栏与I背包展示物品照片、名称和数量。工具台、熔炉、镐、矛及中间材料使用重制模型；桌面与XR共用同一套物品素材。
- 桌面WASD航行/行走，Shift刹船/快走，G上下船，E交互，F使用工具，I背包，J日志，C切换视角，R救援回港。

存档迁移到独立v12文件，原v11进度文件保留。新增物种、照片、序章标记和个人体重纪录不会覆盖旧版存档。

启动生成的 `Builds/FishingPrototype-v0.23.0/FishingPrototype.exe`。PICO设备上的实体输入和性能需要现场验收，桌面专项与自动检查不替代头显测试。
