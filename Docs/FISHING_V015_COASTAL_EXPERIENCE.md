# v0.15.0 · 海湾手册与甩竿

基于已合并的第14版 PR #24。改动只覆盖界面、动物恢复、昼夜、钓竿表现与用户提供的8种鱼模型；沿用库存、鱼获、发现位、抄网和收益事务。

## 界面

深海青底、薄荷绿重点与暖金色强调。常驻信息以半透明小条呈现，工具栏用文字入口，快捷栏从628像素缩为488像素，减少遮挡。日志使用留白、细分隔线和下划线选项；图鉴以实际混元模型缩略图显示新增鱼种，珍珠变体保留独立发现状态。背包、商店、暂停和PICO世界空间手册使用同一配色。

## 有时间的生态

完整昼夜为15分钟有效游玩时间。暂停、背包、日志、手册和失焦时停表。野兔、赤狐被猎取后在5分钟有效游玩后恢复，跨夜保持倒计时，休息会推进恢复。恢复到原栖息点，重载不会提前刷肉；满包与落空不会杀死动物。陆龟保留观察。

存档继续使用独立v9文件，以可选的分钟恢复时间扩展原格式；保留旧恢复日期供旧程序读取。v14缺少分钟字段时，以旧恢复日为依据迁移，并将剩余等待限制为5分钟。发现位、已有任务及鱼获记录不变。

青花鲭、金线海鲷、银沙丁、斑点石斑、月纹蝶鱼、蓝鳍鲔、星灯鱼、赤羽狮子鱼接入同一个造鱼入口，覆盖抛钓、抄网、检视和图鉴。近海增加24条固定预算的鱼，按现有海域、季节、天气、昼夜条件出现。原始GLB及面数与散列见 `ArtSource/Hunyuan/Fish/`。

## 甩竿

桌面停船后，按住鼠标左键后摆蓄力，松开前挥；轻点仍能近抛。蓄力改变浮标落点距离与飞行时间，浮标沿抛物线飞行、落水发出粒子反馈，落水后才开始咬钩计时。咬钩时点击提竿，补上短促抬竿；收线仍遵守张力和余线规则。失焦、打开界面、松键前移入工具区均取消未发出的甩竿。

PICO沿用右握键抓竿、按住右扳机向前挥、松扳机甩竿，挥动速度映射到同一个抛竿力度/飞行过程；左手摇轮收线。手柄真实姿态驱动竿，不套用桌面预设摆动。追踪丢失取消未发出的动作；恢复需要重新松键。

真机手柄力度、握点和持续帧率仍需PICO4Ultra验证。验证结果、截图与实际执行范围见 `VALIDATION_V015.md`。
