# 第28版 · 昼夜海图与海风烧烤

2026-10-15，版本 0.28.0。在第27版海岛家园和奶油纸张界面上继续开发，逐项接入 PR #38 的新增内容。桌面与 PICO 使用同一玩法、物品和存档规则。

## 新内容与操作

- **昼夜界面**：白天沿用奶油纸张，海图改为浅色水域；夜间渐变为深海蓝灰底、米白文字和暖金强调。右上角金币和鱼箱容量加入图标，VR 手册同步显示。
- **汐禾对话**：柜台前电脑按 E、PICO 按 A，查看小店故事、商品、制作与海岛生活等 15 个话题，也可查看商品或标记回潮渔屋。保留当前界面、角色和家园，未整体合并旧 PR。详见 [对话说明](CASHIER_DIALOGUE.md)。
- **真实工具**：接入用户的镐子与提灯模型及材质，调整手柄握点和腕肘。熔炉炼料、锻造台塑形、工作台组装；家中三座固定设施继续可用。详见 [镐子](USER_PICKAXE.md)、[提灯与腰挂](USER_LANTERN.md)。
- **海面生态**：非雨天海面偶尔有鱼跃出水面，海鸥会俯冲捕鱼，再带着小鱼升起。复用现有鱼群和鸟类，避免持续密集表演。
- **钓获惊喜**：已发现的普通鱼种成功钓获时，有机会捞到海漂旧靴、锈蚀铁罐或沉海宝匣。首次发现、稀有鱼和传说鱼不被替换；背包装不下时保留原有鱼获流程。宝匣放入快捷栏，岸上电脑按 F、PICO 用右扳机打开，获得 80 金币。一次物品只结算一次。
- **海风烧烤**：回潮渔屋旁新增烤架和鱼箱，与船上鱼箱共用库存。靠近烤架按 E / A，选择鱼箱中的可食用鱼，鱼会从库存转移到烤架；关闭选鱼界面后烤制 18 秒。烤熟后领取香烤海鱼，放入快捷栏，离船探索时电脑按 F / PICO 右扳机食用，恢复 50% 体力；体力接近全满时不消耗。暂停或打开选鱼界面时停止烤制，离线时间不计入。背包已满时成品留在烤架上，保存后可以继续烤制或领取。
- **自然休息**：床边休息时，人物依次走到床沿、坐下、躺下、坐起、下床。桌面相机跟随动作；PICO 保留真实头部朝向，不强制翻转视角。
- **腰间提灯**：电脑切换其他工具后，提灯挂在腰间，已亮的灯继续照明。PICO 右手靠近腰灯并握住右握把提起，松开归位；选中提灯时右扳机开关。追踪丢失或打开界面后收回，恢复时需松开再抓取。

## 试玩文件

- Windows：[便携 ZIP](../Builds/FishingPrototype-v0.28.0-Windows.zip)，完整解压后运行 `FishingPrototype.exe`；本机也可直接运行 `Builds/FishingPrototype-v0.28.0/FishingPrototype.exe`。
- PICO：[ARM64 APK](../Builds/FishingPrototype-v0.28.0-Android/FishingPrototype.apk)，版本 0.28.0 / code 28。

发布构建入口为 `Tools/Run-FishingBuilds.ps1`，一次生成 Windows 和 Android，并核对 Windows ZIP 内每个文件、APK 原生库及两个包的 SHA-256。独立底层构建入口用于诊断。

## 存档与来源

本版使用独立 `boatattack-fishing-v13.json`，首次运行且尚无 v13 主文件或备份时，会读取第27版的 v12 主文件或备份；原 v12 文件保留。第28版新增的烧烤、宝匣和新物品进度只写入 v13，回到旧版不会带回这些新进度。测试使用独立临时存档。

[验证记录与实际截图](VALIDATION_V028.md)。PICO 安装、双眼实际观感、真实手柄追踪、性能和佩戴舒适度仍需连接设备实测。
