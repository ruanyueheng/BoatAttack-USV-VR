# PICO 提灯与腰挂照明

- Unity 2022.3.62f1，沿用现有提灯模型。
- 岸上背包拥有提灯时，收起的提灯挂在右侧腰间；B → 背包 → 提灯 → 装备并挂到腰侧。
- 左扳机按一下点亮，再按一下熄灭，不必选中提灯。船上左扳机仍是刹车。
- 右手靠近腰侧提环，按住右握把拿起，松手挂回；灯体始终向上，随手位置移动。
- 选中提灯时右扳机仍可开关；桌面按 L 独立开关，选中提灯也可按 F。
- 换工具、采集、检视、整理背包不再误熄灯；腰挂照明不占用拿镐或枪的右手。
- 游泳、攀爬、登船时隐藏灯体并停止照明；返回岸上恢复。切换存档默认熄灭，失去最后一盏灯会清理照明。
- 点光源照亮周围，宽角聚光源照向前下方；使用两盏无阴影实时灯，沿用 PICO 的两灯预算。

2026-10-31：Unity FishingLantern 专项在 PICO 预览画质下通过，覆盖独立开关、暂停阻断、释放后再按、换工具/收起保持照明、站蹲竖直、实际灯室位置、手持及腰挂目标的开关亮度对比、丢弃最后一盏灯后的清理。已查看渲染图，确认腰挂灯在地面形成暖色光池。
