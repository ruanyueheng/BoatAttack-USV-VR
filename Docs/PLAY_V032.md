# 第32版：向海风启航

## 第33版更新：航程存档与动作修复

第33版版本号为 **0.33.0**，正式开发场景仍是 `Assets/scenes/Fishing/fishing_Island.unity`；Unity、URP、输入与 Legacy 人物技术体系不变。

- **三个存档槽**：开始菜单“新建游戏”“读取存档”“手动保存”，暂停菜单也可手动保存和读档。每槽分别展示手动/自动保存的本地时间、天数、金币、累计鱼获和鱼箱数量；空槽、损坏记录、有效备份有不同提示。覆盖已有记录、接管另一航程或替换内存进度必须确认。
- **自动保存**：鱼获结算、交易/升级、任务/探索、休息、采集与制作，以及每60秒有效游玩、暂停/返回开始菜单、失焦/应用挂起/退出。只写当前槽的自动记录，不覆盖手动记录；在另一槽手动保存后，后续自动保存跟随该槽。接管另一航程的已有槽会明确确认并同步替换两份记录，保留上一份有效备份。
- **安全恢复**：保存背包、鱼箱、任务、日历、设施与加工进度以及安全位置、停泊船只、视角模式和航点。游泳、攀登、秘境及尚未完成的动作不作逐帧存档，自动记录保留已获得进度并回最近安全点。待处理鱼保留真实凭据，不复制收益。原落脚点不安全时恢复停泊船只并提示。
- **继续游戏**：只恢复本次进程中的原场景与内存进度，不读取磁盘、不重新开局、不再次播放启航动画；关闭程序后需“读取存档”。没有本次航程时显示提示，继续按钮不可用。
- **旧档**：保留 `boatattack-fishing-v13.json` 及早期旧档不改写；新槽全部为空且旧档有效时迁入槽1手动记录。槽文件在旧基础路径旁，以 `.slot-1.manual.json` / `.slot-1.auto.json` 等结尾。
- **设置**：修复自定义滑条点击/拖动和精确零值；灵敏度统一作用船上/岸上鼠标位移且不随FPS改变；音乐、环境、音效分类控制，静音影响所有类别。沿用 `Fishing.V032.` 设置键兼容旧偏好，菜单/游戏往返不会重置；全屏请求和窗口尺寸持久化。测试模式不写用户偏好。
- **海图**：家中书桌“查看海图”打开独立宽幅阅读窗口，展示现有虚构海域烘焙底图；滚轮/按钮缩放、拖动、航点选择、定位、Esc/关闭按钮。打开时暂停游戏并释放鼠标，关闭恢复原状态。资源或着色器缺失有明确说明及示意/原始图像降级，不伪造真实地形。
- **人物与菜单动态**：完整骨架局部TRS恢复、单一晚帧采样、稳定归一化动作混合、暂停冻结站蹲过渡、游泳/攀登/睡眠叠加幂等及脚踝衔接。标题花草/悬挂物的轻摆、灯塔扫光、人物待机沿用现有资源，数量有界；不移动真实碰撞体和玩家位置。

第33版Windows入口：`Builds/FishingPrototype-v0.33.0/FishingPrototype.exe`，便携包：`Builds/FishingPrototype-v0.33.0-Windows.zip`；ARM64 Android候选：`Builds/FishingPrototype-v0.33.0-Android/FishingPrototype.apk`。本次实际验证与未验证边界见 `Docs/TESTING.md` 的第33版章节及最终报告。下列内容为保留的第32版历史说明。

## 这版的变化

1. 开始菜单改为实际游戏世界：黄昏家岛、小船与船上的主角。点击开始后，展示船驶向画面外，淡出后进入原有序章CG；本次启动后再次从暂停返回菜单时，继续原来的航程。展示船与玩家船独立，保留玩家位置和原有进度。
2. 设置分为操作、画面和声音三页。WASD分别绘制键帽，并有鼠标图示。支持鼠标灵敏度、垂直反转、第一人称视野、三档画质、全屏/窗口、舒适航行、粒子数量，以及主音量、音乐、环境、互动音效与静音。设置会保存。
3. 移除了原竞速环境的21个大型灌木背景片及其碰撞。渔区装饰礁石下沉并取消碰撞。原有可登岸地形和任务设施保留。
4. 增加白帆拱湾、萤火沙洲。用N循环航点，或点击地图上的“拱”“萤”；靠岸低速G下船。两岛有实体地形、植被、营地与夜间灯火。白帆拱湾使用通过Tripo生成、优化后导入的真实拱岩；地图底图已更新。
5. 金币与鱼箱改为图标加数字，移除资源、常驻标题、工具栏和快捷栏的成排外框。小地图增加黄铜外圈、刻度、铆点和方向装饰。战斗中的必要张力、余线与限时提示保留。
6. 增加实时柔和阴影、克制的高光泛光、随时间流动的平滑天空。抛钩入水、近船挣扎、跃起、临近抄网、抄获和船尾航迹会产生柔边水滴及扩散涟漪；低特效模式保留较少的水滴反馈。

## 四座秘境

| 秘境 | 操作与可见反馈 |
| --- | --- |
| 风之回廊 | 先听风铃示范，再以星→风→潮回应；相邻敲击留出至少0.4秒，超过8秒会重奏。地面光带给出节拍。 |
| 森光庭院 | 转动三面反光镜至东、南、西；光束照到幼苗后，持续5秒使植物生长并开启光桥。光束错位时生长会回退。 |
| 沉潮机库 | 水闸依次为关闭、排水、注水。先排水到15%以下，再推货箱两格压住承重台；注水恢复至95%以上，浮桥升起并打开通道。 |
| 星轨圣所 | 每个星盘同时带动下一盘；将三个盘调成东、西、南。全北初态可转一号一次、二号两次。连接的星光与指针同时变化。 |

完成后的回响奖励、已完成秘境、旧信件、装备和v13存档继续沿用，不重置进度。
