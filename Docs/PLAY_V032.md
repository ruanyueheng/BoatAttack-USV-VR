# 第32版：向海风启航

Windows：`Builds/FishingPrototype-v0.32.0/FishingPrototype.exe`。便携包：`Builds/FishingPrototype-v0.32.0-Windows.zip`。PICO：`Builds/FishingPrototype-v0.32.0-Android/FishingPrototype.apk`。

## 这版的变化

1. 开始菜单改为实际游戏世界：黄昏家岛、小船与船上的主角。点击开始后，展示船驶向画面外，淡出后进入原有序章CG；本次启动后再次从暂停返回菜单时，继续原来的航程。展示船与玩家船独立，保留玩家位置和原有进度。
2. 设置分为操作、画面和声音三页。WASD分别绘制键帽，并有鼠标图示。支持鼠标灵敏度、垂直反转、第一人称视野、三档画质、全屏/窗口、舒适航行、粒子数量，以及主音量、音乐、环境、互动音效与静音。设置会保存。
3. 移除了原竞速环境的21个大型灌木背景片及其碰撞。渔区装饰礁石下沉并取消碰撞。原有可登岸地形和任务设施保留。
4. 增加白帆拱湾、萤火沙洲。用N循环航点，或点击地图上的“拱”“萤”；靠岸低速G下船。两岛有实体地形、植被、营地与夜间灯火。白帆拱湾使用通过Tripo生成、优化后导入的真实拱岩；地图底图已更新。
5. 金币与鱼箱改为图标加数字，移除资源、常驻标题、工具栏和快捷栏的成排外框。小地图增加黄铜外圈、刻度、铆点和方向装饰。战斗中的必要张力、余线与限时提示保留。
6. 增加实时柔和阴影、克制的高光泛光、随时间流动的平滑天空。抛钩入水、近船挣扎、跃起、临近抄网、抄获和船尾航迹会产生柔边水滴及扩散涟漪；低特效模式保留较少的水滴反馈。

## 四座秘境

| 秘境 | 操作与可见反馈 |
| --- | --- |
| 风之回廊 | 先听风铃示范，再以星→风→潮回应；相邻敲击留出至少0.4秒，超过8秒会重奏。地面光带给出节拍。 |
| 森光庭院 | 转动三面反光镜至东、南、西；光束照到幼苗后，持续5秒使植物生长并开启光桥。光束错位时生长会回退。 |
| 沉潮机库 | 水闸依次为关闭、排水、注水。先排水到15%以下，再推货箱两格压住承重台；注水恢复至95%以上，浮桥升起并打开通道。 |
| 星轨圣所 | 每个星盘同时带动下一盘；将三个盘调成东、西、南。全北初态可转一号一次、二号两次。连接的星光与指针同时变化。 |
