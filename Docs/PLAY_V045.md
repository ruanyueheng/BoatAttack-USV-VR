# 第45版：秘境声音与遗漏收尾

Windows：`Builds/FishingPrototype-v0.45.0/FishingPrototype.exe`；便携包 `Builds/FishingPrototype-v0.45.0-Windows.zip`。

PICO：`Builds/FishingPrototype-v0.45.0-Android/FishingPrototype.apk`。包版本 0.45.0，versionCode 45。旧存档沿用 schema20，第44版构建保留。

- **四个秘境**：成功操作有各自的机关音，完成阶段/全关有提示，读取回响有长尾；首次通关后的剧情不会截断长尾。机关音跟随“音效”，环境底声跟随“环境”滑块。
- **VR 相册**：B 打开手册 → 自然手记 → 生物／相册图鉴 → 相册。每页六张，点照片看左页放大图；照片图鉴与桌面共用记录。
- **VR 翻页／握书**：左手靠近书左边缘握把固定书，松开释放；右手在页上握把横扫翻页。追踪中断后松手再握。原射线、戳按、翻页按钮均保留。
- **家园储物箱**：手伸到箱盖外沿，任一手握住并向上抬；抬开后显示原储物界面。A 仍能打开。
- **攀梯**：手伸到可见横档，握住后向下拉；左右手交替继续。原左摇杆上下仍可用。
- **集市船**：靠近听见索具／轻水声，成交有短铜铃；离开、休市、暂停或静音时停止。
- **居民**：聚会预留间距，林舟晚间在实际登岸平台面向泊船点。

PICO 4 Ultra／OS5.15.8 实机启动与双眼画面已通过，用户已确认头部与双手柄跟踪正常。Android 使用LZ4分块资源，修复旧包长时间加载黑屏。核对依据及保留边界见 [CLAUDE_INTEGRATION_V045.md](CLAUDE_INTEGRATION_V045.md)；新手势舒适度、四境主观听感和目标帧率仍需逐项实测。
