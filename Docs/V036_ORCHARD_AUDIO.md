# 果树互动素材说明

`Assets/Resources/FishingV036/OrchardOuch.wav` 为本机 Windows SAPI 的 Microsoft Huihui Desktop 简体中文语音合成，内容为“哎哟！”，语速设置为 2。它是真实合成语音，不是提示音或真人录音；未调用外部语音服务。

果树和掉落苹果分别复用项目已有 `FishingV035/OrchardTree`、`FishingV019/apple`。树叶粒子复用游戏现有粒子池。每棵树每天最多拾取一枚甜果；掉落时不占用当天额度，拾取成功才写入存档。未拾取的落果在重新载入后回到树上，可重新摇落；背包满时果子保留在地上。

轻微砸头事件按树编号和游戏日确定为 1/5，不扣生命或物品。桌面镜头只在 0.25 秒内作小于 0.025 米的衰减位移；PICO 使用短震动和透明边缘提示，不移动或旋转玩家镜头。
