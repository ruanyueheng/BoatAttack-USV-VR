# 航程设置与物资存档

电脑：开始菜单或 Esc 暂停菜单 →「日期与物资」。PICO：B 手册 → 设置 →「日期与物资」。

第一次选择「继续自定义存档」会建立独立自定义存档；以后会读取它的最新记录。想重新布置展示，选择游戏历的年份、春夏秋冬、1–28 日和小时，再按「按日期重置」。日期采用游戏历，每季 28 天；不是现实公历。

自定义存档预置 10 万起始金币、满级船具和钓具、工具快捷栏、四境蓝图、家中材料箱、8 格水族箱与 4 尾鱼、五类动物住所和 6 只家养动物、半田成熟作物。材料在家中储物箱，消费品在背包。首次进入与重置后从回潮渔屋开始；时钟默认固定，可在日历恢复流逝。

所选日期重置会补满展示物资，并重建展示进度。因此可以直接跳回较早日期，无需把已经成熟的作物或动物年龄倒拨。展示中仍可捕鱼、做菜、种植、拍照、制作和交易，继续自定义存档会保留这些操作。

「返回原航程」恢复进入前的正常航程。自定义存档与正常的三个存档槽使用不同目录：基础玩家存档旁的 `ClassroomDemo/classroom-demo.json` 及其独立槽文件。正常活动槽偏好保持不变，重新启动游戏也不会自动进入自定义存档。不要将展示 JSON 覆盖到正常存档。

验证导出的样本为 `Logs/V053/Classroom/classroom-demo.json`；游戏内入口会自行建立平台对应的自定义存档，无需手动复制。

课堂演示可选第1年春14日看风筝节、夏14–16日看荧光季、秋14日看收获节、冬14日看灯会。选择18时或21时可比较日落与夜景；节庆装饰在港口广场。日期按所选值重建自定义存档，记得先完成想保留的拍摄或操作。

限定集市船每周六和节日的08:00–19:00营业，每周停在不同渔区。日期面板会显示所选时刻是否营业及所在渔区；默认春14日10时可购买春季纪念品和节日限定风筝。夏14日、秋14日、冬14日10时分别可购夜光浮漂、丰收篮、纸灯笼。用航海图前往面板注明渔区，靠近商船14米内、减速到2.5m/s以下，看向摊位按A（电脑E）购买。
