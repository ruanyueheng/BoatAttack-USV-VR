# 0.57 手作与沉船航线修复

2026-11-01

锯木改为沿锯缝前后推拉，左手按在木料另一侧；锯齿向下，工作手不再横着搬动整把锯子。锻造改用与角色臂长相称的短锤，围绕手腕抬落，铁坯放在桌面前方。只有抬锤后锤面落到铁坯才计数，空中挥动不产出物品。

- 桌面：按住鼠标左键，前后拖动锯木；向上拖动抬锤、向下拖动敲击。Esc 收起。桌面视角会按实际工具范围取景。
- PICO：A 开始，松开右握把后靠近握柄，再握住工具。锯子沿木料前后推拉；锤子抬起约 8–12 厘米后落到铁坯。A 可切换锻造配方，B 收起。工具跟随实际追踪手柄，头部自由观察。
- 完成前不扣材料；锯木产出木板×4，铁镐头消耗铁锭×3，枪械铁件消耗铁锭×6。

沉船沙洲方向西南旧赛道大陆已局部清理，旧地形降至海床并同步处理装饰、碰撞与海图。四个科考岸及家园保留。存档中位于被清理地形上的玩家设施会迁到家园安全地面，保留朝向、加工进度和待领取产物。

本版还修复 VR 手作进入后移动输入重新解锁造成的握把失效，移除手作低头视角中的躯干残片和遮挡工具的重复手柄提示卡。
