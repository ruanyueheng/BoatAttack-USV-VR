# 2026-11-03：PICO VR 模拟试玩与修复

当前源码：0.60.0。按用户说明，本轮不连接 PICO，使用 Unity 2022.3.62f1 的原生 Mock OpenXR，开启项目 PICO 画质设置。头、手、按钮、扳机和摇杆经过原生运行时与正式交互代码；初始位置、物品和材料使用显式隔离夹具。没有使用玩家普通存档。

## 发现和改动

1. **手册“附近互动”误用桌面动作。** 群岛来信和四境图页原先调用 `RequestWorldInteraction`；拾取/远征分支会进入桌面动作，而该动作在 XR 中被取消。两处现在关闭手册并排队，双手追踪有效、摇杆回中后，与 A 键共用 `InteractTracked`，按当前手位和目标派发一次。关闭菜单的 `MotionReady` 守卫仍然保留；否则猎物/家园互动会被同一个守卫误拒绝。追踪丢失、暂停、模态、头部受阻或输入重置取消请求。原生回归验证远处拒绝、近手领取、不重复、等中立、追踪取消，以及真实猎物与家园箱子。
2. **岸上快门被手持手册抢占。** 实际模拟复现：举相机后按右扳机，`UseTrackedTool` 先打开图鉴第15页，随后快门被菜单挡住。现在按本帧追踪姿态决定扳机归属，避免读取上帧 `VrRaised` 漏掉“同时举机和按扳机”的边沿。原生回归验证该边沿不打开手册，正常拍照、按住不连拍、追踪恢复不误拍、松开再按可拍第二张；B菜单仍由原入口处理。
3. **写盘失败仍结算照片；相册满时先删旧照。** 旧代码在异常后仍增加拍照数、图鉴和金币，并可能在新照片失败前删掉旧照片。现在先写临时文件并移动为正式照片，成功后才结算和轮替旧照；失败提示玩家并保留计数、上张照片信息、图鉴、金币与旧照。独立相机回归在旧代码明确失败，修复后通过。
4. **快门输入兼容与失焦/挂起边界。** 改用全游戏统一的数字/模拟量扳机读取；失焦时隐藏取景并停用快门，持续记住应用挂起状态，恢复后要求先松开。挂起期间的扳机也不能漏给手册或其他岸上工具。编辑器回归验证失焦；原生运行时中模拟暂停通知并保持焦点为真，验证暂停、恢复与重按。模拟量兼容缺口由源码确认；本次 Mock 同时提供数字按钮，未据此声称复现仅有模拟量的实体控制器。
5. **手掌和原工具遮挡近眼取景。** 原生截图显示手掌与手册覆盖画面中心，即使照片计数正常。复用现有光学观察显示规则，举相机时隐藏本地近眼身体渲染及原持有工具，放下后恢复。保持原追踪位置和头显投影；渲染状态、恢复断言和最终实际截图均已复核。
