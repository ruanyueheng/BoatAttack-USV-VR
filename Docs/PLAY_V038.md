# 第38版：浮桥、水体与真实握持

版本为 `0.38.0 / versionCode 38`。沿用 v15 存档和原物品编号。

## 沉船沙洲

注满船舱后关闭水阀，水位会保持，浮桥也继续可走。原先完成判定错误地要求水阀必须一直处于“注水”，关阀就会取消桥面碰撞。现在通路由货箱承重和实际水位决定；真正排水才降低桥梁。已完成秘境的旧档仍保留高水位通行条件。

桥板略作延长，碰撞顶面与可见木板对齐，两端与甲板重叠衔接。验证覆盖桥面左右两侧双向连续步行。

船舱水改用有边界和深度的水域，网格波动、深度衰减、折射和环境反射一起表现积水。排水露出原船底；满水时浮筒部分浸入水中。进入深水会浮起游泳，按空格可攀回低甲板，移动会产生涟漪。水体使用有界近似，未引入昂贵的流体粒子模拟。

## 水壶与镐

水壶实际导入模型的深度坐标与旧代码相反：旧握点离真实提手约18厘米，液面和壶嘴也放错了方向。现按实际 FBX 统一握点、内部水面和出水位置，并调整木架上壶的朝向以保持伸手可达。壶内液面保持重力水平，随余量改变，边缘裁到实际内壁、内底或口沿，倾斜时始终限制在壶体内；补水、浇灌和取消动作的数量结算沿用原规则。

原角色每手19个蒙皮关节继续使用。原接触求解器把固定指根的接触也当作远端关节的阻挡，导致持镐四指不闭合。现在每个关节只检查它实际影响的蒙皮顶点，镐柄挂点按掌厚和指根前距校准；工具倾斜时握点、采矿接触位置和手臂可达检查使用同一套坐标。

验证同时检查四指末端弯曲、真实皮肤到柄的距离和穿入情况，并核对水壶源网格，避免再次把数学胶囊的接触误当作实物接触。

## 帧耗

刚性握柄相对手掌没有变化时复用已解算的指姿；半径、握柄位置、指姿或手部尺寸改变时重新求解。液体网格也缓存不变的水量与重力方向，静置、平移时不重复生成。移除林境每帧的层级遍历，并复用秘境视线检测缓冲区，避免同一提示重复查询。

本轮编辑器稳定握持的 CPU 测量从第37版约2.487毫秒降至约0.03–0.05毫秒，预热后托管分配为0。该数字只描述手部求解，不等同于整机帧率或 PICO 性能保证。实际检查和构建状态见[验证记录](VALIDATION_V038.md)。
