# v0.22 水面航路、海湾来信与居民美术

## 水面航路

船前出现带深青底色的珠白细线，每隔14米放置方向箭头，终点为浅青光环。与原水面共用Gerstner波形，沿波面起伏，亮度缓慢向目的地方向流动。抵达7米范围时收起长线，保留终点提示；下船、捕鱼和阅读时收起导览。

真实物理查询给船体留出1.8米水平余量和0.6米吃水。先尝试直达，不通时在4米网格上搜索；对每条边及简化后的路线再次做碰撞检测。泊位旁有桩或栈道时，在8米范围内选择可接近的水面。驶离路线10米后重新规划，沿途已走过的线不留在船后。箭头固定池为12个，没有每帧创建对象。

定位导航时发现捕鱼场景保留了原竞速关卡 `Logic/LevelBounds` 的三面围墙，四个外岛实际无法驶达。本版在当前捕鱼场景初始化时关闭这三面墙；岸线、石块、码头及建筑仍参与避障，原竞速预制体不改。

## 实体拆信

参考《集合啦！动物森友会》把居民来信作为可保存、重读的叙事物件；任天堂官方说明了居民邮箱与寄信互动。浮起、蜡封脱落、翻盖和抽纸的具体动画为本项目设计，未声称照搬某个游戏的动画。[参考来源](https://play.nintendo.com/news-tips/tips-tricks/animal-crossing-new-horizons-neighbors-tips/)

拆信约3.8秒，信纸使用暖色纸面、深色正文、署名和海湾抬头。按E可跳过拆封，读完按E/Esc收起；XR右手A跳过/收起、B关闭，按钮需要先松开再按。开启时固定信的位置，头显仍使用实际跟踪视角。

来信与维修记录照旧在成功交互时写入进度；展示、跳过和重读不产生第二次奖励。阅读复用故事模态守卫，收起手持图鉴及工具，清除桌面近眼身体遮挡；原告示牌在读信期间暂时隐藏，关闭后恢复其原可见状态。焦点丢失、暂停、救援和切换验收场景会关闭阅读。

## 居民和图鉴

五名居民使用Quaternius的真实头部与成品Peasant/Ranger服装，不用几何块拼人物。保留皮肤、眼睛、头发、衣料、皮带和鞋子贴图，合为单材质颜色/法线图集；近处约1.8万–2.3万三角面，远处约5500面。两级LOD按屏幕占比切换，源骨架摆姿后烘焙为静态模型。

前四种鱼的图鉴以前由圆角矩形画成简笔画，现在统一读取真实模型照片。四张临时照片由现有程序网格在Blender中用一致的侧视角和柔光渲染，完整保留鱼鳍与尾部；后八种继续使用用户原模型照片。自由资源检索中，Kenney Fish Pack是2D素材，Quaternius旧鱼包不带贴图，均不能直接补齐目前的画风。最终混元替换需求见 `HUNYUAN_V022_PROMPTS.md`；每条提示词103字以内。

## 资源再生成

按顺序执行，Unity编辑器保持关闭，使用项目既有版本和本地Blender：

1. `Tools/Art/build_v022_residents.py`：读取已保留的授权原件，生成五人的两级FBX、图集、头像、预览和 `ArtSource/V022/Residents-v022.blend`。
2. `Tools/Run-UnityValidation.ps1 -Suite FishingV022Art`：创建URP材质及居民预制体，导出前四鱼种程序网格快照。
3. `Tools/Art/render_v022_fish.py`：从快照渲染临时鱼图鉴照片。已有已验收GLB的同名鱼种会保留原导入器生成的照片。
4. `Tools/Run-V022Validation.ps1`：专项、回归、Windows构建及打包验收。

Blender工具通过 `blender --background --factory-startup --python-exit-code 1 --python <工具路径>` 执行，在独立场景中工作。当前Unity头像/缩略图应纳入Git LFS；不得将Logs、完整下载ZIP或构建目录提交。

照片导出不依赖Unity临时相机的背景渲染。开发中的空白导出已被像素检查拒绝；最终使用真实几何在Blender重渲染，并检查轮廓留白。
