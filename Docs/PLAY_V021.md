# 第21版：收线与取舍

Windows 入口：`Builds/FishingPrototype-v0.21.0/FishingPrototype.exe`。继续使用 v11 存档；原有鱼获、金币、图鉴、岛屿与秘境进度保留。

## 遛鱼

- 停船后抛竿，咬钩时点击左键提竿。斗鱼时按住左键收线，松开左键泄力；手柄右扳机收线，XR 继续使用左手摇轮。
- 每次抛竿的节奏和拉力略有不同，每轮挣扎也会变化。回气时收线、蓄力时准备松手、冲刺和跃水时泄力；只放线会脱钩，一直硬拉会断线。
- 珊瑚鱼和沙丁鱼收线距离缩短。金帆旗鱼至少搏斗20秒，后半段回气更短、反扑更密集，装备升级也不能跳过整场对决。
- 到船边后有 **10秒抄网窗口**。桌面松开左键、按 E 辅助抄网；XR 左握键拿网，覆盖鱼体后轻抬。自动泄力允许左手从卷线器换到抄网，但不会冻结倒计时。继续硬拉仍会断线。
- 入网之后仍需入箱或放生。已经入网的待处理鱼继续安全保存在存档中，抄网倒计时不会再影响它。
- 珍珠鱼、大体型鱼和传说鱼咬钩时使用更明显的水花、音效和桌面提竿反馈。XR 斗鱼震动随张力增强，持续反馈约每0.18秒一次，节奏切换时也会提示。

## 图鉴调查主线

J → 鱼获图鉴：右侧显示清单、下一条目标鱼、出没条件与调查航点。普通和珍珠变体都算，出售或放生后保留进度。

1. **浅湾调查**：珊瑚鱼、银沙丁、金线海鲷 → 开放北岛渔场。原有修复信标的开放途径仍然有效。
2. **水道调查**：飞梭鱼、青花鲭、星灯鱼 → 获得金帆旗鱼精确坐标。到飞梭水道，在夕照使用珍珠饵和至少一级鱼线，符合条件时必遇传说鱼。调查未完成时，原有40%传说咬钩机会保留。

青花鲭只在雨天出现在水道；星灯鱼只在夜间出现；斑点石斑需在涨潮时，且满足秋冬季或薄雾条件。日历显示涨落潮：00:00–06:00、12:00–18:00涨潮，其余时段落潮。鱼种条件在抛竿时确定，不会中途换鱼。原有天气对咬钩速度和珍珠率的加成继续生效。

调查是一组代表鱼种的收集目标。秘境、居民和群岛航记继续使用原有规则。

## 加速与升级

按住 Ctrl + W 加速；约8秒持续加速会过热，自动恢复巡航，冷却到25%后恢复加速。完全过热到解除锁定约9秒。松开Ctrl可提前冷却；刹车、倒航和离水状态不加速。桌面行动栏与XR控制台显示热量。暂停、背包、日志、对话、商店、手册和停船捕鱼时不积累或消耗热量；热量不写入存档。

**二级载重、二级动力、二级操控只能选择一项**，其他两项可购买一级。钓线、卷线器和甲板装饰独立升级。店内说明和购买按钮显示互斥状态，共享规则层也拒绝扣款。此版没有重选专精功能，请按主要玩法选购；旧档已买的多个二级升级全部保留。

渔获卡会突出首次发现和个人最大纪录；普通鱼放生后显示“已放生”，不再误报入箱和售鱼收益。原有最大重量记录长期保存。
