# 第24版试玩

启动 `Builds/FishingPrototype-v0.24.0/FishingPrototype.exe`。

- 按M展开航海图，“家”是金色标记，点击可导航至回潮渔屋的专用泊位。住宅移到港口西侧开阔水面，与港口鱼市、钓具店和渔场分开。超出当前地图范围时，标记显示在边缘；点击范围按钮可扩大视野。
- 靠近家的泊位，低速按G下船，沿独立栈道走到门廊，再进屋。床边按E休息至清晨。住宅、门廊、栈道、浮动鱼市和钓具店的基础有实体阻挡，船不能从底部穿过。
- 进入潮汐钓具店柜台范围，E与原美女店员汐禾交谈，2选择“介绍商品与装备”；对话中可查看商品。Tab直接打开商店，E/Esc关闭商店，Esc结束交谈。
- 店员介绍钓具和船舶升级、探索工具、制作补给及远航口粮；沿用原价格、购买和存档规则。头显使用现有“附近互动”与商店“店员介绍”入口。
- 在下方有真实陆地的高差边缘，可以直接走下或按空格跳下，由重力落地；墙体仍会阻挡。高岸下方无陆地时仍有边缘保护，低岸入水沿用游泳。

沿用第23版v12存档和个人进度。PICO实体操作和舒适度需另行实机试玩。
