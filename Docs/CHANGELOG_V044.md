# v0.44.0 改动记录

本版整合 Claude 已完成但未提交的 V044 开发成果，补齐中断时的必要收尾。基于已合并的 PR55，存档格式为 schema20；实际包版本为 0.44.0 / Android versionCode 44。

## 已实现的内容

- 绘本海岸界面：航海纸纹、深蓝与奶油色主题、手账/背包/地图/目标提示、VR 手账与手柄提示，保留海岸和渔村主题。
- 四境玩法：分阶段机关、变体、检查点、回响贝、逐级提示、风岛阵风/潮岛回灌/星岛观测，进度进入存档。
- 居民与叙事：带蒙皮和重定向动作的居民、头部注视、日程、中文对白与配音，以及实时开场/秘境/结局演出。修复居民朝向和 Interact 导入缓存。
- 交互：第一人称身体显露、工具握持、水壶拿取与井水动作；够不到时先挪到可达位置，再发生真实手部接触。VR 增加甩竿、抓取、曲柄与守灯手势。
- 海上生活：鱼群、漂流瓶、雾中灯语、鲸与海豚、夜光海、集市船与回信；守灯值夜、潮汐日历与退潮收藏；相机、照片图鉴、掌心地图、季节节日。
- 天空、特效与声音：日月、星空、月相、云层、室内避雨；传送门、机关和交互特效；音效与独立 Voice 混音类别。素材、许可、候选与积分沿用各模块账本。
- 移动端：PICO 质量档、固定注视点渲染、贴图压缩设置、草地合并/半密度版本、模型 LOD 和性能报告。

## 本轮补齐与修复

1. 接入已有混元古树、风车、沉船、灯塔，保留原始 GLB 与可编辑 Blender 文件；使用 1024 贴图及远景 LOD。风车叶片独立导出，继续使用原转动动画。灯塔按现有光源标记定位，并移除旧塔几何，保留庭院和守灯设施。
2. 修复 FBX 导出时把空物体局部坐标当作世界坐标的问题，保留传送门/爬梯等定位点。
3. 修复“幽灵陆地”：导航拒绝把高地内部当成水面，路径段检查地形高度，地形开放断面补实体碰撞。保留正常大陆，航线沿真实规划水道绕行，并重新烘焙地图。
4. 家园泊位移回水道中线，修复船体净空失败。
5. 古树使用连续封闭树干/树根碰撞，沉船清除过时舱室墙顶并保留甲板和跳板。行走测试加入“至少一个方向可退出”的断言，并在每一帧保持探测方向，避免被正常视角更新覆盖。
6. 恢复独立规则测试：工坊数据层不再引用 UnityEngine；补收海上事件纯逻辑；旧潮汐与雨天测试同步实际规则。音频专项等待真实挪步完成后检查打水阶段，仍核验水量、声音及取消行为。

## 验证与交付

详见 [交付、验证与遗留](VALIDATION_V044.md) 和 [VR 操作与实机清单](VR_CONTROLS_V044.md)。构建与截图证据以交付记录中的最终运行结果为准。Unity 编辑器、模拟头部输入和桌面计数不能证明 PICO 真机帧率、追踪或佩戴舒适度。

## 仍需后续处理

| 项目 | 当前边界 |
|---|---|
| PICO 性能 | 岛0/岛1等点仍可能超出150次绘制/30万三角面的目标；专项的850次/75万面只是防回退上限，不能当成72/90Hz达标。 |
| 穿插与近看美术 | 原报告205处交叠（不少为合理建筑咬合）仍需分级处理；商店、天文台、市场船尖刺面、NPC聚会站位及低头近墙需后续整理。 |
| VR 功能 | VR 相册页、握边/扫页、掀箱盖和双手交替爬梯未完成；控制器姿态手势仍需真机体验。 |
| 生活与居民 | 桌面相册/取景框尚缺最终人工画面确认；掌心地图对比度、节日聚会形态和林舟晚间码头站位有待调整。 |
| 声音 | 集市船专用循环/成交声与部分候选逐条试听未完成；音频数值检查不等于主观好听。 |
| 天空与启动 | 云形仍会重复；启动阶段停顿、实测与估算绘制差异、小地图安卓压缩效果需要进一步实测。 |
