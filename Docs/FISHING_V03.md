# 怪鱼航线 v0.3 — 海湾探索

更新：2026-09-27。基于 v0.2 原地迭代，保留旧版构建。交付目标是 Windows 可玩的第三版及 PICO 适配基础，**不是已验收的 PICO APK**。未引入商业游戏素材或新付费依赖。

## 体验变化

### 让每次出航有目标

- **港口委托**：海湾早餐（珊瑚鱼 + 飞梭鱼，奖金 24）、远航补给（飞梭鱼 + 鼓鼓鱼，奖金 32）、海岛盛宴（三种鱼，奖金 50），依次循环，没有限时压力。
- 集齐后返港按 E，领取鱼货原价和额外奖金；优先消耗普通鱼，保留不需要的货物。未集齐时 E 为普通出售。O 可直接尝试提交订单。
- **航海日志 / 图鉴**：J 打开并暂停世界；三种鱼的普通与珍珠变体分别收录。记录售出后保留；日志显示栖息地、拉锯建议、累计捕获和订单进度。
- **鱼饵策略**：B 循环切换。均衡饵为 12% 稀有率；舒缓饵张力增长 -20%、收线速度 -15%；珍珠饵稀有率 25%、张力增长 +18%。鱼饵免费、不消耗；单次捕捞开始后不能中途换饵。
- **可读的拉锯**：每种鱼循环回气、蓄力、冲刺。回气时收线更有效，冲刺时张力上升更快；飞梭鱼节奏快，鼓鼓鱼冲刺强。UI 用文字说明，不只靠红绿色。
- **航点提示**：N 切换港口与三个渔区，显示距离和相对船头方向。它是方位提示，不是避障路径规划；仍需沿水道航行。

### 场景与表现

- 原创灯塔、灯笼、补给桶、栏杆等港口细节。
- 三处渔区增加海蚀礁石、珊瑚式枝条、不同颜色与横杠数量的航标；不靠颜色也能辨认。
- 四只低成本远景海鸥，不增加动态灯、粒子群、反射摄像机或鱼群物理。
- 静态装饰按区域和材质合并；包括原市场主体，总计 **26 个合并 MeshRenderer / 34,627 顶点**。这不是整场景总 draw call 或总顶点数：原岛屿、水面、文字和 LineRenderer 不包含在内。
- 渔区装饰超过 240 m 暂停显示，每 0.4 秒检查；新增合并装饰不投射实时阴影，保留受光。灯塔不做远距隐藏，用作港口地标。
- 新礁石是无碰撞的视觉装饰，不是完成的实体岛礁；布置在原 9 m 标记圈外，保持原有市场实体碰撞。

### UI 与舒适性

- 统一海军蓝底板、米白正文、薄荷绿状态、金色奖励。常驻内容分为品牌、航向、资产，底部只显示当前操作。
- HUD 适配宽高安全区，新增图鉴弹层与暂停设置。H 收起辅助信息。
- 暂停菜单可切换舒适航行、世界空间仪表预览、捕鱼提示音。舒适设置和静音设置保存在本机，不写入测试存档。
- 舒适航行默认开启：推进和转向输入缩至 65%，桌面垂直波动采用更慢的平滑；保持无主动横滚、无头部摇摆、无速度 FOV。
- 世界空间仪表约 0.97 m 宽，参考距离 2.4 m，锁定船上水平参照而非锁定头部。它是**只读仪表预览**，没有手柄射线交互。当前使用内置拉丁字体，显示英文；中文头显字体资产仍待接入。

## 存档与旧版兼容

- 路径和文件名仍为 `Application.persistentDataPath/boatattack-fishing-v1.json`，内部格式升级为 `version=2`。
- v1 可迁移金币、鱼线等级、鱼箱和已处理 ID；仅补录鱼箱内的发现。旧版没有保存已经卖掉的鱼种，不能凭空还原历史图鉴。
- v2 增加发现位图、累计捕获、完成订单数；校验范围、库存/图鉴一致性和交易价值。
- `.bak` 备份恢复逻辑保留。第三版写入 v2 后，第二版不能直接读取该新格式；需要回退玩法时，应先保留 v1 存档副本，不能把“保留旧 exe”理解成存档双向兼容。
- 自动试玩使用临时测试存档，不读写玩家正常进度。

## PICO 4 Ultra：本轮做了什么

1. 活动 XR 时禁止桌面 HUD 和桌面相机姿态/FOV 写入，包括启动阶段；不强制 60 Hz，由 XR runtime 决定显示节奏。
2. 只读 World Space 仪表可供后续座舱使用；不假装它已经是 XR Origin。
3. 水面深度、不透明颜色、WaterFX 纹理改为 XR-aware 数组采样；补全水面片元和两种 WaterFX pass 的 stereo/instance ID 传递。
4. WaterFX 使用可采样的非 MSAA 目标并绑定数组切片。
5. 旧平面反射是单眼纹理，立体相机跳过该额外摄像机并回退环境反射探针；单眼全屏焦散暂不在立体相机绘制。
6. 保留桌面专用色调映射；XR 激活时关闭这一后处理。

**仍未完成**：PICO 4 Ultra 固件 / SDK 支持矩阵核对、loader、XR Origin、座舱跟踪基座、真实手柄抛竿/收线/抄鱼、中文世界空间 UI、Android ARM64 APK。项目旁的 PICO 6.1.1 目录没有被盲目导入或安装。现有通用 XR 输入不等于本版捕鱼工具已经支持头显操作。

## 设备验收门槛（不能由桌面截图代替）

- 先在官方兼容 SDK 的最小场景确认真实 6DoF 与双手追踪，再接入捕鱼。
- 使用目标设备实际支持并选择的刷新模式：例如选择 72 Hz 时每帧预算 13.89 ms；选择 90 Hz 时 11.11 ms。这是预算换算，不是宣称设备支持矩阵已核实或当前游戏已经达标。
- 分别测量 CPU / GPU 帧时、持续 20 分钟温度与帧率、动态分辨率、Multiview 和固定注视点渲染，不同时盲开所有选项。
- 左右眼逐项检查水面折射、反射探针回退、岸线深度、泡沫、鱼线与仪表；确认无单眼消失、错层、抖动或重影。
- 坐姿、站姿、重置朝向、系统暂停/恢复、单手失追踪、头显摘戴、突然转弯/刹车都要实测。
- 根据体验再选择稳定座舱、限制加速度、转向方式或传送，不能直接把船体横滚/俯仰写给 HMD。

- Windows：`Builds/FishingPrototype-v0.3/FishingPrototype.exe`，与相邻 DLL 和 Data 文件夹一起保留。
- 验收命令和证据见 TESTING.md；自动检查不代替真人键鼠手感、平衡性与头显测试。
