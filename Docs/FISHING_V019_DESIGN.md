# 第19版：潮汐回响

2026-10-11开始开发，2026-10-12完成桌面验收（北京时间）。基于第18版群岛航海、捕鱼、制作和存档系统。

## 本版范围与实现顺序

- [x] 钓艇转向：基础目标角速度从45–26°/s提高至60–38°/s；升级继续叠加，高速收敛和船体稳定约束保留。
- [x] 商店：替换重复盒子陈列，展示真实航海工具、食品、材料及船用物件；商店、背包、日志统一深海蓝与黄铜色视觉。
- [x] 四岛：风铃岩湾与瞭望台、潮林营地与蘑菇林、沉船打捞场、星象石阵；可辨认轮廓、植物和设施。
- [x] 六位居民：四岛居民、码头领航员、钓具店店员；分支对话、剧情和实用信息，线索收录航记。
- [x] 地区表现：抵达地区时名称、副标题和纹章渐入渐出；秘境进出有短暂淡出，安全落地后恢复控制。
- [x] 四座可进入秘境：风铃顺序、林间明暗、货箱与水闸、星象棱镜；独立房间、实体门、机关状态反馈、一次性奖励。
- [x] 自由移动：游泳与靠岸、可攀登的绳梯；统一体力与休息恢复，碰撞和救援继续可用。
- [x] 新存档v11：继承v10，旧档保留；NPC认识、秘境完成和终章奖励永久去重。
- [x] 纯规则测试、Unity专项与旧玩法回归、Windows构建、两种比例的Player截图。

## 世界观与探索循环

海湾曾由“潮汐守望者”维护四条航路：风、林、潮与星。大风暴损坏地面航标，也让存放航路记忆的四处秘境沉寂。玩家作为新任领航员，可以捕鱼赚钱、搜集物资、升级船舶，向居民打听航路，进入秘境取回四段回响，最后回港向领航员报告。第18版来信、寻宝和信标继续独立存在，探索顺序自由。

每座秘境首次完成奖励90金币；四座完成后由港口领航员给予180金币，所有奖励只支付一次。机关错误不扣钱。中途离开可重新挑战；已完成秘境仍可再次进入参观。秘境内救援直接返回港口，不遗留室内状态或冻结输入。
