# v0.21 PR 审查

What this change does: 本版让每次遛鱼的节奏和拉力有所变化，为传说鱼保留至少20秒的对决，并给抄网设置10秒窗口。图鉴调查连接北岛渔场和传说坐标；天气、昼夜与潮汐决定部分鱼种是否出现；加速会过热，二级船舶升级需要三选一。

审查基线为 `bc8d0d8b`，范围是 `feature/v021-fishing-tension` 的本版代码、调用入口、测试和说明。按单人本地游戏、最多10条鱼货和12种鱼评估；不假定多人联网或服务器并发。开发前已有的美术、导入和XR项目设置改动不纳入本版提交，项目设置只提交版本号。

## 审查中修复的问题

1. **高张力抄网失败后无法重试** — `Assets/Scripts/Fishing/FishingCatchRig.cs`、`Assets/Scripts/Editor/FishingV021Validation.cs`

   网口判定原先只检查 Landing 阶段。玩家在高张力时覆盖并提网，网口已记为捕获，但新增的结算规则拒绝这条鱼；之后网口不再发出捕获事件。现在网口也使用 `Session.CanNet`，张力降低后可以重新覆盖、提起并正常结算。Unity 用实际网变换验证了先拒绝、泄力后重试、测量放生，以及奖励只发一次。

2. **实际 XR 控制台遗漏新规则提示** — `Assets/Scripts/Fishing/FishingDockConsole.cs`、`Assets/Scripts/Fishing/FishingXRNotebook.cs`

   原改动把热量和倒计时写进了桌面世界仪表，而该仪表在头显模式下隐藏。实际 XR 控制台仍显示旧提示，北岛开放也只检查信标。现已接入热量、过热冷却阈值、剩余抄网时间和图鉴解锁；XR 日历补上潮汐。Unity 组件断言检查实际生成的控制台文字，航点回归也改用统一的渔场准入规则。

3. **XR 状态文字被区域高度截断** — `Assets/Scripts/Fishing/FishingDockConsole.cs`

   新增的完整状态在实际字体下需要210像素，旧区域只有196像素。现增加文字区域高度并下移按钮及提示区，保留原字号；组件断言确认状态文字适合区域。控制台按钮仍使用其实际碰撞体进行射线回归。

## 已核对的行为

- 斗鱼节奏由每次捕获ID产生，不同种子可复现且确有差异；非有限时间不会推进计时。小鱼更快完成，升级也不能跳过传说鱼最低对决时间。
- 物理网口、桌面辅助抄网和捕获结算共享张力条件。抄网超时不产生鱼获；已入网的待处理鱼仍沿用持久化结算。
- 调查从永久图鉴发现位推导，普通和珍珠变体均计入。出售、放生和重载不清空调查，原信标解锁路径保留。
- 冲突的二级购买在共享交易层拒绝并保留金币，港口、商店和XR入口使用相同规则。旧档多个二级升级不被撤销。
- 加速热量作用于真实船体推力；菜单、暂停和停船时不推进热量。旧存档格式继续为v11。
- 没有新增依赖、并行任务系统、独立调查存档或装备重置流程；核心计算与鱼种表规模固定。
