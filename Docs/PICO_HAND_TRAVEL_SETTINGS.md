# 手部对齐、跑图速度与退出设置

来自同学的 PR #59（原提交 `656b36ea`，含 `c0b67038` 的 XY/创造更正，本轮冻结到 `f9ec22f8`，基于 v0.52.0）。2026-10-31 整合至 v0.55.0，与 PR #60 的家园/集市改动及 0.53 日期与物资功能共存。整合验证见 [VALIDATION_V055.md](VALIDATION_V055.md)，提灯更新见 [PICO_LANTERN.md](PICO_LANTERN.md)。

- 手部：按角色的水平前方轴在身体 XY 平面修正左右侧倾，再转换为左右掌模型坐标。控制器指向变化不会改变校准轴，船体摇晃也不改变参考倾角。使用新的 XY 偏好键，避免继承旧局部轴的校准值。保持原有追踪位置、手掌偏移和持竿/工具共享掌坐标；实际握感仍需佩戴确认。
- VR 手册 → 设置 → 手部/退出：左右手分别以 5° 步长调节，可反向调整、清零或恢复 +30°；范围 ±90°，自动保存，也可校准眼高或进入退出确认。手册收起后观察实际握持效果。日期与物资继续保留独立入口。
- VR 步速三档 1.3 / 2.2 / 3.0 m/s，默认中档；疾跑继续乘 1.7。保留现有摇杆加速、碰撞、蹲行和追踪门禁。桌面步行 3.4、疾跑 5.8 m/s。
- 船的动力与前进限速参数统一乘 1.3，保留升级层级、刹车、倒航、加速和舒适航行规则；这些是参数调整，不代表实测航速必然同比增长。
- 桌面设置底部增加二次确认退出，VR 设置增加独立确认页，可取消。统一调用保存与退出；活动槽保存失败则保持游戏打开。未入箱鱼获不自动发放。编辑器中只停止播放，独立程序中退出应用。
- 创造模式：桌面设置顶部可切换；VR 设置中的“创造/帮助”进入独立页。开启后钱包显示 ∞，购买免金币扣款；真实钱包不被替换，关闭恢复正常收费，重启默认关闭。容量、解锁、互斥及重复购买限制保留；获得的物品和升级正常保存，游戏奖励照常计入真实钱包。
