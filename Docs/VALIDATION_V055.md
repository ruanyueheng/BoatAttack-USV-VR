- PR #60 的萝卜双子叶幼苗、种子袋、奶油墙面、五类动物住所与活动、菜园和商船实体碰撞、商品价格和 A 键购买、动态商品牌与文字深度修复均保留。美术与家园代码保持不变，集市仅增加创造模式支付和 ∞ 余额呈现，完整场景回归再次通过。旧版说明见 [VALIDATION_V054.md](VALIDATION_V054.md)。
- 日期与物资仍使用第 34 页、设置中的独立入口。PR #59 原本也使用 34 页，现将手部对齐分配为 35、退出确认为 36、创造模式为 37，避免互相覆盖。
- VR 设置右下角“手部/退出”进入手部校准；该页提供左右手独立 ±5° 调节、清零、恢复 +30°、眼高校准、退出游戏及返回设置。退出页可取消或返回首页。校准和退出时，左页状态不会因指向按钮而被隐藏。
- 按角色水平前方轴在身体 XY 平面修正左右侧倾，控制器指向变化不会改变校准轴。左右掌模型转换前应用补偿，持竿和工具沿用同一掌坐标；范围 ±90°，拒绝 NaN/无穷值，自动保存。采用新的 XY 偏好键，避免继承旧轴的校准值。
- 创造模式通过桌面设置顶部或 VR“创造/帮助”切换：显示 ∞、购买免金币，实际金币仍保留。关闭恢复收费，重启默认关闭，容量/解锁/互斥/重复购买规则仍有效；获得的物品和升级正常保存，奖励正常计入真实金币。切换存档不会改变本次会话的开关。
- VR 步速为 1.3 / 2.2 / 3.0 m/s，默认 2.2，疾跑倍率 1.7；桌面步行/疾跑为 3.4 / 5.8 m/s。船动力与前进限速参数乘 1.3，升级、左握把加速、刹车、倒航、舒适模式及 0.53 船体竖向阻尼保留。参数增长不代表实测航速同比增长。
- 保留 PR #59 的统一保存退出，并补齐暂停菜单仍直接退出的旧路径。保存失败时保持游戏运行，包括原槽不可用的情况；取消或关闭设置会清除旧确认状态，避免下次一次点击误退出。退出页和桌面设置可见保存错误。
- 综合回归发现旧手柄说明的新增长文字超出详情区，现仅在说明页使用页内剩余空间并在 22–20 字号间适配，保留完整按键说明。
- 提灯更新同时保留：腰间灯换工具、采集和整理背包时继续照明；岸上左扳机/桌面 L 独立开关，右握把从实际提环拿起，松手挂回，手持灯保持竖直。船上左扳机仍刹车，游泳/攀爬/登船隐藏灯体并停止照明，切换航程或失去最后一盏灯会清理灯光。两盏无阴影实时灯沿用原 PICO 灯光预算。相机/望远镜提示与日期页关闭处理均保留。
