# 第27版 · 海岛手册与灯塔家园

2026-10-15，版本 0.27.0。UI 沿用已确认的奶油纸张、手写标题、海岛插画和深海绿墨色；现有渔屋重建为赤陶瓦顶、旧木板外墙、百叶窗、阁楼窗、烟囱与门廊的海边木屋，并加入可登岸的小岛、灯塔、山坡、岩岸和木码头。

## 进入新家园

在导航中选择「回潮渔屋」，航行至现有泊位后低速登岸。沿码头进屋，床、收音机、海图书桌、灯光开关和工作台/熔炉/锻造台继续使用原有交互。屋内区域、旧设施坐标和制作交易保持兼容，没有重置金币、背包、鱼箱或主线进度。

岛屿与屋外环境参照提供的插画制作，保留灯塔、草坡、沙径、岩岸和海边木屋的结构。房间按游戏原有 12×10 m 的可活动区域保留；单图不可见的背面依据玩法补建。海水和玩家船仍由现有游戏系统绘制，没有烘焙进模型。

## UI

- 常驻信息继续保持小面积；背包、图鉴、商店与事务页按需打开，不在窗口四边铺满面板。
- 桌面 HUD、背包/制作、日志/图鉴、商店、日历与故事卡统一为奶油纸面和高对比墨色。
- VR 手册各功能页使用同一纸册框架；物品照片、材料数量和完整悬停说明仍连接现有数据。航海图扩大显示区，右侧为航点列表。
- 右手 B 打开/关闭手册，右手射线配合扳机选择。纸册保持 World Space，并保留双手追踪、失焦、关闭后摇杆回中和世界操作门禁。
- 共享按钮样式提供 Normal / Hover / Pressed / Selected / Disabled；页面有 120 ms 的轻微出现反馈。海面航线不会覆盖纸面文字和按钮。

## 周围地形

原独立岩壁 LargeCliff03 与新岛东侧挤在一起，已在游戏运行时定向清理，并将对应的一小块旧地形底座降至海面以下。使用 TerrainData 运行时副本，原始场景与地形资产没有被破坏；退出时恢复。

该区域原有的玩家设施会迁到新岛的平整空地，保留设施编号、已预付材料、待领成品和加工进度；已经站在新岛上的设施不会反复迁移。清理区域继续避开命名的登陆/调查点。主岛、商店、其他钓场、登陆点和调查进度保留。水深和航海图均同步新增岛屿与清理结果，地图包含钓具店。
