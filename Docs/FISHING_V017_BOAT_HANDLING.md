# v0.17.0 · 稳定航行、甲板夜灯与手动昼夜

## 问题复现与修复

第16版旧船在持续转向复现中最大倾斜约47.43°，测试末速度仅0.0064m/s。新船壳自动计算的惯性轴偏离船体轴；Unity的旋转约束以惯性轴为基准，原来的横倾/纵倾锁定仍会让转向逐步倾斜。舷外机原采样点仅在船体坐标Y=-0.20m，而船浮起时根部约在Y=0.40m，造成动力频繁中断。旧转向还施加了赛艇横滚力矩。

钓艇专用的稳定模式将惯性轴对齐船体，保持原横倾/纵倾约束，保留水面升沉与碰撞；推进不再施加抬头力矩，转向仅沿竖直航向轴，并随速度降低目标转向率。增加侧向水阻、7m/s前进动力渐减与既有4m/s倒航上限；真实凸船壳使用零摩擦接触材质，靠碰撞阻挡障碍，支持接触后倒船退出。舷外机轴长与实际推进采样点一起调至船体Y=-0.70m，入水判定带迟滞；船壳仍在水中时，短暂出水最多维持0.6秒动力，完全离水后仍停止推进。

原赛艇和AI仍使用已有模式。这里的稳定模式只在单人钓艇预制体开启。

Unity关于约束基准的说明：[Rigidbody.constraints](https://docs.unity.com/en-us/engine/6000.0/script-reference/unityengine/rigidbody/constraints)。项目实际采用Unity2022.3，并以本地运行复现和专项测试确认影响。

## 模型与灯光

船体使用不透明材质。旧船“透明”来自独立内壁的法线朝外，内部观察时背面被剔除。新模型把外壁、舷沿、朝内的内壁和船底连接成闭合厚壁网格；生成时检查流形边和内壁法线，Unity导入后再次检查内外壁。补充船内肋条、船首储物板、舷外机安装架/螺旋桨和甲板灯，仍为一个合并船模、4,906三角面。

船尾侧安装一个暖色点灯，5m局部照明、无额外阴影。灯随真实日历的日照因子在黄昏渐亮、白天关闭，照亮船底和附近装备。船舶素材检索、许可证与取舍见[素材比较](BOAT_ASSET_RESEARCH_V017.md)。

## 使用

- 桌面：`J 日志 → 日历`，选择“白昼08:00”“夜晚21:00”或“自动流逝/时间固定”。
- PICO：`B 潮汐手册 → 日历/预报`，用右手射线和扳机选择同样的操作。
- 时间选择推进真实日历，可能进入次日；日历时间不倒退，夜间鱼种、动物恢复和环境同步。固定/自动状态随现有存档保存。
- 钓鱼等待、搏鱼或有未处理鱼获时禁用时间修改，避免更改正在进行的鱼获条件。普通岸边休息仍沿用原规则。
- 航行操作不变：W前进、S倒航、A/D转向、Shift减速；实物障碍仍需倒船或绕行。

重新生成船模：Blender后台执行`Tools/Art/generate_solo_skiff.py`；重新生成预制体：`Tools/Run-UnityValidation.ps1 -Suite FishingSkiffBuild`。完整复现入口：`Tools/Run-V017Validation.ps1 -Capture`。
