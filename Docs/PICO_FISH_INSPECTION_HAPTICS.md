# PICO 鱼获检视与反馈

- Unity 2022.3.62f1，沿用当前模型与存档格式。
- 鱼钓起后，左手靠近活鱼握住左握把拿起；已入网或在托盘上的鱼也可再次拿起。
- 头显检视采用左手夹鱼器：手指握住橡胶柄，金属夹爪连接实际鱼嘴，鱼身在手下方垂直悬挂。手柄随手腕转动，夹口带动鱼移动，鱼通过转接头保持重力下垂并轻微挣扎；不再把鱼身侧面当掌心握点。
- 把鱼移到抄网口，松开左握把放入抄网；松在其他位置会安全放到托盘。按 A 也可将手中鱼放入网，再按 A 存入鱼箱。
- 左手持鱼时隐藏收获面板，避免面板拦截实体抓取；失去跟踪、暂停会安全收起鱼，不自动丢弃或重复发奖。
- 头显竿身按“竿尖 → 实际鱼/浮标”的拉向弯曲，收线有预载，张力增加时曲率加深；松轮后平滑减载。手柄与鱼轮不变形，鱼线从最终变形竿尖发出。桌面原有受力算法保留。
- 统一震动强度乘 1.7、时长乘 1.5。强度最高 0.95；拒绝非法值，仅对支持震动且应用在前台的手柄发送。
- 覆盖鱼竿咬钩/搏鱼、抓鱼、枪械、猎矛、采集、果树、工坊、相机、机关及菜单触碰等已有反馈。左手持活鱼时增加有间隔的挣扎反馈。

验证包含原桌面抛竿/搏鱼/入箱回归，以及模拟手柄姿态下实际渲染手掌到夹柄的距离、夹口到鱼嘴距离、夹口实体几何、翻转手腕后鱼头朝上、松手回网/托盘、再次抓取与同一鱼获只结算一次检查。竿弯专项覆盖低张力收线、拉力增加、松轮减载、握柄旋转后跟随世界线向、暂停/非法值、卸载及鱼轮固定。FishingLantern 的震动倍率及非法值断言沿用。

实际握感与震动效果需要佩戴头显体验。
