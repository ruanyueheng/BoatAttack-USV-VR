# PICO 卖鱼、免费升级与望远镜

Unity 2022.3.62f1，沿用 v0.52.0 项目和存档格式。

## 卖鱼

- B → 首页“卖鱼与委托”，可以查看鱼箱货值和两处交易点导航。
- 将船停在潮汐渔港的青色港圈内，或上岸进入潮汐钓具店，走近女店员柜台后交易。商店增加“鱼货回收”招牌，店员对话也有卖鱼入口。
- 普通出售保留委托所需的鱼；“全部出售”包含委托鱼。两种操作均需再次点击确认。离开交易点、暂停或鱼货变化时不会沿用旧确认直接成交。
- 钓起的鱼先从手/抄网存入鱼箱；背包里狩猎肉类不是鱼箱鱼货。
- 桌面商店底部也有卖鱼确认按钮，原港口交易保留。

## 创造模式

- B → 设置 → 创造模式 / 航行帮助，开启后点击免费升级卡片，包含甲板、发动机、舵、鱼线、鱼轮和载重。
- 真实钱包不被改成巨大整数，购买与升级不扣真实金币；开关保存在本机，重启或覆盖安装后仍记住。
- 创造模式可以在安全位置直接升级。暂停、对话、游泳/攀登、检视、未处理鱼获等情境仍阻止交易。满级和二级船舶专精互斥规则保留。

## 望远镜

- 装备望远镜，双手按住握把，将实体镜筒举到双眼前，通过后目镜观察。移开、松握或换装备会退出，不再用按键显示头锁放大窗。
- 右摇杆上下调节 2–8 倍，A 记录面前的动物。只有真实镜筒目镜显示光学远景，头显主视野和追踪投影不变。光学相机只在双手握持且目镜对准眼睛时工作。
- 装备望远镜时，举手拍照的相机手势不再抢占望远镜。

测试使用隔离存档和模拟姿态/图像目标；真实头显的视舒适度、画面清晰度与帧率仍需佩戴验收。
