# 第43版：旧档兼容与浇水音效整合

本版包含 [第42版内容](PLAY_V042.md)，并整合同学的 [PR #54](https://github.com/ruanyueheng/BoatAttack-USV-VR/pull/54)。人物仍保持原配色。

- 浇水、补水循环走“音效”音量，降低“环境”音量不会连带静音；短水流有更快的起声和收尾。继续使用已归档的真实水声，没有新增生成素材。
- 修复第42版把正常旧档误判为损坏的问题。第40–41版的八项动物冷却记录会在内存中补齐到当前长度；读取不会修改旧文件，正常保存时才写入当前格式并保留备份。第42版已有的新档也可以继续使用。
- 第42版的野外补给箱、袖口与低头修复、目标卡、鱼缸、家具和剧情镜头均保留。

Windows正式存档位于 `%USERPROFILE%\AppData\LocalLow\UnityTechnologies\BoatAttack\`。文件名中的 `boatattack-fishing-v13.json` 是沿用的存档基础路径，**不是游戏版本号**；三槽手动/自动记录分别附加 `.slot-N.manual.json`、`.slot-N.auto.json`，备份为 `.bak`。安装包目录变化不会搬走这些文件。

遇到旧档问题时应先备份整个存档目录，再运行本版读取已有槽；不需要手动改JSON，也不需要用新航程覆盖旧槽。当前存档格式仍为19，降级到旧程序前保留备份。

本地Windows ZIP、ARM64 APK与审阅/验证结果见 [第43版审阅记录](REVIEW_V043.md)。
