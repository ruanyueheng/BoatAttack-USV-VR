# v0.62.0 VR工具与课堂演示修复

2026-11-03，基于c76bc7ab的0.61.0。使用Unity 2022.3.62f1，保留旧存档格式及现有PICO画质。

本版改动与使用方法：

1. 掌心地图展开和收起动画期间隐藏左手按键提示；相机道具、取景框和望远镜近眼展示时隐藏提示，放下后恢复。
2. 已确认此前ADB恢复的外部相册属于shell且无其他用户访问权限；保留照片并修正该设备目录访问。新版Android照片保存到应用内部目录，按航程无损复制旧照片并保留原件，失败可回读和重试。写盘成功后才结算，不申请相机或广泛存储权限。
3. 锯木改为可见木料范围与实际锯齿接触，支持沿锯身方向的短距离推拉与斜持；仍需握把握住，空中、倒齿、失追踪和离开锯缝不计进度。
4. B → 设置 → 手部角度；VR舒适页也有手部角度入口。支持左右各±5°、清零、恢复默认30°、校准眼高，沿用自动保存。
5. B → 主线剧情。显示当前目标与剧情顺序，点击追踪主线标记当前目的地；首页无临时消息时也显示当前主线。林舟任命 → 家中旧海图 → 四境回响 → 远航罗盘 → 白帆拱湾。
6. B → 设置 → 创造模式。金币、普通材料、燃料、种子和壶水免耗，覆盖配方、四类手作、熔炉、种植、设施、饲喂和诱捕。动作、背包容量、蓝图、每日次数和主线遗物条件保留；真实销售/交付仍移走实物。零鱼箱也可在烧烤架练习，保留真实鱼获，完成领取1份烤鱼；练习计时不写入存档，读档、切换航程或重启后需重开，真实烤鱼继续保存。
7. 修正0°下铲子向右伸出的局部握持朝向，并将握点从-0.155m改到模型真实D柄横杆-0.200m；不修改全局掌心偏移或用户角度。核查中还修正猎矛强制覆盖握持姿态的问题。切换航程会清空旧相册缓存。
