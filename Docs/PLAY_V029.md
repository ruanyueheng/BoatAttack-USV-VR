# 第29版 · 海风里的收获

2026-10-16，版本0.29.0。延续第28版存档、家园和手册界面。

## 试玩

- Windows：[完整便携包](../Builds/FishingPrototype-v0.29.0-Windows.zip)。解压后运行FishingPrototype.exe，保留同目录数据文件。
- PICO：[ARM64安装包](../Builds/FishingPrototype-v0.29.0-Android/FishingPrototype.apk)。

## 十二项改动

| 项目 | 第29版行为 |
|---|---|
| 左键钓鱼 | 修复桌面每帧关闭VR手册导致抛竿蓄力被清空。到钓点按E驻钓，轻点左键近抛，按住再松开远抛；咬钩时左键提竿。 |
| 自然手册 | 统一位置和旋转的参考方向，缩小至手册实际尺寸；双手从两侧托住，抬头和低头保持手物连接。 |
| 新模型 | 用户的兔、狐替换岸上相应动物；海龟替换水面及海洋鱼种中的海龟；海鸥替换飞行与俯冲捕鱼的旧模型。原陆龟保留，海龟不会在陆地上充当陆龟。 |
| 西湾三工坊 | 工作台、熔炉、锻造台均保留并补齐旧存档缺项。增加小标牌；近距离看向设施时，互动键优先打开设施，避免被熔炉前的维修记录抢走。 |
| 海洋游动 | 随机选择水域目标，平滑转向，穿插停留，检查前方障碍并限制活动水域；蟹、龙虾、章鱼缓慢活动，快鱼更快。 |
| 钓点生态 | 浅湾以珊瑚鱼、蝶鱼、海鲷、海马、海龟为主；水道偏鲭鱼、金枪鱼、鳐鱼与乌贼；深水礁区偏石斑、狮子鱼、章鱼、龙虾与灯笼鱼；北岛偏沙丁鱼、海鲷、海龟及夜间水母。鱼类仍遵守昼夜、季节和潮汐条件。 |
| 跃水 | 各钓点分别安排附近鱼类跃水，等待主要在玩家附近计算；优先选择视线前方，起落有水花，跃出约1.5米，持续约1.65秒。局部事件留有间隔，雨天减少活动。 |
| 望远镜 | 桌面F举镜，滚轮以0.5倍调整，范围2–8倍；显示当前倍率。举镜时滚轮用于调倍，放下后恢复切换快捷栏。第三人称保持普通视野。 |
| 提灯 | 暖色近光加柔和地面散光，微弱烛火变化、桌面柔和遮挡与灯窗发光；调整近距离曝光。腰挂继续照路，PICO使用两盏局部灯并关闭实时灯影。 |
| 烤鱼 | 重建为有厚度的整鱼，包含圆润鱼身、鱼头、双侧鱼鳍、分叉尾、炭烤划痕和柠檬；烤架、背包图标及手持共用新模型。 |
| 所有物品检视 | 43种非空背包物品均可实际拿起。桌面Z检视快捷栏物品，按住右键转动，Z/F/Esc收起；背包选中物品后点“拿起检视”，储物区物品也可直接检视。检视不消耗物品，也不会触发食用、放置或开枪。PICO从背包装备后可用实体手柄拿着观看，右扳机收起检视，再使用物品。 |
| 钓获反馈 | 鱼一入网就显示醒目的“钓到了！”框、鱼种、重量、新发现/纪录及后续按键，伴随音效和粒子；入箱或放生后显示实际结果。VR待处理面板同步使用钓获标题。 |

## 模型与存档

四个原始GLB逐字节复制到ArtSource/V029，桌面原件未修改。Unity资源位于Assets/Resources/FishingV029；每种动物3500三角面，保留UV并另存1024像素原色贴图，以满足既有海洋模型预算。烤鱼为项目新建模型。

沿用boatattack-fishing-v13.json及既有迁移路径；不清空物资、鱼箱、制作队列或工坊。进入新版后正常保存。

## 设计参考与验收边界

参考[Sea of Thieves官方钓鱼介绍](https://www.seaofthieves.com/news/fishing-in-sea-of-thieves)对区域鱼类和钓获奖励的组织，以及[Minecraft官方提灯介绍](https://www.minecraft.net/pt-pt/article/taking-inventory--lantern)中的实用灯光定位。提示框排版、随机游动和暖光参数为本项目设计，没有照搬游戏素材。

验证记录见[第29版验收](VALIDATION_V029.md)。桌面真实鼠标事件通过隔离的Unity输入环境验证；这不等于实际玩家长时间游玩或PICO真机测试。2–8倍光学视野为桌面功能，未修改头显投影参数。
