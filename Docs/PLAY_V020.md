# 第20版：海岸重塑

Windows试玩：`Builds/FishingPrototype-v0.20.0/FishingPrototype.exe`。本版沿用第19版v11存档，捕鱼、钱币、升级、来信、居民及秘境进度继续保留。

## 船只操控

- W / ↑ 前进，A / D 转向；S / ↓ 倒航。
- **前进时按住 Ctrl 加速**，松开恢复巡航。加速需要同时给前进油门，不会自动前进；Shift刹车优先，倒航不加速。
- 手柄使用右肩键加速、左肩键刹车；PICO使用左摇杆前推并按下加速、左扳机刹车。
- 船的基础转向目标从60–38°/秒提高到84–54°/秒，转向响应系数4.8→6.6。航速越高转向越收敛，原操舵升级继续叠加。
- 加速使用1.65倍推力及1.35倍前进速度上限，仍由水面物理和船体阻力决定实际速度。舒适模式继续降低油门和转向输入；没有燃油或加速体力条。
- 停船捕鱼、岸上移动、暂停、背包、日志、对话、商店或手册打开时不会给船加速。

## 四岛外观

四座岛重新建模为连续海岸，湿沙、干沙、草地与沙径平滑衔接。木板栈桥有独立木板、桩柱和绳栏；沉船沙洲与星望岛移动到西南、东南开阔海面，航点与地图同步更新；原登陆、来信、宝箱、信标及秘境互动点继续可达。

| 岛屿 | 本版造型 |
|---|---|
| 月牙风铃岛 | 连续海蚀拱、悬挂风铃、岩峰与沿岸岩群、带屋顶与绳栏的可攀登瞭望平台 |
| 翡翠潮林岛 | 弯曲老树、外露根系、独立叶片的树冠、迎风松、蕨类、灌木与营地 |
| 沉船沙洲 | 弯曲肋骨、错缝破损船板、部分甲板、倾斜桅杆、残帆、桅索和船首残骸 |
| 星望遗迹岛 | 径向石台、带柱槽的残柱、风化柱帽、倒塌石柱与实体星环 |

14个原创模型在Blender中制作，可编辑工程和重建脚本随PR保留。沿岸纹理岩石复用原BoatAttack资源，帐篷、桶等复用已授权的Kenney资源。[模型来源](../ArtSource/V020/ATTRIBUTION.md)

## 探索与验收

按J查看航记并设定航点，Shift减速至5.4km/h以下后G下船。E交谈、读信、开箱、操作机关；秘境线索与奖励规则沿用[第19版说明](PLAY_V019.md)。游泳、绳梯、口粮、救援及返回港口继续可用。
