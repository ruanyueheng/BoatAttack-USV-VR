# PR: v0.3 → v0.3.1 活海湾

## 目的
在已合并的第二版基础上，增加可持续的出航目标、天气变化、可观察海洋生物与更完整的原创模型，同时保留后续 PICO 4 Ultra 的性能/舒适性边界。

## 提交与范围
- 首个提交：此前本地 v0.3——订单、鱼获图鉴、鱼饵策略、HUD 重排、港口装饰与 XR 水面采样准备。
- 第二个提交：本轮 v0.3.1——五种天气、自然观察日志、海龟/鳐/海豚/鱼群/海鸥、曲面网格工具、礁石/珊瑚/海草/贝壳/海星/拱门、可点击工具栏、天气设置，以及零时间步相机 NaN 修复。
- 没有安装新的 SDK、升级 Unity/URP 或改写原海岛场景；不包含 Windows 程序、临时日志或玩家存档。

## 实现要点
- 天气 12 秒平滑过渡，固定或自动循环，暂停冻结；活跃鱼种咬钩等待 -25%、稀有概率 +4 个百分点，在抛竿时锁定。
- 天气环境借用值在 disable 时恢复；天空是运行时克隆，不污染共享材质。
- 9 个固定生物实体和 3 个生态景观网格；观察要求 28m 内、面向目标、无实体遮挡；重复观察不能刷金币。
- 普通雨量最多 96 片几何条带，精简/活动 XR 时 32 片有效条带；不使用闪电、镜头抖动、体积云或额外反射相机。
- 自然观察按可选 wildlifeMask 写入 v2 存档，兼容旧 v2 缺少该字段；v1 按第三版规则迁移。v2 仍不可交给第二版直接读取。
- 本轮发布目录使用非 Development 的 Windows Release 构建。

## 人工审查 / 未宣称完成
- Windows 的防火墙弹窗阻挡了交互验收；没有批准或修改安全设置。离屏场景图不是完整 HUD/键鼠测试，黑屏的桌面 backbuffer 截图不作为证据。
- 新模型是低成本风格化原创网格，不是写实生物资产；新增生物采用有限路径，不是食物链/繁殖/捕食模拟，也不可捕捞。
- 继续检查鱼群实际路径、鳍翼形变、天气色调、字号/按钮、音量、普通键鼠/手柄和长时间舒适性。
- 尚无 PICO loader、XR Origin、真实手柄捕鱼、ARM64 APK、Vulkan/Multiview 或 PICO 4 Ultra 帧时/温度验收。所有几何预算均不等于全场景性能保证。
- 原第一人称桌面与世界空间只读仪表不是头显运行模式。

## 建议审查顺序
1. `BayClimate.cs`、`FishingModel.cs` 与 `ClimateTests.cs`：规则、存档兼容和奖励边界。
