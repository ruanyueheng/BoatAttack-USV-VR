# 0.48 PICO 捕鱼闭环与界面

## 现在怎样钓鱼

1. 在钓点按A驻钓，再按A快捷拿竿抛出。也可用右握把拿竿、甩腕抛竿。
2. 咬钩时A提竿；遛鱼时按住右扳机收线，鱼跃水或张力高时松开。
3. 鱼靠近后可用手/抄网接住；等待的自动辅助仍保留。钓上来后，收获卡出现在当前视线前约1.25米。
4. 普通鱼按A放入鱼箱；卡片自动收起，再按A即可快捷拿竿重抛。选择放生需要单独确认。
5. 传说鱼先按A测量，再按A发起放生，松开后再次按A确认。不会作为普通鱼卖出。

鱼箱满时保留待处理鱼并显示原因，不重复扣除或结算。B可以收起界面，之后A仍能重新处理鱼获。菜单、失焦或追踪中断会释放工具，恢复后可以重新拿竿。

## UI 与画面

手册改用与Windows相同的星海底图和撕边羊皮纸，保留共用衬线标题、金边、插画和图标。新收获卡直接使用Windows鱼类缩略图，只呈现存放和放生两项相关操作。

继承0.47的100%渲染比例、4×MSAA、Low固定注视点、平滑转向和远景方向修复。移动端水面复用已有主阴影结果，减少四次额外阴影采样；使用官方OpenXR持续性能等级，保留系统温控管理。实际帧率以验证记录为准，不宣称全场景90Hz。
