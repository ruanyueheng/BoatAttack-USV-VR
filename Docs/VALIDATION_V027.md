## 视觉与实现中修正的问题

- Unity 单面剔除发现屋顶绕序错误；修正主屋顶和瓦片朝向，并在建模脚本加入朝上法线检查。
- 功能页左侧纸面遮挡状态/地图；修正装饰背景的兄弟顺序，加入内容在纸面之上绘制的检查。
- 样板恢复首页时，功能页副标题可能残留；恢复首页的固定副标题与原图标。
- 原码头按钮中心为固定数值；新布局改从实际 BoxCollider 中心计算，保留既有射线验证调用。
- 字体层级变化后，标签宽度可能用上一段标题字测量；标签测量前明确切回正文字体。
- 航线遮挡验收曾依赖“返港后仍残留一条路线”的偶然状态；现在通过实际导航目标与规划命令建立明确夹具。
- 邻近岩壁清理同时保留旧设施/命名点支撑；地形仅复制修改，不写回源资产；海水深度重新采样。
