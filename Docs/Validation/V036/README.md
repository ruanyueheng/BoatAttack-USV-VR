# V036 历史证据归档

本目录从本地第36版最终运行记录提取，供 PR 和克隆后的仓库直接阅读。此次归档没有重新执行第36版测试，也不作为第37版验证结果。

`sources.json` 记录每份原始文件的本地相对路径、SHA-256、归档文件名和提取方式。断言摘要保留原始结果行，去除启动日志与堆栈，并将工作区绝对路径改为仓库相对路径；规则和输入摘要仅保留各自最终总数。原始完整日志、安装包及全部截图仍保存在本地 `Logs/`、`Builds/`，这些目录没有随本次 PR 发布。

JSON 保留历史数值和版本，仅将工作区绝对路径改为相对路径。性能测量输出、井水截图、APK 签名与上一版证书记录按字节原样归档。`apk-signature.txt` 与 `apk-prior-signature.txt` 可核对 APK v2 签名及证书摘要一致性。

本页所列历史证据只对应 `0.36.0 / versionCode 36`。当前版本结果见[第37版验证记录](../../VALIDATION_V037.md)。
