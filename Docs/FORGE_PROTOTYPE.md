# 三类工坊的当前分工

参考 Minecraft 的工作台组装、熔炉处理原料的分工；金属塑形阶段按本游戏需求额外设计，不声称是原版 MC 铁砧配方。参考 [官方配方机制](https://learn.microsoft.com/en-us/minecraft/creator/documents/recipeintroduction?view=minecraft-bedrock-stable)。

| 设施 | 职责 | 产物 |
| --- | --- | --- |
| 工作台 | 组装、工艺制作 | 石镐、铁镐、猎矛、猎枪、灯笼、望远镜、熔炉和锻造台设施 |
| 熔炉 | 消耗燃料、计时冶炼/烧制 | 铁锭、木炭、玻璃、砖、烤肉 |
| 锻造台 | 金属塑形 | 铁镐头、枪械铁件 |
| 随身加工 | 无需设施的基础处理，单独页签 | 木板、木棍、绳索、基础工作台 |

主要配方：

| 产物 | 材料 | 设施 |
| --- | --- | --- |
| 木棍 ×4 | 漂流木 ×1（或木板 ×2） | 随身加工 |
| 石镐 ×1 | 石料 ×3、木棍 ×2、绳索 ×1 | 工作台 |
| 铁锭 ×1 | 铁矿石 ×1 + 燃料 | 熔炉，8 秒 |
| 铁镐头 ×1 | 铁锭 ×3 | 锻造台 |
| 铁镐 ×1 | 铁镐头 ×1、木棍 ×2、绳索 ×1 | 工作台 |
| 枪械铁件 ×1 | 铁锭 ×6 | 锻造台 |
| 猎枪 ×1 | 枪械铁件 ×1、木板 ×2、绳索 ×1 | 工作台 |
| 灯笼 ×1 | 煤 ×2、兔毛 ×1（或狐皮/旧毛皮 ×1） | 工作台 |
| 锻造台 ×1 | 石料 ×8、黏土 ×4、木板 ×4 | 工作台 |

熔炉沿用每份 8 秒、煤/木炭支持 4 份、木材支持 1 份的现有燃料和队列规则。原主线铁锭/玻璃灯笼及海贝灯笼配方继续保留在工作台。猎枪仍可在商店购买，制作只是新增获取渠道，价格和射击行为不变。

初始西岸的公共工作台、熔炉、锻造台均可使用；靠近按 E。设施页只显示各自配方，“随身加工”页独立保留木板/木棍等操作。桌面与 XR 使用同一设施分类表；在错误设施上请求制作会被拒绝，不吞材料。

石料和漂流木等在岸上 E 采集。煤点位于真实山脚岩壁旁，持石镐/铁镐 E 开采，煤 ×3 / ×4；资源 90 秒恢复。铁矿同样需要镐。煤 + 毛皮灯笼必须回工作台组装，装备后 F 点亮/熄灭。

保存兼容：既有物品 0–37 不重新编号，铁镐头与枪械铁件追加为 38 / 39。旧铁镐、猎枪、灯笼等成品保持原样；炉内任务保留旧配方 ID、已预留的材料/燃料和加工进度。旧锻造台的即时冶铁/石镐/铁镐配方 ID 仅作为正确设施配方的别名，不在 UI 重复显示，也不允许旧设施绕过分工。

锻造与组装仍为即时材料交易；暂不扩展敲击小游戏、装备耐久、附魔或新动画。新增零件使用无字简图和低面数占位模型，不改变已有枪体、镐子或灯笼模型。

验证入口：`Tools/Run-UnityValidation.ps1 -Suite FishingForge`。本机可使用临时 `-DisableBurst` 绕过原生缓存问题，不修改永久设置。完整场景测试覆盖真实采石、工作台石镐、真实熔炉 Update 完成冶铁、锻造两个零件、工作台组装铁镐与猎枪、煤矿开采、工作台灯笼和保存。
