# 锻造台首版

西侧初始登岸点的公共工坊增加一座锻造台。模型包含石基、砧座、锤子、钳子和煤火；靠近按 E 打开专用制作页。

暂定配方：

| 产物 | 消耗 | 设施 |
| --- | --- | --- |
| 石镐 ×1 | 石料 ×3、木棍 ×2、植物纤维 ×2 | 锻造台 |
| 铁锭 ×1 | 铁矿石 ×2、煤 ×1 | 锻造台 |
| 铁镐 ×1 | 铁锭 ×3、木棍 ×2、绳索 ×1 | 锻造台 |
| 手提灯笼 ×1 | 煤 ×2、兔毛 ×1（或狐皮 ×1） | 锻造台 |
| 锻造台 ×1 | 石料 ×8、黏土 ×4、木板 ×4 | 工作台 |

石料、漂流木、纤维和黏土通过岸上 E 采集；低处石料需靠近并按 Ctrl 蹲下触及。矿石和煤需要镐。漂流木 ×1 可徒手直接制木棍 ×4，无需寻找木棍采集点；原木板 ×2 制木棍 ×4 保留为备用配方。锻造台页面也展示徒手配方，材料齐全后可在同一页准备木棍。首版锻造为即时交易；铁锭配方中的煤直接作为材料消耗，尚未添加敲击小游戏、耐久或时间队列。

煤点现在位于真实山脚岩壁旁的可站立地面，保留原资源 ID 和 90 秒恢复记录。装备石镐/铁镐后靠近按 E 开采；石镐得煤 ×3，铁镐 ×4，不直接破坏山体碰撞网格。无安全落位的海岸不强放煤点；初始西岸已验证可开采。

在锻造台选择对应毛皮的灯笼配方；兔毛与狐皮不混为一种物品，旧存档的旧毛皮也有兼容配方。龟壳和海鸥羽毛不算毛皮。产物沿用现有提灯模型、图标及照明：装备到快捷栏后 F 点亮/熄灭。原主线铁锭/玻璃灯笼配方保留，不影响旧存档。

自己制作的锻造台可放进快捷栏，岸上按 F 放置，空闲时可回收。公共锻造台不能拆除。设施类型和位置、背包材料及产物均随存档保存，旧存档加载后只补一座公共锻造台。满背包或材料不足不会吞材料。

验证入口：`Tools/Run-UnityValidation.ps1 -Suite FishingForge`。本机可添加 `-DisableBurst` 临时绕过原生 Burst 缓存加载失败；不修改全局设置。测试覆盖真实岸上采石、打开锻造台、制作、保存与防重复生成。场景预览输出 `Logs/Forge/forge-in-game.png`。

已兼容主线 v0.23（b726e38）新的物品模型、握持接口及 v12 存档；Unity 2022.3.62f1 狩猎与锻造专项通过。石料采集测试使用新模型实际可达位置，不绕过臂长判定。
