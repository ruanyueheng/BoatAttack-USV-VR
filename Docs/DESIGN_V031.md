# 第31版设计记录

2026-10-17，潮汐回响 v0.31.0。

## 设计依据

实际研究[小王子：星辰之旅](https://littleprince.dev/)的开场、章节地图、暂停、设置与两章三维场景。首次公开访问停在加载完成页；按用户要求另派子代理长时间等待后，在本机 Edge 实际进入家园与国王章节，并操作了移动、快跑、开门、对话和章节切换。参考截图保存于本次会话的 visualizations 目录，未复制其游戏资源。

观察到的主要特点：画面承担氛围；重点标题与辅助文字有明确尺寸差；米白、暖金和深蓝形成稳定对比；锁定内容以淡色剪影表达；章节选择后只呈现一段短简介与一个主要行动。第31版据此采用夜海主菜单、七章竖向目录、插画卡片和单条详情，并让实体翻书先于阅读页出现。

另阅读 [Black Salt Games 对 DREDGE 界面、交互和适配的第一方设计复盘](https://developer.apple.com/videos/play/meet-with-apple/247/)，关注画幅适配、点击目标、减少误操作与保留世界可视面积。未将其移动端布局直接移植到桌面或头显。

## 实现范围

- 启动菜单：开始游戏、控制、退出；开始游戏续用既有存档，首次开始后才进入序章。
- 控制：全屏/窗口按钮、F11 与 Alt+Enter、窗口可调整大小；窗口参数交由平台管理，舒适与音效偏好沿用既有隔离规则。
- 提灯：桌面选中即手持，F 开关，换其他工具后回到腰间；VR 仍按实际握取。暖光与发光窗跟随可见灯体。
- 低位拾取/采集：共用真实臂长、视线和俯身上限，先完成自动蹲姿再推进接触计时；不跳过障碍、工具要求、满包或事务检查。
- 自然手册：独立封面、书页、书签与自然笔记；双手翻开后进入自然观察页；Esc 返回游戏。
- 航海手札：七章目录；鱼种目录与详情分开，传说、观察、调查、日历、四岛与秘境均增加插画/实物图标。
- 夜景：月牙、280颗稳定星点、家岛既有灯塔双向暖色环扫。昼间消隐，雨雾减弱星月；暂停时停止灯束旋转。
