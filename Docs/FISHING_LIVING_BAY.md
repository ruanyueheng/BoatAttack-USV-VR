# v0.3.1 活海湾：天气、自然观察与原创曲面建模

基于 v0.3，2026-09-27。本次 PR 同时包含此前尚未提交到主分支的 v0.3 与本轮活海湾扩展，分两个功能提交审查。Windows 仍是当前可运行目标，**不是已完成的 PICO APK**。

## 天气如何影响出航

| 天气 | 观感 | 活跃鱼种 |
|---|---|---|
| 晴朗海湾 | 清澈光照、较远能见度 | 珊瑚鱼 |
| 海风多云 | 冷色天空、减弱日照 | 飞梭鱼 |
| 轻雨潮汐 | 有限雨滴、柔和环境声 | 飞梭鱼 |
| 薄雾海湾 | 平滑线性雾、保持近场清晰 | 鼓鼓鱼 |
| 金色夕照 | 暖色天空、低角度阳光 | 珊瑚鱼 |

- 自动按此顺序循环，每种保持约 95–150 秒，变化采用 12 秒平滑过渡。暂停时天气与生物停止推进。
- 活跃鱼种咬钩等待缩短 25%，稀有概率增加 **4 个百分点**。鱼饵与天气叠加，例如珍珠饵的 25% 变成 29%；不是所有鱼种普遍加成。
- 加成在每次抛竿时锁定；天气变化不会改变正在收线的鱼或追溯修改鱼价。
- 暂停设置支持选择下一种天气、固定当前天气 / 自动循环、精简雨量。过渡未结束时拒绝再次换天气，以免反复点击产生亮度跳变。
- 天气偏好只作用于本次运行，不改玩家存档；重新开始默认晴天。
- 不增加雷电闪屏、风暴推船或镜头晃动。薄雾从 35 m 后开始，最短雾终点 185 m；不遮挡近处工具与鱼获。

## 生物不是只作摆设

- 新增 **绿海龟、蓝斑鳐、湾流海豚、银鳞鱼群、海湾鸥**。
- 固定 9 个活动实体：海龟、鳐、海豚各 1；鱼群、海鸥各 3。每个鱼群由一份包含 7 条鱼的网格绘制。
- 海龟缓慢浮游，鳐舒展胸鳍，海豚有跃出动作，鱼群沿渔区游动，海鸥环港盘旋；部分鳍翼使用低振幅顶点动画，不为每片鱼鳍建立独立物理对象。
- 雨天提高鱼群活动速度，晴天 / 夕照提高海豚活动；变化使用插值和积分，不因换天气瞬移。
- **T 观察**：在 28 m 内看向尚未记录的生物，并且视线未被实体障碍遮挡，即可收录到日志的“自然观察”页。可点击左侧出现的观察按钮。
- 自然观察不消耗鱼箱、不增加金币、不重复刷奖励；已有三种可捕获鱼类保持原玩法。新增大型生物是观赏对象，不可捕捞。
- 这是有限路径的生态表现与发现系统，不是食物链、捕食 AI、繁殖或完整生态模拟。生物和新景观无碰撞，不承诺全海域真实避障。

## 建模与画面

所有本轮模型为项目内原创程序化网格，未下载第三方商业生物资产。

- 海龟：曲面背甲、抬高的甲片、浅色腹甲、头眼和四鳍。
- 鳐：宽胸鳍、细尾、蓝斑与眼部；海豚：流线身体、浅腹、吻部、背鳍与水平尾鳍。
- 海鸥：躯干、头喙、分层羽翼和深色翼尖；鱼群：银蓝体色与尾鳍。
- 石块由原来的八面体轮廓改为多层错位岩面；增加枝状珊瑚、弯曲海草、贝壳、海星和礁区拱门。
- 新增 `FishingPalette`：URP 顶点色受光与雾化 shader，保留 stereo / instancing 宏；共享材质而非为每个颜色新增 renderer。
- 3 处生态景观各合为 1 个网格。原装饰（含港口）22 个合并 renderer / 37,463 顶点；新增生物与生态景观共 8,464 个唯一网格顶点。此数**不含原岛屿、海面、渔具和文字，不是全场景帧率结论**。
- 超出距离的生物（160 m）、生态景观（200 m）停止绘制。人口固定，运行中不反复创建 / 销毁动物。

## UI / 可靠性

- 左侧天气卡显示当前天气、活跃鱼种、预报与剩余时间。
- 图鉴拆为鱼获 / 自然观察页，新增可点击图鉴、设置、视角按钮，保留键盘快捷键。
- 点击左侧按钮不会同时抛竿或收线；屏幕坐标经过宽高缩放后再判断交互区。
- 捕鱼音效与天气音统一静音；引擎和原环境音不在本开关范围。
- 修复暂停 / 恢复同帧 `deltaTime=0` 时 `SmoothDamp` 可能造成 NaN 相机位置的问题，桌面相机和世界仪表都加零步长保护。
- 天气组件启用时暂时接管当前捕鱼场景的环境写入者，克隆天空材质；停用时还原天空、太阳颜色 / 旋转 / 强度、雾和环境光，恢复原组件。不会把天气烘写进共享天空材质或原竞速场景。

## 保存与版本

- 延用 v0.3 的 version=2，新增可选 `wildlifeMask`。已有 v2 未包含该字段时按 0 读取；支持迁移 v1。
- 不增加全新存档文件名，保留原金币、升级、鱼箱、订单、鱼获图鉴与已处理 ID。
- 旧版 v0.2 不能读取 v2，这是第三版已有的单向迁移边界。需要回退旧版前请保留存档副本。
- 非 Development 的 Release 构建，不需要联网；独立运行：`Builds/FishingPrototype-v0.3.1/FishingPrototype.exe`。此前 v0.2 / v0.3 构建保留。

## PICO / VR 的保守处理

- 雨为最多 96 片小型不透明几何条带，精简模式或活动 XR 时最多 32 片有效条带；不使用满屏透明雨幕、体积云、闪电或新反射摄像机。
- 雨滴在船周 4.5–11 m 环带，不贴脸、不附着头显视野。
- 仅使用一个既有太阳灯，不额外增加实时灯或每帧更新反射探针。
- 仍需匹配 PICO 4 Ultra 实际固件的 SDK / loader、XR Origin、真实双手工具交互、ARM64 构建，以及设备上的双眼水面 / 新 shader / 持续帧时 / 温度 / 舒适性测试。
- 桌面 D3D11 shader 编译、mesh 预算、自动测试通过，不等于 PICO Vulkan / Multiview 已验证。

## 审查建议

1. 先看 `BayClimate` / `FishingModel` 与纯规则测试：天气输入、固定 / 自动 / 暂停、观察保存及旧档兼容。
2. 再看 `FishingWeather` 的生命周期恢复与雨量上限。
3. 看 `FishingEcology` 的观察视线、固定人口和 `FishingMeshBuilder` 的网格复用。
4. 最后看 HUD 与扩展 `FishingAutoplay`；手工检查实际画面、鱼群位置、音量及按键手感。

### 本轮图像修正

离屏渲染复核发现：新网格颜色需要从 sRGB 转线性才能保留预期绿 / 蓝色；原海岛天空使用 `_SkyTint` 而不是 `_Tint`，且曝光为 4。已修正顶点色转换与天空属性匹配，并仅在捕鱼运行时天空克隆上将曝光限制为 1.4，原天空资产不变。雨滴使用浅蓝色不受光条带，避免弱光下变成黑色短线。

“多云”采用现有天空背景的颜色/日照/雾变化，不新增体积云或气象流体模拟。
