# 参考：《小王子：星辰之旅》（littleprince.dev）实玩观察 V044

截图根目录：`Logs/V044/ref/lp-scenes/`（下文简写为 `S/`）。实玩环境：Edge + Playwright CDP，视口 1600x900。
实玩覆盖：标题、旅程地图、B-612、国王星、爱虚荣的人、酒鬼，共 4 个已解锁星球；后 4 个星球被云雾遮住，没有进入。
脚本：`E:\cdptools\lpstep.js`，每步一个进程，复用同一个标签页。

## 一、通用框架

- **操作**：WASD 或方向键移动，镜头相对角色；鼠标移动控制环绕镜头（指针锁定，拖拽时灵时不灵）；E 交互；Esc 暂停。没有跳跃、冲刺之类的复杂操作。
- **相机**：第三人称肩后跟随，距离近（角色约占屏高 1/3）。进入室内或贴墙时会自动拉近、抬高视角（`S/03-king/06.png`、`S/05-drunk/05.png`）。
- **任务 UI**：左上角是一颗金色四角星加一行衬线中文主目标，下方是小字子目标，比如“照料玫瑰花 / 去工具棚拿水壶”（`S/02-b612/grid-a.png`）。界面上只有这一处 HUD，没有血条和小地图。
- **引导**：目标物上方浮一个**金色细圈加四角星**的世界空间标记，并有星屑粒子拖尾，从角色身边飘向目标（`S/02-b612/03.png`、`05.png`）。走近后出现键帽式提示“[E] 推开门”（`S/04-vain/02.png`）。
- **对话**：底部是半透明暗色长框，带细金边，左上角是说话人名牌，文字逐字淡入（`S/02-b612/06.png`）。
- **暂停菜单**：背景是全屏高斯模糊的游戏画面，左侧竖排衬线字：Logo、章节名、继续、设置、回到旅程地图、全屏、清除进度。当前项前面加金星（`S/02-b612/15-pause.png`）。
- **关卡选择**：一张羊皮纸撕边卷轴铺在星空上，8 颗小星球按两行排列，用金色虚线连接。未解锁的星球是灰蓝剪影加云团遮罩，选中的星球套金色圆环。底部依次是：章节号、星球名、一句原著引文、“前去拜访”（`S/01-map/01.png`）。
- **加载页（过场）**：深蓝星空，左侧是章节号、大标题、金线加星、副题和两行旁白，右侧是水彩风星球插画。底部的金线进度条以一颗星为游标，同时有一群白鸟沿金色点线从左飞到星球，把加载进度做成了“旅程”的样子（`S/02-b612/01.png`、`02.png`）。
- **美术分层**：UI、地图和加载页一律是水彩或纸本插画（`S/00-title/02.png`）；3D 场景是写实偏风格化的 PBR 卡通，近似皮克斯风。两套风格只靠统一的配色和金色衬线 UI 串起来。

## 二、按场景

### B-612（`S/02-b612/`）
- 场景：草坡上有花海（白雏菊、紫薰衣草、黄花），三座冒烟的火山，一间木工具棚，树桩上放着玻璃罩和玫瑰。**星球边缘外面是无边云海**，地平线被雾化成白色（05、06、13）。
- 建模：草是海量单片草叶卡，风吹摆动，近景很密。岩石是圆钝的低频造型，带苔藓顶面混合。火山是简洁锥体，烟柱用体积感粒子做。角色头发是大块“叶片”状发束，衣服有布纹法线（06 近景）。
- 光照：高饱和蓝天，强太阳和光晕，逆光下角色边缘被照亮（`14-backlit.png`）。阴影柔和，远景有大气透视。
- 交互：先自动触发“去看看玫瑰花”，到达后弹出对话，接着派发子任务“去工具棚拿水壶”，属于典型的“小事+情绪”任务链。

### 国王星（`S/03-king/`）
- 场景：奶油白大理石宫殿，金色皇冠浮雕门，紫色王旗，琥珀色彩窗。地面是罗盘星芒拼花，抛光大理石带反射（01、05）。门外是紫蓝晚霞和巨大的积云（11）。
- 演出：门在靠近后自动敞开，门缝里透出红毯、远处的王座和顶部的金色吊灯，一次纵深构图就把目标交代清楚了（09）。
- 色板：奶油白、金、紫红、晚霞粉紫，暖色主光加冷色天光。

### 爱虚荣的人（`S/04-vain/`）
- 场景：红白条纹马戏帐篷剧场，挂满灯泡串和三角彩旗，门楣上是悲喜剧面具，外墙贴海报“LE VANITEUX”（01）。室内有一排排红椅、星纹红毯、红丝绒幕，舞台中央站着戴高礼帽的人（08）。
- 交互：门口是“[E] 推开门”。座位上浮着几个金圈标记（可能可以坐下或鼓掌，没有试出来）。
- 灯光：大量小点光源（灯泡串）加暖橙主色，舞台上有一束顶光，营造“表演”的氛围（14）。

### 酒鬼（`S/05-drunk/`）
- 场景：黄昏，鹅卵石小路，粗石墙配木梁的半木结构酒馆，门两侧挂壁灯，吧台窗口透出暖光，木桶、高脚凳，常春藤垂挂（01）。
- 室内：木地板、楼梯，桌上摆满酒瓶，酒鬼垂头坐着，只有一盏烛光（06）。整体偏暗，只做局部暖光，情绪压抑。
- 建模：石块是夸张圆胖的“面包石”，体块大，法线细节少，很适合手工或程序化建模参考（02）。

### 音效印象
截图看不出音效。从页面行为推断：标题页需要点击才进入，大概率是为了解锁 WebAudio 播放 BGM；加载页文案很文学，推测配的是钢琴或弦乐的安静配乐。这部分**没有实测**，请 audio 组自行试听确认。

## 三、可迁移到海岸游戏的建议

### UI
1. 全游戏只留一处 HUD：左上角“金色图标+主目标+子目标”两行衬线字（参考 `S/02-b612/grid-a.png`）。把我们的捕鱼任务、秘境目标统一塞进这个组件。
2. 目标指引改用世界空间的“细金圈+星”标记，加一条从玩家飘向目标的粒子拖尾，代替箭头或小地图（`S/02-b612/03.png`）。
3. 交互提示做成键帽加动词短语，比如“[E] 收网”“[E] 推开门”，靠近时淡入（`S/04-vain/02.png`）。VR 版可以把键帽换成扳机图标。
4. 暂停菜单：全屏模糊游戏画面，左侧竖排文字，当前项前加金星（`S/02-b612/15-pause.png`）。
5. 对话框：底部半透明暗框，细金边，名牌，文字逐字淡入（`S/02-b612/06.png`）。

### 模型
1. 石块、礁石用“圆胖低频体块+顶面苔藓或青苔混合”（`S/05-drunk/02.png`、`S/02-b612/03.png`），比写实碎石更耐看，面数也低。
2. 地标物用强剪影：火山锥、条纹帐篷、皇冠门。海岸上可以做灯塔、红白条纹救生站、渔屋这样一眼就能认出的造型（`S/04-vain/01.png`）。
3. 植被靠密度取胜：草卡加多色小花点缀（白、紫、黄三色），近景铺满，远景渐隐（`S/02-b612/05.png`）。

### 特效 / 光照
1. 场景边界用“云海”或远景雾带把世界收口，掩盖地图边缘（`S/02-b612/06.png`）。海面地平线可以加一圈低云雾带。
2. 每个区域定一套色温：白天高饱和蓝天（B-612）、紫粉晚霞（国王星 `S/03-king/11.png`）、暖橙室内点光（剧场 `S/04-vain/08.png`）。秘境和时段可以直接套这三种。
3. 用灯泡串、壁灯这类大量小点光加 Bloom 做“温暖据点”（码头、渔屋）（`S/05-drunk/01.png`）。
4. 火山烟柱这种缓慢上升的体积粒子，可以挪用到渔屋炊烟、远处船只上（`S/02-b612/12.png`）。

### 过场 / 剧情
1. 加载页做成“章节卡”：章节号、标题、一句旁白、插画，进度条用金线加星标，再加一群鸟沿点线飞行（`S/02-b612/01.png`）。我们切换秘境时可以直接照抄这套结构。
2. 关卡地图用羊皮纸卷轴，未解锁的地点盖上云雾剪影，选中时出现金圈和一句引文（`S/01-map/01.png`）。可以作为“海域图”来选秘境或钓点。
3. 演出用“门自动打开，露出纵深目标”这种镜头替代过场动画，成本低、效果足（`S/03-king/09.png`）。
4. 任务写成“情绪小事”：看玫瑰、拿水壶，比“捕获 10 条鱼”更有温度。可以改写成“给灯塔守人送一条鱼”这类目标。

### 音效（推断，需要试听验证）
1. 标题页点击后再开启音频（浏览器和 VR 首次交互的习惯做法）。各场景用单一主题配器：草原用木吉他或钢琴，剧场用八音盒或手风琴，酒馆用低沉大提琴。
2. 交互标记出现时配一声轻铃或星音，和金色视觉标记配对。

### 秘境玩法
1. 每个秘境只做一个“主人公+一件小事”，用 2–3 步子任务链推进（对照 B-612 的“看玫瑰 → 拿水壶 → 浇水”）。
2. 秘境入口用强剪影地标加“[E] 推开门”，门开后的纵深镜头当作进入演出（`S/03-king/09.png`、`S/04-vain/05.png`）。
3. 秘境的解锁进度用地图上的“云雾散开”来表现（`S/01-map/01.png`）。

## 第二轮：通关观察（lp-explorer2，2026-10-28）

> 状态：B-612 已打到最后一步"浇水"，最后一次按 E 时同一标签页被另一个 agent（lp-explorer）切到了酒鬼/商人星，所以浇水动画和章节结束演出没有看到。截图在 `Logs/V044/ref/lp-scenes/02-b612-r2/`。

### B-612 任务链（重进章节会从头开始，一共 5 步）
1. **四处走走，熟悉一下这颗星球**：底部居中的教学提示写"[鼠标] 点击画面后移动鼠标，看看四周"（`r0.png`）。玩家走几步后，左上目标文字先变淡，再切到下一条（`r7.png`），没有弹窗。
2. **去看看玫瑰花**：玫瑰在山顶，有玻璃罩、木栅风屏和树桩台（`r26.png`、`r30.png`）。它不锁顺序：我路过工具棚时先拿了水壶，系统照样认，再走到玫瑰附近时直接跳到"去泉眼打水"（`r12.png`）。
3. **拿水壶**：水壶就放在工具棚地上。靠近后屏幕上出现 "[E] 拿起水壶"，按下后角色手提水壶走路，提示变成 "[E] 放回水壶"，可以反悔（`r7.png`）。
4. **去泉眼打水**：泉眼在悬崖边的小池，池子连着小溪。靠近出现 "[E] 打水"（`r19.png`）。按下后角色**自动走到水边，蹲下把壶浸进水里**，水面冒出白色涟漪环（`w2.png`、`w4.png`），同一时刻目标切到"最后一次给她浇水"。
5. **最后一次给她浇水**：只有面朝玫瑰并靠得够近才出现 "[E] 浇水"（`v1.png`）。

### 引导手段
- 目标点上有金色圆环加四芒星，作为世界空间标记。从角色身边飘出一串金色星屑，沿地面指向目标（`r4.png`、`r11.png`）。
- 没有小地图，也没有箭头。星球很小，加上地标物（工具棚、火山、玻璃罩），基本不会迷路。
- 目标文字一律写成带情感的短句，比如"最后一次给她浇水"，既交代了剧情（要告别），也说明了动作。

### 交互反馈（重点：水壶和浇水）
- 交互提示是**世界空间的键帽加动词**，在物体旁边淡入，动词随状态变化（拿起/放回/打水/浇水）。
- 拿起水壶后，水壶挂在手上的骨骼点上，走路时跟着摆动。没有背包 UI，"拿着什么"直接看角色手上。
- 打水用的是"自动对位 + 蹲下动画 + 水面涟漪"三件套。玩家只按一次键，不用自己去对准位置。
- 镜头会跟着上下坡自动俯仰，体验上偶尔会变成俯视（`r11.png`），VR 里不能照搬这一点。

### 对我们的借鉴（水壶、浇水）
- 水壶要分**空/满两个状态**，打水是一个独立的子任务。满壶时可以在壶口加滴水粒子作为状态提示（它是靠任务文字提示的）。
- VR 里打水要"把壶口压到水面以下 0.3 秒"才算灌满，同时配涟漪环加咕嘟声。浇水按壶身倾斜角度出水，接近目标时出现金圈提示。

### 第二轮补充：用户通关后的各星球观察
地图通关后，8 颗星全部解锁（`01-map/02-all-unlocked.png`）。下排四颗依次是第五章商人（玻璃穹顶天文台）、第六章点灯人、第七章地理学家、第八章地球（沙漠和坠机）。点线路径呈 S 形把它们串起来。
- **已拜访星球的地图文案会变成回顾句**："点灯人 · 已经拜访过 / 他想留下来陪点灯人，可这颗星球太小，容不下两个人。"按钮也从"前去拜访"变成"再去看看"。文字以打字机效果逐字出现（`01-map/03-lamp-selected.png`）。
- **离开星球的方式**：章节完成后，左上目标变成"可以启程了"，底部提示"按住 [Q] 启程"（长按，防止误触）。长按完成后，屏幕上会扩散开一块不规则的**星空水彩墨迹**，把画面吃掉，然后回到地图（`07-lamp/depart.png`）。这一步就是章节结束演出，没有结算界面，也没有奖励弹窗。
- **全程没有失败、重试和收集要素**。没有血量、计时和评分，每颗星只有一条线性任务链，失败与重试这一项不存在。

#### 点灯人（第六章，和我们的"守灯值夜"直接相关）`07-lamp/`
- **场景**：不是小星球，而是**海上的一条礁石长堤**，尽头立着一盏路灯，四周是一望无际的海面，近处有浪花溅起的粒子（`01.png`）。堤上铺满紫色和粉色的绒球花，入夜后在灯光里变成紫色。这和我们的海岸几乎是同一套构图。
- **任务**：只有一步，"去灯下看看"。走到灯下出现 "[E] 交谈"（`03.png`），对话结束后就"可以启程了"。
- **核心演出是加速的昼夜循环**：对话一开始，天空就以大约 40～60 秒一个周期循环。顺序是：白天（手绘感很强的积云、蓝天）→ 珊瑚粉和橙色的日落（太阳贴着海平线，海面成片高光）→ 紫色暮色，**点灯人举杆点亮路灯** → 深蓝夜空，星星和月亮出来，月亮在天上快速移动 → 粉紫色黎明，**点灯人举杆熄灯** → 回到白天（`timelapse.png`、`grid1.png`）。
- **对话写法**：线性，没有选项。小王子问"你好。你为什么刚把路灯熄了？""可你为什么又把它点亮了？"，点灯人答"从前还说得过去：早上熄灯，晚上点灯。""现在它一分钟转一圈，我连一秒钟也歇不了。"（`Ltext.png`）。台词之间穿插没有对话框的空镜，用来让玩家看天色变化。收尾是小王子的内心独白"……只有他不让我觉得可笑。也许是因为……"。独白不放在对话框里，而是以斜体浮字直接写在场景上方。
- **光照**：路灯是全场唯一的暖色点光，配大范围 Bloom，夜里人物几乎只剩剪影。整个画面的色温跟着天空走，花和海也跟着染色。

#### 国王（第三章）`03-king-r2/`
- 链路是：宫门前 "[E] 推开宫门" → 门向内打开，露出纵深 → 红毯大厅（两侧烛台、彩窗射进体积光、大理石地面反射）→ 走到王座 "[E]" 交谈。
- **对话镜头**用正反打：国王近景和小王子近景交替。中间插一个**特写**，国王用手指着书上的日历（暗示他要等日落才"命令"太阳落下），还有一个**没有台词的反应镜头**，只给小王子的表情。台词如"啊，来了一位臣民！""当然。不过命令要下在合适的时候。今晚七点四十，我会命令它落下。"/"……七点四十，它本来就要落下的。"对话同样没有选项（`Kgrid.png`）。

## 最值得借鉴的 10 条（第二轮）
1. **[过场/特效] 用对话驱动加速昼夜**：守灯值夜可以直接照搬"一段对话（或一段值守）内天空走完白天、日落、暮色、夜、黎明一整圈"，每次换段都配一个"点灯/熄灯"动作（点灯人 `timelapse.png`）。
2. **[特效/天空] 天空分五个关键色**：白天用手绘积云，日落是珊瑚粉加橙色、太阳贴海平线，暮色是紫色，夜晚是深蓝加星星和快速移动的月亮，黎明是粉紫色。花、海、人物全都跟着天空色温染色。我们重做天空时可以把这五个关键帧做成 Gradient 来插值。
3. **[模型/场景] 礁石长堤加尽头孤灯**：点灯人星就是我们海岸场景的标准答案。一条礁石堤加一盏灯，铺满绒球花，海面打浪花粒子，用一个强剪影把视线引向尽头。
4. **[光照] 夜景里只放一个暖色光源**：路灯是唯一暖光，配大 Bloom，人物压成剪影。VR 值夜时把灯塔或提灯作为唯一暖光源，代价低，情绪足。
5. **[交互] 世界空间的"键帽加动词"，动词随状态变化**：拿起/放回/打水/浇水/推开宫门/交谈。VR 里改成扳机图标加动词，物体旁边淡入。
6. **[秘境玩法] 水壶空满两态，加自动对位**：打水时按一次键，角色自己走到水边、蹲下、水面出现涟漪环。VR 里改成"壶口压到水面以下就灌满"，再配涟漪和咕嘟声。拿着的东西直接显示在手上，不做背包。
7. **[UI] 目标文字分两层，加屏幕边缘的距离指示**：左上写情感化的主目标和子步骤，目标在画面外时底边显示"蛇 · 10 米"。小场景只用金圈和星屑，大场景才启用距离指示（地球 `02.png`）。
8. **[过场] 长按启程，用水彩墨迹转场**：长按 Q 防误触，星空墨迹扩散吃掉画面后回到地图，章节之间不做结算界面。我们离开秘境时可以用"长按扳机加海雾或墨迹转场"。
9. **[过场] 对话镜头三件套**：正反打、道具特写（国王的日历）、无台词反应镜头，内心独白用浮字代替对话框。成本低，叙事密度高。
10. **[UI/地图] 拜访后地图文案改成回顾句**：章节卡从"前去拜访"变成"再去看看"，介绍语改写为这次发生了什么，用打字机效果逐字出现。我们的海域图或秘境卡可以在完成后写一句回忆，比打勾更有温度。
