# 第39版：海岸行走、正面绕线与炭烤海鱼

版本：0.39.0 / Android versionCode 39。保留 v15 存档和原有物品编号。

- 沉船浮桥的实际木板加宽至3米，两端覆盖甲板接缝，补上随桥升降的实体侧栏；横向栈道的桥口绳索留出真实开口。桥面支撑优先于水深判定，关阀保持满水通路。
- 未承重时浮桥保持锁在水下，并提示排水、推箱与注水步骤；货箱未完全到位时最多显示99%，避免外观已接平或百分比提前显示100%造成误判。
- 修正绳索被归入无碰撞装饰子网格的问题，重新生成四个秘境、风桥、根桥和相关岛屿建筑的结构碰撞。栏杆阻挡与入口开口一起检查。
- 绕线台面朝实际操作位置，取消和重新开始也保持正面。桌面画圈输入、XR握把和材料结算沿用原流程。
- 烤鱼使用腾讯混元3D V3.1实际生成的模型及原始贴图，运行网格6000三角面、长0.68米。烧烤架、手持、背包图标与烧烤页照片使用同一资源。
- 增加轻烟、细小炭火粒子与Meowa实际生成的滋滋声，烤熟后烟量降低；空架、离远和暂停时停止相应发射和声音。花园/林地有轻微花粉、夜间萤光，步行时有少量扬尘，尊重减少特效设置。
- 游近浅岸时按实际水位识别可站立的浅沙地，自动转为步行；需有四点支撑、站立净空和身体宽度的通路。陡岸仍使用原有跳跃攀岸。
- 家园边石、栅栏沿实际地形落地，草丛、花和果树也按地面查询定位。

生成记录：[混元模型](../ArtSource/V039/Hunyuan/manifest.json)、[Meowa音效](../ArtSource/V039/Meowa/sources.json)。本次使用混元1次已有额度、Meowa20已有积分，没有充值。模型通过实时BlenderMCP导入、减面、尺寸适配和导出再导入检查。

验证和安装包结果见 [VALIDATION_V039.md](VALIDATION_V039.md)。PICO实际佩戴、控制器追踪和设备长时间帧率需真机确认。
