# V037 手部交互核查

原人物每只手已有 19 个真实蒙皮关节：食指、中指、无名指、小指各 4 节，拇指 3 节。V037 没有用新造的手套遮盖原手，也没有把“增加骨骼”当作穿模的修复。

旧水壶将掌心目标直接放在提手中心线，而且手背朝下，手指朝上弯。旧测试只证明掌心接近这个目标，不能证明可见手皮包住提手。持物还叠加了当前行走/待机动画的指节姿态，握持形状会随着动画改变。

V037 把提手中心线与掌面挂点分开，按真实角色指根位置校准掌面距离，手背朝上、指尖向下闭合。主动持物时恢复每个原指节的中立局部位移、旋转、缩放，腕部保持标定的手部尺寸；退出持物后仍恢复本帧原动画。细握柄额外提供实际中心线和半径，每根手指各自闭合到接触前，拇指保留自己的对掌弯曲轴。

| 动作 | 核查及本次处理 |
|---|---|
| 拿壶、携带、打水、倾壶、归还 | 改正手背方向、掌面厚度和指根前距；同一个提手表面约束贯穿所有持壶相位，壶的位置与握点仍由独立物体决定。 |
| 提井绳打水 | 原左手在空中握拳；现可见井绳经过左手实际握绳处，并对各指提供绳面限制。取消后恢复两点井绳。 |
| 锄头翻土 | 原锄头在最终手部 IK 之后才摆放，且柄穿过掌心；现放入同一个最终呈现顺序，先摆好柄的表面，再解算原手臂和手指。 |
| 钓竿与线轮 | 保留独立竿柄及转柄挂点；竿柄和线轮增加各指接触限制，线轮继续独立旋转，手腕不随轴扭转。 |
| 镐头 | 保留实际矿石接触点、工具比例和腕臂分摊，增加木柄表面限制；接触许可不因视觉夹短而放宽。 |
| 猎矛 | 保留实际矛尖检测，逐指闭合需求改为细杆握持，再受真实杆面限制。 |
| 提灯 | 保留实物提环和专属腕姿；改用现成的逐指提灯姿势，区别于统一握拳。 |
| 摇筛、摇柄 | 桌面双手从各自柄的外侧接近，挂点留出掌厚，不再把两只掌心塞在柄中心；转柄跟随实际运动。XR 保留物理追踪位置，只为指节提供接触表面。 |
| 枪械 | 核查前护木支撑、后握把、食指扳机姿势、双手可达域、枪托与视线避让；保留专属左右指型，获得持物指节中立姿态修复。 |
| 双筒镜、手册与翻盖 | 核查厚镜筒支撑和逐指弯曲，手册翻盖继续跟随铰链；保留专属宽物支撑姿势，获得同一动画污染修复。 |
| 抄网、双手捧鱼、左手检视 | 核查真实网柄、鱼体表面取点、独立物体摆放及手臂可达域；保留各自工具挂点，获得同一指节中立姿态修复。 |
| 拾物、播种、收获、摇树 | 核查接触许可和动画所有权；XR 继续使用真实手柄位置/握把输入，不伪造手指追踪。 |

`FishingV037HandsValidation` 复用实际拿壶、补水、浇水和归还流程，额外采样多个相位的真实蒙皮顶点，要求指皮接近提手、避开提手实心区域及壶体内部；同时执行原角色姿态与手工作业回归。首轮新增检查确实找出空握和补水时穿入，修正过程保留失败日志，不以掌心误差代替皮肤检查。最终通过状态见 V037 集成验收记录。

握柄接触采用窄杆胶囊近似，并非任意形状物件的全表面物理求解。没有实体 PICO 手柄和佩戴测试，不能把源场景断言或桌面画面当作真实追踪手感、触觉及人体差异验收。
