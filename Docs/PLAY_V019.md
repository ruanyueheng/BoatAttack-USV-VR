# 第19版：潮汐回响

本版把捕鱼、航海、岛屿居民与秘境连成一段可以自由探索的旅程。Windows入口：`Builds/FishingPrototype-v0.19.0/FishingPrototype.exe`。普通启动会继承第18版存档，旧存档文件保留。

## 先去哪里

1. 按N选择“潮汐钓具店”，或在J日志中选择探索岛并设置航点。
2. Shift刹车，S倒航；低于5.4km/h时按G下船。船的基础转向目标提高到60–38°/s，操舵升级仍可继续增强。
3. 店内柜台按E打开商店，“与汐禾交谈”可以听商品介绍。店门前的林舟会介绍回潮海的故事，也负责秘境终章。
4. 到四座探索岛，与附近居民按E交谈；在潮纹石门前按E进入秘境。
5. 阅读铭文、尝试机关，前往门后的回响台领取奖励。每座秘境首通90金币，四座完成后向林舟汇报领取180金币。已完成的秘境可重访，奖励不重复发放。

## 四岛与四座秘境

| 岛屿 | 新外观与居民 | 秘境玩法 |
|---|---|---|
| 月牙风铃岛 | 风铃瞭望台、石峰、岩拱；修缮师铃音 | 风之回廊：按归航铭文敲响三种风铃，错误时重新开始 |
| 翡翠潮林岛 | 阔叶林、松树、营地、蘑菇与花；守护人青禾 | 森光庭院：安排三盏林灯的明暗，接通光桥 |
| 沉船沙洲 | 归潮号残骸、桅索、打捞台、物资桶；打捞员阿砾 | 沉潮机库：把货箱推上承重台，再操作水闸 |
| 星望遗迹岛 | 石阵、星象仪、棱镜；记录者望星 | 星轨圣所：根据日出、落日和南星的铭文调整三个星盘 |

解谜线索可以在NPC对话和J日志“世界与秘境”中查看。第18版的来信、寻宝、信标与回港航记奖励继续可用，四岛没有固定访问顺序。

## 自由移动

WASD移动，Shift快跑，空格跳跃，Ctrl蹲下。离开低岸或栈桥可游泳；Shift加速游泳会消耗体力。朝低岸移动并按空格可以上岸，靠近船体也可按G登船。

风铃岛与沉船沙洲有可攀登的绳梯。靠近两端按E开始，W/S上下攀登，空格离开。体力不足时速度降低；停步、静止游泳或坐船可恢复体力。商店“远航物资”中的炭烤兽肉可以放进快捷栏，按F食用恢复50%体力；体力充足时不消耗。

秘境入口按E返回岛屿。R随时救援回港，保留鱼获、金币及已完成剧情。秘境中途离开会重置未完成机关，已领取的回响永久保留。

## 商店和界面

商店有五个分区：钓具升级、船舶升级、探索工具、制作补给、远航物资。共六条升级线、18种可购买用品。罗盘、绳卷、提灯、望远镜、桨、铲、瓶装用品和食品分别陈列；部分食品是展示物件，不单独出售。

UI统一深海蓝、黄铜边线和物品插图。地区名称会缓缓浮出，秘境进出会淡出再淡入。日志增加世界故事与回响进度，秘境使用室内导览图。

## PICO操作与本版边界

PICO继续使用左摇杆移动、右手A附近互动、B潮汐手册。手册“潮汐回响 / 秘境”提供世界故事、航点与附近互动；店内升级页可以打开店员介绍。绳梯使用左摇杆上下；游向低岸时自动尝试上岸。秘境过渡复用头显遮罩，不接管追踪摄像机或重设眼高。

本版交付Windows试玩版；尚未生成新的Android包，也没有做PICO头显真机输入、立体显示或性能验收。NPC采用固定地点的分支对话，没有日程、配音与口型系统；攀登目前用于制作好的绳梯，不包含任意岩壁攀爬。
