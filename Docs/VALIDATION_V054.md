# 0.54.0 家园与海上集市

2026-10-31，基于已合并的 0.53（6aee16c9）。本轮按用户要求在 Windows 原生 OpenXR Mock Runtime 中模拟 PICO VR，启用 `-fishing-pico-quality`。所有自动化和试玩使用隔离存档，沿用现有存档格式。

## 修复

- 萝卜第一阶段改为四株双子叶幼苗，784 三角；种子工作台增加三个有萝卜标记的牛皮纸袋。成熟作物不变，源生成器同步更新。
- 菜园五段栅栏增加连续实体碰撞，两个原有入口保持可走。
- 渔屋粗石纹墙改为暖奶油漆墙，保留木梁、墙裙、门和家具坐标。
- 后院五类既有住所分别加入小屋、栖杆或遮阴浅池、食水碗及实体围栏。排除侵入住所的花草并避开果树。动物有步行、停顿、转身、兔跳和龟类缓慢活动；暂停或剧情期间停止活动。体型按转身占地归一，满容量时避开其他动物、食水碗和棚体。
- 限定商船增加五段船壳/甲板碰撞与随波运动的运动学刚体；商品牌显示名称、价格、选中操作和已购状态，购买指引显示余额和结果。交易要求低速靠近、明确注视且无遮挡。修复动态标签切入 VR 被清空，以及驻钓时 A 优先抛竿导致买不到的问题。
- 自查修复世界文字透墙：独立 URP 字体材质只采字体图集透明度，进行深度测试，保留颜色和立体渲染宏；字体图集重建会同步更新，未改手册 UI 材质。

## 怎么买限定商品

在“设置 → 日期与物资”选择本季 14 日 10 时并按日期重置，可进入物资齐备的独立航程。地图及航程页会显示当日集市所在渔场。

驶向集市船挂商品牌的一侧，减速至 2.5m/s 以下，靠到船中心 14 米内。看准商品牌，出现“按 A 购买”后按右手柄 A；桌面按 E。无需登上商船。商品牌显示价格，购买后显示已购与余额；收集类商品不能重复扣费。节日限定在非节日不可购买。
