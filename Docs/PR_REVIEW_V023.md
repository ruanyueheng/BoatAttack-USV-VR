# v0.23 开发者自审

What this change does: 应用用户四条混元魚素材，将可捕获生物扩为20种，加入可登岸、步行、居住和睡眠的回潮渔屋，以及36秒世界观序章。工坊物品、手持表现和桌面/XR背包统一使用实物模型与照片。

按单人本地游戏、20种固定生物、36格背包和一栋住宅评估；本报告为开发者自审，不能替代独立PR或头显审查。

## 已修复的问题

1. **新物种发现位溢出**：原int已占23位，20物种需要39位。改用long，原位次保持，实际v11十二项纪录迁移及Unity JSON高位恢复均验证。
2. **直接读取网格后模型轴不对**：FBX对象层旋转被忽略，矛尖和门廊与交互不一致。烘焙静态坐标，验证镐Y轴、矛尖+Z和门廊-Z。
3. **掌心可达却仍离开物体**：腕部目标超过实际臂长。共享工具摆放按校准后的腕部目标修正；所有钓竿、鱼获和工具调用一并更新。
4. **住宅藏在树冠且不能实际走到**：树冠被当成地基，旧自由登岸点和栈道之间有水面，初始护栏方向也挡住转移视线。固定临水位置、专用浮码头、沿入口方向的泊位与真实角色步行验证解决这些问题。
5. **家具在游戏中丢失配色**：同路径的FBX与prefab造成Resources入口冲突。住宅读取明确的View预制体，每个实物的实际材质都经过断言。
6. **多实例子部件相互变形**：GLTF左右枕头共用网格，先保存世界变换并为每个实例复制网格后再处理，避免叠加变换与漂浮。
7. **序章或床边输入穿透**：复用剧情守卫，阻止走路、房间步进、菜单、交互、工具和时间设置。未结算鱼获不能播放序章或睡眠；中断与重复完成不奖励、不重复推进时间。
8. **回归夹具仍检查旧版本**：同步15航点、v12保存、20模型预算和恢复规则；接缝检查保留真实游泳语义，不以关闭既有游泳功能来让旧断言通过。
9. **打包验收只保护旧存档**：验收同时核对v12正式存档、v11原档及二者备份和用户偏好，没有放宽隔离边界。

## 范围与开销

没有新增运行依赖或购买素材。新增原鱼约3500面，新物种≤5000面；家具与物品共用材质和缓存照片。片头纹理尺寸固定，摄影机仅播放期间启用，音频和渲染纹理在销毁时释放；头显摄影机不接管双眼。
