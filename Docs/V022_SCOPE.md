# v0.22 开发范围

日期：2026-10-13。基线：主线 `99af2eff`，分支：`feature/v022-navigation-and-letters`。

本版覆盖航点水面导航、实体拆信与阅读、居民外观、前四种鱼的图鉴缩略图与完整模型接入入口。沿用v11存档及原交易、探索、图鉴发现规则。

开发开始时已有的船体、渲染管线、鱼类导入参数、地图、旧居民缩略图、店员新资源及XR配置修改均保留，按本版文件清单提交。测试重新烘焙的地图在回归后恢复为测试前的工作副本。

## 调用范围

- 桌面地图、N键、日志、调查和XR手册继续共用航点选择；水面导览读取同一目的地。
- 由真实碰撞体规划水路；解除捕鱼场景继承的三面竞速围墙，保留岸、岩石、建筑和秘境碰撞。原竞速关卡资源不改。
- 岛屿来信、维修记录与日志故事共用浮起、脱封、翻盖、抽纸动画；移动、手持工具、近眼躯干、XR房间步进、跳过、关闭、救援及重复奖励均纳入验证。
- 五名岛屿/港口居民使用原授权人物头部与CC0成品服装、共享颜色/法线图集和两级LOD；原店员资源继续使用。
- 全部12鱼种支持同名模型、贴图和图鉴图片；前四种先使用现有网格的完整立体照片，等待用户提供混元模型后替换。
- Unity专项、既有版本与接触流程回归、Windows包、实际打包验收、使用说明、资源许可和PR审查。

原始角色、服装、鱼GLB与原件许可均保留。新增居民为静态摆姿资产，沿用原来的朝向跟随；没有把它描述为新增骨骼动画。混元模型没有在用户提供前标成完成。
