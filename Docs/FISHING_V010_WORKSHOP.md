# v0.10.0 海岸工坊与人物更新

## 续做范围

本版基于已合并的 v0.9，在 `feature/coastal-crafting-v010` 上继续完成人物、岸线交互和工坊玩法，不重建原有工程。

- 船上绿色扁圆盘是 `Safe catch inspection tray`（渔获检查托盘）。平时收起，仅在船上检查托盘内的待处理渔获时显示。
- 使用指定的 [Beach Character / Quaternius](https://poly.pizza/m/DojKLcO34E)（CC0），保留 Idle / Walk / Run。原始 GLB、Unity FBX、转换脚本及署名都已在本地，不需要再次下载。
- 按模型实际 Body / 独立 Foot 层级处理站、蹲、坐姿，使用校准后的踝部锚点和双骨 IK，避免膝踝错位或跨帧累积。
- 不再限于四个预设码头：靠近有碰撞体的低矮、干燥、可站立岸面，低速按 G 自动选落脚点。深水、窄柱、高崖和障碍物仍会被安全检查拒绝，不代表所有水陆边界均可无条件传送。
- 回船按水平船体边缘距离判断（4m），不再只量船中心或旧落点。仍检查高差和阻挡；原有码头长栈桥保留回船便利，但不能隔墙穿越。
- 公共工作台、熔炉和玩家放置设施避开整条登岸栈桥及勘测台；设施检查四角支撑、坡差与占用空间。
- 工坊交互和放置排除与岸线系统相同的水面／导航辅助碰撞体；背包和制作页保留失败、满包和存档提示。

## 玩法

1. 靠岸减速后按 **G** 下船，**E** 采集附近木堆、石块、草丛、黏土、砂和矿物。
2. **I → 制作／熔炼** 查看配方。徒手可制作木板、木棍、绳索和工作台。
3. 公共工坊在首个码头岸边。靠近工作台／熔炉按 **E** 打开对应页面。
4. 铁矿和煤需要快捷栏装备石镐／铁镐；铁镐提高矿物采集数量。
5. 制作设施后，用 **1–9** 选中，再朝岸上空地按 **F** 放置。自建设施可在界面内回收，公共设施不可拆。
6. 熔炼需要原料与燃料，关闭背包后世界时间才继续。成品必须领取；满包时留在炉内，不会丢失。设施、炉内进度及资源恢复状态随存档保存，离线不加速。

共有 **15 条配方**：

| 工位 | 配方 |
|---|---|
| 徒手 | 漂流木×1 → 木板×4；木板×2 → 木棍×4；纤维×3 → 绳索×1；木板×4 → 工作台×1 |
| 工作台 | 石块×8 → 熔炉；石块×3＋木棍×2＋绳索×1 → 石镐；铁锭×3＋木棍×2＋绳索×1 → 铁镐 |
| 工作台 | 铁锭×2＋玻璃×2＋木炭×1 → 提灯；铁锭×3＋玻璃×4＋绳索×1 → 望远镜 |
| 工作台 | 砖块×6＋石块×2 → 熔炉；贝壳×6＋玻璃×2＋木炭×1 → 提灯 |
| 熔炉 | 漂流木 → 木炭；铁矿 → 铁锭；黏土 → 砖块；砂 → 玻璃（每份 8 秒） |

煤／木炭每份可支持 4 批，漂流木／木板每份支持 1 批。单次可处理 1–8 批；每次开炉向上取整消耗燃料，不保留不足整批的剩余燃烧量。资源采集后 90 秒恢复；当前地图生成 64 处资源节点。设施总数上限为 32（含公共设施）。
